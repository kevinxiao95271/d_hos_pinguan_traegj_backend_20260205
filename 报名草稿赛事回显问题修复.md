# 报名草稿赛事回显问题修复

**修复时间**: 2026-02-25 22:52

## 问题描述

用户反馈：
> 王可心（13600001234）登录后创建了报名草稿并选定了赛事，但下次点击进入草稿编辑时，赛事字段又变成必须要选择的状态，之前选择的赛事没有回显。

## 问题分析

### 根本原因

在 `Registration` 实体中，`competition` 字段被标记为 `@JsonIgnore`：

```java
@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = "competition_id")
@JsonIgnore  // ← 导致序列化时不返回
private Competition competition;
```

这导致：
1. ❌ API返回的报名详情中**没有赛事信息**
2. ❌ 前端无法获取 `competitionId` 和 `competitionName`
3. ❌ 编辑草稿时赛事下拉框无法回显

### 数据库验证

查询数据库确认数据是存在的：

```sql
SELECT 
    r.id,
    r.project_name,
    r.status,
    r.competition_id,
    c.name as competition_name
FROM registrations r
LEFT JOIN competitions c ON r.competition_id = c.id
WHERE r.applicant_id = 9;  -- 王可心的用户ID
```

**结果**：
- 报名ID: 7
- 项目名: 我的品管圈
- 状态: DRAFT
- **赛事ID: 1** ✅
- **赛事名: 2026浙江省品管大赛** ✅

数据库中赛事信息完整，问题在于API未返回。

## 解决方案

### 修改1: 扩展 RegistrationDetailResponse

**文件**: `src/main/java/com/trae/pinguan/web/dto/RegistrationDetailResponse.java`

**修改前**:
```java
@Data
@AllArgsConstructor
public class RegistrationDetailResponse {
    private Registration registration;
    private InstitutionInfo institution;
    private List<RegistrationMember> members;
    private ActivityInfoDetailResponse activityInfo;
    private ProjectSummary projectSummary;
    private List<MaterialFile> materials;
}
```

**修改后**:
```java
@Data
@Builder
@AllArgsConstructor
public class RegistrationDetailResponse {
    private Registration registration;
    
    @Schema(description = "赛事ID")
    private Long competitionId;  // 新增
    
    @Schema(description = "赛事名称")
    private String competitionName;  // 新增
    
    private InstitutionInfo institution;
    private List<RegistrationMember> members;
    private ActivityInfoDetailResponse activityInfo;
    private ProjectSummary projectSummary;
    private List<MaterialFile> materials;
}
```

### 修改2: 更新 RegistrationService.getDetail()

**文件**: `src/main/java/com/trae/pinguan/service/RegistrationService.java`

**修改前**:
```java
public RegistrationDetailResponse getDetail(Long registrationId) {
    Registration registration = registrationRepository.findById(registrationId)
            .orElseThrow(() -> new IllegalArgumentException("报名不存在"));
    
    // ... 其他逻辑 ...
    
    return new RegistrationDetailResponse(
        registration, 
        institutionInfo, 
        members, 
        activityDetail, 
        summary, 
        materials
    );
}
```

**修改后**:
```java
public RegistrationDetailResponse getDetail(Long registrationId) {
    Registration registration = registrationRepository.findById(registrationId)
            .orElseThrow(() -> new IllegalArgumentException("报名不存在"));
    
    // ... 其他逻辑 ...
    
    // 获取赛事信息
    Long competitionId = null;
    String competitionName = null;
    if (registration.getCompetition() != null) {
        Competition comp = registration.getCompetition();
        competitionId = comp.getId();
        competitionName = comp.getName();
    }
    
    return RegistrationDetailResponse.builder()
            .registration(registration)
            .competitionId(competitionId)         // 新增
            .competitionName(competitionName)     // 新增
            .institution(institutionInfo)
            .members(members)
            .activityInfo(activityDetail)
            .projectSummary(summary)
            .materials(materials)
            .build();
}
```

## 前端集成

### 编辑报名草稿页面

**修改前**（赛事无法回显）:
```javascript
// 获取报名详情

// 初始化表单

```

**修改后**（赛事正确回显）:
```javascript
// 获取报名详情
const response = await axios.get(`/api/registrations/${id}`);
const { 
  registration, 
  competitionId,      // ✅ 可以获取
  competitionName,    // ✅ 可以获取
  institution 
} = response.data.data;

// 初始化表单
form.value = {
  projectName: registration.projectName,
  groupType: registration.groupType,
  competitionId: competitionId,  // ✅ 赛事ID正确回显
  institutionId: institution.id
};

// 赛事下拉框会正确显示选中的赛事
```

```vue
    groupType: detail.registration.groupType

});
</script>
```

## 总结

### 问题

报名草稿编辑时，赛事字段无法回显，用户需要重新选择。

### 原因

`Registration.competition` 字段被 `@JsonIgnore` 标记，导致API不返回赛事信息。

### 解决

在 `RegistrationDetailResponse` 中新增 `competitionId` 和 `competitionName` 字段，并在 Service 层显式获取和返回。
