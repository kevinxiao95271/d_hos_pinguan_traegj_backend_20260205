# 机构等级字段添加说明

## 问题描述

前端显示"-"是因为后端API返回的数据中没有机构等级信息。

## 解决方案

在以下4个API中添加 `institutionLevel` 字段：

| API | 字段位置 | 影响场景 | 状态 |
|-----|---------|---------|------|
| GET /api/registrations/{id} | institution.level | 参赛者报名详情 | ✅ 已添加 |
| GET /api/admin/registrations/filter | institutionLevel | 书审/面谈分组列表 | ✅ 已添加 |
| GET /api/reviews/my-tasks | institutionLevel | 评委任务列表 | ✅ 已添加 |
| GET /api/registrations/my | institutionLevel | 我的报名列表 | ✅ 已添加 |

## 修改详情

### 1. GET /api/registrations/{id} - 报名详情

**修改文件**: 
- `src/main/java/com/trae/pinguan/web/dto/InstitutionInfo.java`
- `src/main/java/com/trae/pinguan/service/RegistrationService.java`

**修改内容**:
```java
// InstitutionInfo.java - 添加字段
@Schema(description = "机构等级", example = "三级甲等")
private String level;

// RegistrationService.java - 填充数据
institutionInfo = InstitutionInfo.builder()
    .id(inst.getId())
    .name(inst.getName())
    .code(inst.getCode())
    .uscc(inst.getUscc())
    .region(inst.getRegion())
    .level(inst.getLevel())  // 新增
    .build();
```

**返回示例**:
```json
{
  "data": {
    "registration": {...},
    "institution": {

      "uscc": "12330000470093469F",
      "region": "浙江省杭州市",
      "level": "三级甲等"
    },
    ...
  }
}
```

- `src/main/java/com/trae/pinguan/web/ReviewController.java`

**修改内容**:
```java
// ReviewTaskItem.java - 添加字段
private String institutionLevel;

// ReviewController.java - 填充数据
ReviewTaskItem.builder()
    .id(task.getId())
    .registrationId(reg != null ? reg.getId() : null)
    .projectName(reg != null ? reg.getProjectName() : null)
    .institutionName(reg != null && reg.getInstitution() != null 
            ? reg.getInstitution().getName() : null)
    .institutionLevel(reg != null && reg.getInstitution() != null 
            ? reg.getInstitution().getLevel() : null)  // 新增

    .status(task.getStatus())
    .createdAt(task.getCreatedAt())
    .build();
```

## 前端调用说明

### 1. 报名详情页

```javascript
// 获取报名详情
const response = await fetch(`/api/registrations/${id}`, {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await response.json();

// 显示机构等级
const institutionLevel = data.data.institution.level;
console.log('机构等级:', institutionLevel);
```

### 2. 我的报名列表

```javascript
// 获取我的报名
const response = await fetch('/api/registrations/my', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await response.json();

// 显示列表
data.data.forEach(item => {
  console.log(`${item.projectName} - ${item.institutionLevel}`);
});
```

### 3. 书审分组列表

```javascript
// 获取分组列表
const response = await fetch(`/api/admin/registrations/filter?competitionId=${id}`, {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await response.json();

// 显示分组
data.data.forEach(group => {
  group.items.forEach(item => {
    console.log(`${item.projectName} - ${item.institutionLevel}`);
  });
});
```

### 4. 评委任务列表

```javascript

});
```

## 注意事项

1. **空值处理**: 如果机构没有设置等级，字段值为 `null`，前端需要处理空值情况
2. **权限验证**: 所有API都需要JWT token认证
3. **数据一致性**: 机构等级来自 `institutions` 表的 `level` 字段
4. **向后兼容**: 新增字段不影响现有功能
