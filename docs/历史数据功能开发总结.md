# 历史数据查询功能开发总结

## 功能概述

为品管大赛评审系统新增了独立的历史数据查询功能，允许组委会管理员和系统运维人员查询和筛选历史参赛数据。

## 开发内容

### 1. 数据库表

**表名**: `pinguan_his_data`

- 总记录数: 1818 条
- 数据来源: 历史参赛数据
- 特点: 独立表，不与其他业务表关联

### 2. 后端实现

#### 2.1 实体类
- **文件**: `src/main/java/com/trae/pinguan/domain/entity/HistoricalData.java`
- **说明**: 映射 pinguan_his_data 表的所有字段

#### 2.2 数据访问层
- **文件**: `src/main/java/com/trae/pinguan/repository/HistoricalDataRepository.java`
- **说明**: 继承 JpaRepository 和 JpaSpecificationExecutor，支持动态查询

#### 2.3 DTO 对象
- **查询请求**: `src/main/java/com/trae/pinguan/web/dto/HistoricalDataQueryRequest.java`
- **响应对象**: `src/main/java/com/trae/pinguan/web/dto/HistoricalDataResponse.java`

#### 2.4 服务层
- **文件**: `src/main/java/com/trae/pinguan/service/HistoricalDataService.java`
- **功能**:
  - 动态构建查询条件（Specification）
  - 支持多字段筛选
  - 支持分页和排序
  - 实体到 DTO 的转换

#### 2.5 控制器
- **文件**: `src/main/java/com/trae/pinguan/web/HistoricalDataController.java`
- **功能**:
  - 提供 RESTful API 接口
  - 权限验证（仅限 COMMITTEE_ADMIN 和 OPS）
  - 参数接收和响应返回

### 3. 功能特性

#### 3.1 筛选条件

| 筛选项 | 字段 | 匹配方式 | 说明 |
|--------|------|----------|------|
| 地区 | institutionAddress | 模糊匹配 | 从机构地址中提取 |
| 组别 | competitionGroup | 精确匹配 | 如：综合组、基层组 |
| 品管工具 | circleName | 模糊匹配 | 圈名 |
| 入围状态 | dataStatus | 精确匹配 | 如：已提交、已保存 |
| 医院名称 | institutionName | 模糊匹配 | 机构名称 |
| 项目名称 | projectName | 模糊匹配 | 项目标题 |
| 年份 | year | 精确匹配 | 数据年份 |

#### 3.2 分页支持
- 页码: page（从 0 开始）
- 每页大小: size（默认 20）
- 总页数和总记录数自动计算

#### 3.3 排序支持
- 排序字段: sortBy（默认 id）
- 排序方向: sortDirection（ASC/DESC，默认 DESC）
- 支持按任意字段排序

#### 3.4 权限控制
- 仅限 `COMMITTEE_ADMIN` 和 `OPS` 角色访问
- 其他角色返回权限不足错误
- 通过 JWT Token 进行身份验证

### 4. API 接口

**接口地址**: `GET /api/historical-data`

**请求示例**:
```
GET /api/historical-data?region=杭州&competitionGroup=综合组&page=0&size=20
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "content": [...],
    "totalElements": 1818,
    "totalPages": 91,
    "number": 0,
    "size": 20
  }
}
```

## 使用指南

### 前端集成示例

```javascript
// 1. 登录
const login = async () => {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      phone: '13800000041',
      name: 'CommitteeAdmin A',
      role: 'COMMITTEE_ADMIN'
    })
  });
  const data = await response.json();
  return data.data.token;
};

// 2. 查询历史数据
const queryHistoricalData = async (token, filters) => {
  const params = new URLSearchParams(filters);
  const response = await fetch(`/api/historical-data?${params}`, {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  return await response.json();
};

// 3. 使用示例
const token = await login();
const result = await queryHistoricalData(token, {
  region: '杭州',
  competitionGroup: '综合组',
  page: 0,
  size: 20
});

console.log(`找到 ${result.data.totalElements} 条记录`);
```

## 注意事项

1. **独立功能**: 此功能完全独立，不影响现有业务逻辑
2. **只读操作**: 仅提供查询功能，不支持增删改
3. **权限严格**: 只有组委会管理员和系统运维可以访问
4. **性能优化**: 使用分页查询，避免一次性加载大量数据
5. **数据安全**: 通过 JWT 认证，确保数据访问安全
