## 严重问题汇总

### 🔴 问题1：等级筛选完全失败

**现象：**
- 单独搜索"二级"：返回 **0** 条
- 单独搜索"三级"：返回 **0** 条
- 单独搜索"三甲"：返回 **0** 条

**测试代码：**
```json
POST /api/institutions/search
{
  "keyword": "",
  "region": "",
  "level": "三级",
  "page": 0,
  "size": 10
}
```

**预期结果：** 返回所有三级医院  
**实际结果：** 0 条记录

**影响：** 
- ❌ 用户无法通过等级筛选机构
- ❌ 等级 + 其他条件的组合搜索也会失败

---

### 🟡 问题4：城市搜索返回结果的region字段不匹配

**现象：**

| 搜索城市 | 返回数量 | 返回的region字段 |
|---------|---------|-----------------|
| 湖州市 | 1849 | 德清县、安吉县 |
| 台州市 | 3728 | 椒江区 |
| 宁波市 | 1650 | 鄞州区、上海市、江东区、镇海区、北仑区、奉化区 |

**问题：**
- 搜索"湖州市"，但返回结果的 `region` 字段显示的是"德清县"、"安吉县"（区县级）
- 搜索"宁波市"，结果中竟然包含"上海市"的机构

**预期：**
- 城市搜索应该匹配该城市及其下属区县
- 不应该出现其他城市的机构

**影响：**
- ✅ 功能基本可用（能返回结果）
- ⚠️ 但返回结果可能不准确，需要验证搜索逻辑

## 问题分析

### 根本原因推测

#### 1. 数据库问题
```
无条件搜索返回0条 → const_init_institutions 表可能没有数据
```

**验证方法：**
```sql
SELECT COUNT(*) FROM const_init_institutions;
```

#### 2. 等级字段不匹配

**机构表存储：** `二级`、`三级`、`三甲`、`未分级`  
**前端传入：** `二级`、`三级`、`三甲`（从字典获取）  

**可能问题：**
- 字段名不对（应该是 `level` 还是 `institutionLevel`？）
- 值格式不对（是否有前后空格？）
- 查询逻辑有bug

#### 3. 关键词搜索逻辑问题

**当前情况：**
- 单独关键词搜索：失败 ❌
- 城市 + 关键词搜索：成功 ✅

**推测：**
- 关键词搜索可能依赖于 region 字段不为空
- 或者查询条件拼接有问题
