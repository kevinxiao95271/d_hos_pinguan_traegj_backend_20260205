# 机构报名数量限制 - 前端对接指南

## 功能概述

为防止单个机构提交过多报名项目，系统限制同一机构在同一赛事中的报名数量。参赛者在报名页面可以实时查看配额信息。

## 核心API

### 查询机构报名配额

**接口：** `GET /api/registrations/institution-quota`

**参数：**
- `competitionId` (必填): 赛事ID
- `institutionId` (必填): 机构ID

**请求示例：**
```bash
curl -X GET "http://localhost:6031/api/registrations/institution-quota?competitionId=21&institutionId=1" \
  -H "Authorization: Bearer {token}"
```

**响应示例：**
```json
{
  "success": true,
  "data": {
    "institutionId": 1,
    "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
    "competitionId": 21,
    "competitionName": "2026浙江品管大赛",
    "currentCount": 2,
    "maxCount": 8,
    "remainingCount": 6,
    "canRegister": true
  }
}
```

**字段说明：**
- `currentCount`: 当前已报名数量
- `maxCount`: 最大允许报名数量（默认8，运维可修改）
- `remainingCount`: 剩余可报名数量
- `canRegister`: 是否还可以报名（true/false）

## 前端实现方案

### 1. 页面加载时查询配额

```javascript
// 封装配额查询函数
const checkInstitutionQuota = async (competitionId, institutionId) => {
  try {
    const response = await fetch(
      `/api/registrations/institution-quota?competitionId=${competitionId}&institutionId=${institutionId}`,
      {
        headers: {
          'Authorization': `Bearer ${token}`
        }
      }
    );
    
    const result = await response.json();
    
    if (result.success) {
      return result.data;
    } else {
      throw new Error(result.message);
    }
  } catch (error) {
    console.error('查询配额失败:', error);
    throw error;
  }
};

// 在报名页面加载时调用
useEffect(() => {
  const loadQuota = async () => {
    try {
      const quota = await checkInstitutionQuota(competitionId, institutionId);
      setQuotaInfo(quota);
    } catch (error) {
      message.error('获取报名配额信息失败');
    }
  };
  
  loadQuota();
}, [competitionId, institutionId]);
```

### 2. 显示配额提示信息

```jsx
import { Alert, Progress } from 'antd';

const QuotaAlert = ({ quota }) => {
  if (!quota) return null;
  
  const { currentCount, maxCount, remainingCount, canRegister } = quota;
  const percentage = (currentCount / maxCount) * 100;
  
  // 根据剩余数量确定提示类型
  let alertType = 'info';
  let alertMessage = `报名配额：已报名 ${currentCount}/${maxCount} 个项目，剩余 ${remainingCount} 个名额`;
  
  if (!canRegister) {
    alertType = 'error';
    alertMessage = `您的机构报名数量已达上限（${maxCount}个项目），无法继续报名`;
  } else if (remainingCount <= 2) {
    alertType = 'warning';
    alertMessage = `您的机构还可以报名 ${remainingCount} 个项目，名额即将用完`;
  }
  
  return (
    <div style={{ marginBottom: 16 }}>
      <Alert
        message={alertMessage}
        type={alertType}
        showIcon
        style={{ marginBottom: 8 }}
      />
      <Progress 
        percent={percentage} 
        status={canRegister ? 'active' : 'exception'}
        format={() => `${currentCount}/${maxCount}`}
      />
    </div>
  );
};

// 在报名页面中使用
<QuotaAlert quota={quotaInfo} />
```

### 3. 控制"创建报名"按钮状态

```jsx
import { Button, Tooltip } from 'antd';

const CreateRegistrationButton = ({ quota, onCreateClick }) => {
  if (!quota) {
    return (
      <Button type="primary" loading>
        加载中...
      </Button>
    );
  }
  
  const { canRegister, maxCount } = quota;
  
  if (!canRegister) {
    return (
      <Tooltip title={`您的机构报名数量已达上限（${maxCount}个项目）`}>
        <Button type="primary" disabled>
          创建报名（已达上限）
        </Button>
      </Tooltip>
    );
  }
  
  return (
    <Button type="primary" onClick={onCreateClick}>
      创建报名
    </Button>
  );
};

// 使用示例
<CreateRegistrationButton 
  quota={quotaInfo} 
  onCreateClick={handleCreateRegistration}
/>
```

### 4. 创建报名时的错误处理

```javascript
const handleCreateRegistration = async (registrationData) => {
  try {
    // 创建前再次检查配额（防止并发问题）
    const quota = await checkInstitutionQuota(competitionId, institutionId);
    
    if (!quota.canRegister) {
      message.error(`您的机构报名数量已达上限（${quota.maxCount}个项目），无法继续报名`);
      return;
    }
    
    // 发起创建请求
    const response = await fetch('/api/registrations', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify(registrationData)
    });
    
    const result = await response.json();
    
    if (result.success) {
      message.success('创建报名成功');
      // 刷新配额信息
      const newQuota = await checkInstitutionQuota(competitionId, institutionId);
      setQuotaInfo(newQuota);
    } else {
      // 处理错误信息
      if (result.message.includes('报名数量已达上限')) {
        message.error('您的机构报名项目数已达上限，无法继续报名');
        // 刷新配额信息
        const newQuota = await checkInstitutionQuota(competitionId, institutionId);
        setQuotaInfo(newQuota);
      } else {
        message.error(result.message);
      }
    }
  } catch (error) {
    console.error('创建报名失败:', error);
    message.error('创建报名失败，请稍后重试');
  }
};
```

### 5. 完整页面示例

```jsx

const RegistrationPage = () => {
  const [quotaInfo, setQuotaInfo] = useState(null);
  const [loading, setLoading] = useState(true);

      setQuotaInfo(quota);
    } catch (error) {
      message.error('获取报名配额信息失败');
    } finally {
      setLoading(false);
    }
  };
  
  const checkInstitutionQuota = async (competitionId, institutionId) => {
    const response = await fetch(
      `/api/registrations/institution-quota?competitionId=${competitionId}&institutionId=${institutionId}`,
      { headers: { 'Authorization': `Bearer ${token}` } }
    );
    const result = await response.json();
    if (result.success) {
      return result.data;
    }
    throw new Error(result.message);
  };
  
  const handleCreateRegistration = async () => {
    // 创建报名逻辑
    // ...
    // 创建成功后刷新配额
    await loadQuotaInfo();
  };
  
  if (loading) {
    return <Card loading />;
  }
  
  const { currentCount, maxCount, remainingCount, canRegister } = quotaInfo || {};
  const percentage = (currentCount / maxCount) * 100;
  
  return (
    <Card title="我的报名">
      {/* 配额提示 */}
      <Alert
        message={
          canRegister
            ? `报名配额：已报名 ${currentCount}/${maxCount} 个项目，剩余 ${remainingCount} 个名额`

        showIcon
        style={{ marginBottom: 16 }}
      />
      
      {/* 配额进度条 */}
      <Progress 
        percent={percentage} 
        status={canRegister ? 'active' : 'exception'}
        format={() => `${currentCount}/${maxCount}`}
        style={{ marginBottom: 24 }}
      />
      
      {/* 创建按钮 */}
      {canRegister ? (
        <Button type="primary" onClick={handleCreateRegistration}>
          创建报名
        </Button>
      ) : (
        <Tooltip title={`您的机构报名数量已达上限（${maxCount}个项目）`}>
          <Button type="primary" disabled>
            创建报名（已达上限）
          </Button>
        </Tooltip>
      )}
      
      {/* 报名列表 */}
      {/* ... */}
    </Card>
  );
};

export default RegistrationPage;
```

## 用户体验建议

### 1. 提前提示

在报名列表页面顶部显示配额信息，让用户清楚了解剩余名额。

### 2. 分级提示

- 剩余名额充足（>2）：蓝色信息提示
- 剩余名额不足（≤2）：橙色警告提示
- 已达上限（=0）：红色错误提示

### 3. 实时更新

每次创建、删除报名后，自动刷新配额信息。

### 4. 友好提示

- 已达上限时，提示"如需增加名额，请联系管理员"
- 名额即将用完时，提示"请尽快提交"

## 常见问题

### Q1: 配额统计包括哪些状态的报名？

A: 包括所有状态的报名（草稿、已提交、已退回、已通过等），只要是该机构在该赛事中创建的报名都会计入。

### Q2: 如果用户删除了一个报名，配额会立即释放吗？

A: 是的，删除报名后配额会立即释放。建议在删除操作后刷新配额信息。

### Q3: 管理员修改限制值后，前端需要刷新吗？

A: 不需要。下次查询配额时会自动获取最新的限制值。

### Q4: 如果两个用户同时创建报名，会超限吗？

A: 不会。后端在创建时会再次检查，如果已达上限会拒绝创建。建议前端在创建前再次检查配额。
