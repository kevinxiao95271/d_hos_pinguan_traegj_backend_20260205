# 自动分组功能 - 前端对接指南

## 功能说明

自动分组功能用于将竞赛报名项目智能分配到不同的细分组（A1/A2/B1/B2/C1/C2等）。

## API接口

### 1. 执行自动分组

**端点**: `POST /api/admin/registrations/auto-group`

**权限**: OPS / COMMITTEE_ADMIN

**请求参数**:

```typescript
interface AutoGroupRequest {
  competitionId: number;           // 必填：竞赛ID
  status?: string;                 // 可选：筛选报名状态（APPROVED/SUBMITTED等）
  minGroupSize?: number;           // 可选：最小分组大小（默认20）
  maxGroupSize?: number;           // 可选：最大分组大小（默认31）
  maxStdDev?: number;              // 可选：标准差上限（默认2.5）
  maxInstitutionSpread?: number;   // 可选：同机构最多散落分组数（默认2）
}
```

**请求示例**:

```javascript
// 基本使用（使用默认参数）
const response = await fetch('/api/admin/registrations/auto-group', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    competitionId: 21
  })
});

// 只处理已审核的报名
const response = await fetch('/api/admin/registrations/auto-group', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    competitionId: 21,
    status: 'APPROVED'
  })
});

// 自定义参数
const response = await fetch('/api/admin/registrations/auto-group', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    competitionId: 21,
    status: 'APPROVED',
    minGroupSize: 18,
    maxGroupSize: 35,
    maxInstitutionSpread: 3
  })
});
```

## 使用流程

### 流程1: 基本使用

```
1. 用户点击"自动分组"按钮
2. 弹出确认对话框
   "确定要对当前竞赛的所有报名进行自动分组吗？
    此操作会覆盖现有的分组结果。"
3. 用户确认后，调用API
4. 显示加载状态
5. 成功后显示结果统计
6. 刷新分组列表
```

### 流程2: 高级使用

```
1. 用户点击"自动分组"按钮
2. 弹出参数配置面板
3. 用户选择竞赛、状态筛选等参数
4. 用户点击"开始分组"
5. 显示加载状态
6. 成功后显示结果统计
7. 刷新分组列表
```

## 代码示例

### Vue 3 示例

```vue
<template>
  <div>
    <el-button 
      type="primary" 
      @click="handleAutoGroup"
      :loading="loading"
    >
      {{ loading ? '分组中...' : '自动分组' }}
    </el-button>

    <!-- 参数配置对话框 -->
    <el-dialog v-model="dialogVisible" title="自动分组">
      <el-form :model="form" label-width="120px">
        <el-form-item label="竞赛">
          <el-select v-model="form.competitionId">
            <el-option 
              v-for="comp in competitions" 
              :key="comp.id" 
              :label="comp.name" 
              :value="comp.id"
            />
          </el-select>
        </el-form-item>
        
        <el-form-item label="状态筛选">
          <el-select v-model="form.status" clearable>
            <el-option label="全部" :value="null" />
            <el-option label="仅已审核" value="APPROVED" />
          </el-select>
        </el-form-item>
      </el-form>
      
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" @click="executeAutoGroup">开始分组</el-button>
      </template>
    </el-dialog>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { ElMessage, ElMessageBox } from 'element-plus';

const loading = ref(false);
const dialogVisible = ref(false);
const form = ref({
  competitionId: null,
  status: 'APPROVED'
});

const handleAutoGroup = () => {
  dialogVisible.value = true;
};

const executeAutoGroup = async () => {
  try {
    await ElMessageBox.confirm(
      '确定要执行自动分组吗？此操作会覆盖现有的分组结果。',
      '确认',
      { type: 'warning' }
    );
    
    loading.value = true;
    dialogVisible.value = false;
    
    const response = await fetch('/api/admin/registrations/auto-group', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      },
      body: JSON.stringify(form.value)
    });
    
    if (!response.ok) {
      throw new Error('自动分组失败');
    }
    
    const result = await response.json();
    
    // 统计结果
    const stats = {};
    result.forEach(item => {
      const type = item.groupType;
      if (!stats[type]) {
        stats[type] = { count: 0, groups: new Set() };
      }
      stats[type].count++;
      stats[type].groups.add(item.groupCode);
    });
    
    // 显示结果
    let message = '自动分组完成！\n';
    Object.entries(stats).forEach(([type, data]) => {
      const groupList = Array.from(data.groups).sort();
      message += `${type}: ${data.count}个项目 → ${data.groups.size}个分组\n`;
    });
    
    ElMessage.success(message);
    
    // 刷新列表
    // refreshList();
    
  } catch (error) {
    if (error !== 'cancel') {
      ElMessage.error(error.message || '自动分组失败');
    }
  } finally {
    loading.value = false;
  }
};
</script>
```

## 常见问题

### Q1: 自动分组会覆盖手动分组吗？

A: 是的，自动分组会覆盖所有项目的现有分组结果。建议在执行前提醒用户。

### Q2: 可以只对部分项目执行自动分组吗？

A: 可以通过`status`参数筛选特定状态的报名，例如只处理已审核的报名。

### Q3: 自动分组后可以手动调整吗？

A: 可以，自动分组后可以使用批量分类接口手动调整个别项目的分组。

### Q4: 如何查看分组结果？

A: 调用`GET /api/admin/registrations/grouped?competitionId={id}`接口查看分组结果。
