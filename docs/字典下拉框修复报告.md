## ✅ 修复方案

### 修改内容

**文件**: `src/main/java/com/trae/pinguan/web/DictionaryController.java`

#### 1. 导入ApiResponse

**修改前** ❌:
```java
import org.springframework.http.ResponseEntity;
```

**修改后** ✅:
```java
import com.trae.pinguan.web.dto.ApiResponse;
```

#### 2. 修改所有方法返回值

**修改前** ❌:
```java
@GetMapping("/{type}")
public ResponseEntity<List<DictionaryItem>> getByType(@PathVariable String type) {
    List<DictionaryItem> items = dictionaryService.getByType(type);
    return ResponseEntity.ok(items);  // ❌
}

@GetMapping
public ResponseEntity<List<DictionaryItem>> getAllActive() {
    List<DictionaryItem> items = dictionaryService.getAllActive();
    return ResponseEntity.ok(items);  // ❌
}

@PostMapping
public ResponseEntity<DictionaryItem> create(@Valid @RequestBody DictionaryItemRequest request) {
    DictionaryItem item = dictionaryService.create(request);
    return ResponseEntity.ok(item);  // ❌
}

@PutMapping("/{id}")
public ResponseEntity<DictionaryItem> update(@PathVariable Long id, @Valid @RequestBody DictionaryItemUpdateRequest request) {
    DictionaryItem item = dictionaryService.update(id, request);
    return ResponseEntity.ok(item);  // ❌
}

@DeleteMapping("/{id}")
public ResponseEntity<Void> delete(@PathVariable Long id) {
    dictionaryService.delete(id);
    return ResponseEntity.ok().build();  // ❌
}
```

**修改后** ✅:
```java
@GetMapping("/{type}")
public ApiResponse<List<DictionaryItem>> getByType(@PathVariable String type) {
    List<DictionaryItem> items = dictionaryService.getByType(type);
    return ApiResponse.ok(items);  // ✅
}

@GetMapping
public ApiResponse<List<DictionaryItem>> getAllActive() {
    List<DictionaryItem> items = dictionaryService.getAllActive();
    return ApiResponse.ok(items);  // ✅
}

@PostMapping
public ApiResponse<DictionaryItem> create(@Valid @RequestBody DictionaryItemRequest request) {
    DictionaryItem item = dictionaryService.create(request);
    return ApiResponse.ok(item);  // ✅
}

@PutMapping("/{id}")
public ApiResponse<DictionaryItem> update(@PathVariable Long id, @Valid @RequestBody DictionaryItemUpdateRequest request) {
    DictionaryItem item = dictionaryService.update(id, request);
    return ApiResponse.ok(item);  // ✅
}

@DeleteMapping("/{id}")
public ApiResponse<Void> delete(@PathVariable Long id) {
    dictionaryService.delete(id);
    return ApiResponse.ok(null);  // ✅
}
```

**关键改动**:
1. ✅ `ResponseEntity<T>` → `ApiResponse<T>`
2. ✅ `ResponseEntity.ok(data)` → `ApiResponse.ok(data)`
3. ✅ 统一响应格式：`{success: true, data: ...}`

## 🚀 前端集成建议

### 标准集成方式

```javascript
// 加载字典数据
async loadDictionaries() {
  try {
    const response = await axios.get('/api/dictionaries/method');
    
    // 检查响应格式
    if (response.data && response.data.success) {
      // ✅ 正确：从data字段获取数组
      this.dictionaries.methods = response.data.data;
    } else {
      console.error('加载字典失败:', response.data.message);
    }
  } catch (error) {
    console.error('请求异常:', error);
  }
}
```

### Element Plus 下拉框使用

```vue
<template>
  <el-select v-model="formData.methodCode" placeholder="请选择品管工具">
    <el-option
      v-for="item in dictionaries.methods"
      :key="item.code"
      :label="item.label"
      :value="item.code"
    />
  </el-select>
</template>

<script setup>
import { ref, onMounted } from 'vue';
import axios from 'axios';

const dictionaries = ref({
  methods: [],
  subjectTypes: [],
  experienceImproves: [],
  qualityTopics: []
});

const formData = ref({
  methodCode: '',
  subjectTypeCode: ''
});

onMounted(async () => {
  // 加载所有字典数据
  const [methodRes, subjectRes, experienceRes, qualityRes] = await Promise.all([
    axios.get('/api/dictionaries/method'),
    axios.get('/api/dictionaries/subject_type'),
    axios.get('/api/dictionaries/experience_improve'),
    axios.get('/api/dictionaries/quality_topic')
  ]);
  
  // 统一处理响应格式
  if (methodRes.data.success) {
    dictionaries.value.methods = methodRes.data.data;
  }
  if (subjectRes.data.success) {
    dictionaries.value.subjectTypes = subjectRes.data.data;
  }
  if (experienceRes.data.success) {
    dictionaries.value.experienceImproves = experienceRes.data.data;
  }
  if (qualityRes.data.success) {
    dictionaries.value.qualityTopics = qualityRes.data.data;
  }
});
</script>
```
