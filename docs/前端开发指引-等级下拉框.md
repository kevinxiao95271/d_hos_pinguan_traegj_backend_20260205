# 前端开发指引 - 机构等级下拉框

**更新日期**: 2026-02-08  
**适用场景**: 注册页面、筛选页面的机构等级选择

---

## 📋 核心要点

### 等级下拉框数据源

**推荐使用：** `GET /api/dictionaries/institution_level`

**原因：**
- ✅ 统一的字典管理
- ✅ 已修复为实际存在的等级（一级、二级、三级）
- ✅ 与其他字典（品管工具、主题类型）使用方式一致
- ✅ 便于后台统一维护

---

## 🔌 API 详情

### API 1: 获取等级字典（推荐）

**接口：** `GET /api/dictionaries/institution_level`

**请求示例：**
```javascript
fetch('http://localhost:6031/api/dictionaries/institution_level')
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });
```

**响应格式：**
```json
{
  "success": true,
  "data": [
    {
      "id": 133,
      "type": "institution_level",
      "code": "一级",
      "label": "一级",
      "status": "ACTIVE"
    },
    {
      "id": 127,
      "type": "institution_level",
      "code": "二级",
      "label": "二级",
      "status": "ACTIVE"
    },
    {
      "id": 130,
      "type": "institution_level",
      "code": "三级",
      "label": "三级",
      "status": "ACTIVE"
    }
  ],
  "message": null
}
```

**字段说明：**

| 字段 | 类型 | 说明 | 用途 |
|------|------|------|------|
| `id` | Number | 字典项ID | 内部使用，通常不需要 |
| `type` | String | 字典类型 | 固定为 "institution_level" |
| `code` | String | **等级代码** | **用于搜索和筛选** |
| `label` | String | 等级显示名称 | 用于下拉框显示（与code相同） |
| `status` | String | 状态 | ACTIVE=启用 |

## 💻 前端代码示例


### React 示例

```jsx
import React, { useState, useEffect } from 'react';
import { Select } from 'antd';

const InstitutionLevelSelect = () => {
  const [institutionLevels, setInstitutionLevels] = useState([]);
  const [selectedLevel, setSelectedLevel] = useState('');

  // 加载机构等级列表
  useEffect(() => {
    const loadInstitutionLevels = async () => {
      try {
        const response = await fetch('/api/dictionaries/institution_level');
        const data = await response.json();
        
        if (data.success) {
          setInstitutionLevels(data.data);
        } else {
          console.error('获取等级列表失败:', data.message);
        }
      } catch (error) {
        console.error('请求出错:', error);
      }
    };

    loadInstitutionLevels();
  }, []);

  return (
    <Select
      placeholder="请选择机构等级"
      value={selectedLevel}
      onChange={setSelectedLevel}
      allowClear
    >
      {institutionLevels.map(item => (
        <Select.Option key={item.code} value={item.code}>
          {item.label}
        </Select.Option>
      ))}
    </Select>
  );
};

export default InstitutionLevelSelect;
```

## 🔍 搜索机构时使用等级

### API: 机构搜索

**接口：** `POST /api/institutions/search`

**请求示例：**
```javascript
const searchInstitutions = async (level) => {
  const response = await axios.post('/api/institutions/search', {
    keyword: '',           // 机构名称关键词
    region: '',            // 地区
    level: level,          // 等级（使用 code 值）
    page: 0,               // 页码
    size: 10               // 每页数量
  });
  
  return response.data;
};

// 使用示例
searchInstitutions('二级')
  .then(data => {
    console.log('找到机构:', data.data.totalElements);
    console.log('机构列表:', data.data.content);
  });
```

**完整示例：**
```vue
<template>
  <div>
    <!-- 等级选择 -->
    <el-select 
      v-model="searchForm.level" 
      placeholder="请选择机构等级"
      clearable
    >
      <el-option
        v-for="item in institutionLevels"
        :key="item.code"
        :label="item.label"
        :value="item.code"
      />
    </el-select>

    <!-- 搜索按钮 -->
    <el-button type="primary" @click="searchInstitutions">
      搜索
    </el-button>

    <!-- 结果列表 -->
    <el-table :data="institutions" v-loading="loading">
      <el-table-column prop="name" label="机构名称" />
      <el-table-column prop="region" label="地区" />
      <el-table-column prop="level" label="等级" />
    </el-table>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import axios from 'axios'

const institutionLevels = ref([])
const institutions = ref([])
const loading = ref(false)

const searchForm = ref({
  keyword: '',
  region: '',
  level: ''  // 等级筛选

  }

      console.log('找到机构:', response.data.data.totalElements)
    }
  } catch (error) {
    console.error('搜索出错:', error)
  } finally {
    loading.value = false
  }
}

onMounted(() => {
  loadInstitutionLevels()
})
</script>
```

## 📊 数据处理建议

### 1. 缓存等级列表

等级列表不常变化，建议缓存：

```javascript
// 使用 Vuex/Pinia 缓存
// store/dictionaries.js
import { defineStore } from 'pinia'
import axios from 'axios'

export const useDictionaryStore = defineStore('dictionary', {
  state: () => ({
    institutionLevels: [],
    methods: [],
    subjectTypes: []
  }),
  
  actions: {
    async loadInstitutionLevels() {
      // 如果已加载，直接返回
      if (this.institutionLevels.length > 0) {
        return this.institutionLevels
      }
      
      const response = await axios.get('/api/dictionaries/institution_level')
      if (response.data.success) {
        this.institutionLevels = response.data.data
      }
      
      return this.institutionLevels
    }
  }
})
```

使用：
```vue
<script setup>
import { useDictionaryStore } from '@/store/dictionaries'

const dictionaryStore = useDictionaryStore()

onMounted(async () => {
  await dictionaryStore.loadInstitutionLevels()
})
</script>

    <el-option
      v-for="item in dictionaryStore.institutionLevels"
      :key="item.code"
```

### 2. 统一字典加载方法

建议创建统一的字典加载工具：

```javascript
// utils/dictionaries.js
import axios from 'axios'

// 字典类型枚举
export const DictionaryType = {
  INSTITUTION_LEVEL: 'institution_level',  // 机构等级
  METHOD: 'method',                        // 品管工具
  SUBJECT_TYPE: 'subject_type'            // 主题类型
}

// 加载字典
export const loadDictionary = async (type) => {
  try {
    const response = await axios.get(`/api/dictionaries/${type}`)
    
    if (response.data.success) {
      return response.data.data
    } else {
      console.error(`获取字典失败: ${type}`, response.data.message)
      return []
    }
  } catch (error) {
    console.error(`请求字典出错: ${type}`, error)
    return []
  }
}

// 批量加载多个字典
export const loadDictionaries = async (types) => {
  const promises = types.map(type => loadDictionary(type))
  const results = await Promise.all(promises)
  
  return types.reduce((acc, type, index) => {
    acc[type] = results[index]
    return acc
  }, {})
}
```

使用：
```javascript
import { loadDictionary, loadDictionaries, DictionaryType } from '@/utils/dictionaries'

// 单个加载
const levels = await loadDictionary(DictionaryType.INSTITUTION_LEVEL)

// 批量加载
const dictionaries = await loadDictionaries([
  DictionaryType.INSTITUTION_LEVEL,
  DictionaryType.METHOD,
  DictionaryType.SUBJECT_TYPE
])

console.log('机构等级:', dictionaries.institution_level)
console.log('品管工具:', dictionaries.method)
console.log('主题类型:', dictionaries.subject_type)
```

### ❌ 方式2: 使用 institutions/levels API

```javascript
// ❌ 不推荐（虽然可用）
const response = await axios.get('/api/institutions/levels')
const levels = response.data.data
```

**问题：**
- 这个API返回的是数据库中**实际使用**的等级
- 可能包含旧数据（如"三甲"、"未分级"等）
- 不是标准的字典格式
- 与其他下拉框（品管工具、主题类型）使用方式不统一

## ⚡ 性能优化

### 1. 使用 Promise.all 并行加载

```javascript
const loadAllDictionaries = async () => {
  const [levels, methods, subjectTypes] = await Promise.all([
    axios.get('/api/dictionaries/institution_level'),
    axios.get('/api/dictionaries/method'),
    axios.get('/api/dictionaries/subject_type')
  ])
  
  return {
    levels: levels.data.data,
    methods: methods.data.data,
    subjectTypes: subjectTypes.data.data
  }
}
```

### 2. 使用 localStorage 缓存

```javascript
const loadInstitutionLevels = async () => {
  // 尝试从缓存加载
  const cached = localStorage.getItem('institution_levels')
  if (cached) {
    const { data, timestamp } = JSON.parse(cached)
    
    // 缓存有效期1小时
    if (Date.now() - timestamp < 3600000) {
      return data
    }
  }
  
  // 从API加载
  const response = await axios.get('/api/dictionaries/institution_level')
  if (response.data.success) {
    const data = response.data.data
    
    // 缓存到 localStorage
    localStorage.setItem('institution_levels', JSON.stringify({
      data,
      timestamp: Date.now()
    }))
    
    return data
  }
}
```

## 🎯 总结

### 核心要点

1. ✅ **使用字典API**: `GET /api/dictionaries/institution_level`
2. ✅ **使用 code 值**: 下拉框绑定 `code`，搜索时传 `code`
3. ✅ **统一管理**: 与品管工具、主题类型等其他字典统一处理
4. ✅ **缓存优化**: 字典数据不常变化，建议缓存

### API清单

| API | 用途 | 返回格式 |
|-----|------|---------|
| `GET /api/dictionaries/institution_level` | 获取等级列表 | 字典格式 ✅ |
| `POST /api/institutions/search` | 搜索机构 | 分页结果 |
| `GET /api/institutions/cities` | 获取城市列表 | 数组 |

### 当前可用等级

- **一级** - 223个机构
- **二级** - 253个机构
- **三级** - 164个机构
