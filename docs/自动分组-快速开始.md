# 自动分组功能 - 快速开始

## 5分钟快速上手

### 1. 基本使用

最简单的方式，使用默认参数：

```bash
curl -X POST http://localhost:8080/api/admin/registrations/auto-group \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"competitionId": 21}'
```

### 2. 只处理已审核的报名

```bash
curl -X POST http://localhost:8080/api/admin/registrations/auto-group \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "competitionId": 21,
    "status": "APPROVED"
  }'
```

### 3. 查看分组结果

```bash
curl -X GET "http://localhost:8080/api/admin/registrations/grouped?competitionId=21" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 核心特点

| 特点 | 说明 |
|------|------|
| 🎯 智能分组 | 自动计算最优分组数量 |
| 🏥 机构集中 | 同机构项目集中在1-2个分组 |
| ⚖️ 负载均衡 | 各分组项目数量保持均衡（20-31个） |
| 📊 组别独立 | 基层组/综合组/进阶组分别处理 |
| ⚙️ 参数可配 | 支持自定义约束条件 |

## 默认参数

```json
{
  "minGroupSize": 20,           // 最小分组大小
  "maxGroupSize": 31,           // 最大分组大小
  "maxStdDev": 2.5,            // 标准差上限
  "maxInstitutionSpread": 2    // 同机构最多散落分组数
}
```

## 分组规则

### 组别前缀

| 组别 | 前缀 | 示例 |
|------|------|------|
| 基层组 | A | A1, A2, A3... |
| 综合组 | B | B1, B2, B3... |
| 进阶组 | C | C1, C2, C3... |

### 机构散落规则

- ✅ 优选: 1-2个分组（符合92.9%历史数据）
- ⚠️ 可接受: 3个分组
- ❌ 避免: 4个以上分组

### 分组大小规则

- 最小: 20个项目
- 最大: 31个项目
- 标准差: ≤2.5

## 前端集成

### Vue 3 最简示例

```vue
<template>
  <el-button @click="autoGroup" :loading="loading">
    自动分组
  </el-button>
</template>

<script setup>
import { ref } from 'vue';
import { ElMessage } from 'element-plus';

const loading = ref(false);

const autoGroup = async () => {
  try {
    loading.value = true;
    
    const response = await fetch('/api/admin/registrations/auto-group', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      },
      body: JSON.stringify({
        competitionId: 21,
        status: 'APPROVED'
      })
    });
    
    if (!response.ok) throw new Error('分组失败');
    
    ElMessage.success('自动分组完成！');
    
  } catch (error) {
    ElMessage.error(error.message);
  } finally {
    loading.value = false;
  }
};
</script>
```

### React 最简示例

```jsx
import { useState } from 'react';
import { Button, message } from 'antd';

const AutoGroupButton = () => {
  const [loading, setLoading] = useState(false);

  const autoGroup = async () => {
    try {
      setLoading(true);
      
      const response = await fetch('/api/admin/registrations/auto-group', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${localStorage.getItem('token')}`
        },
        body: JSON.stringify({
          competitionId: 21,
          status: 'APPROVED'
        })
      });
      
      if (!response.ok) throw new Error('分组失败');
      
      message.success('自动分组完成！');
      
    } catch (error) {
      message.error(error.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <Button type="primary" onClick={autoGroup} loading={loading}>
      自动分组
    </Button>
  );
};
```

## 注意事项

1. ⚠️ **权限要求**: 需要OPS或COMMITTEE_ADMIN权限
2. ⚠️ **覆盖警告**: 会覆盖现有分组结果，建议执行前提醒用户
3. ⚠️ **时机选择**: 建议在报名截止后执行
4. ✅ **可重复执行**: 可以多次执行调整结果
5. ✅ **可手动调整**: 自动分组后可以手动调整个别项目

## 故障排查

### 问题1: 401 Unauthorized

**原因**: Token过期或无效

**解决**: 重新登录获取新Token

### 问题2: 403 Forbidden

**原因**: 权限不足

**解决**: 确保用户有OPS或COMMITTEE_ADMIN权限

### 问题3: 分组结果不理想

**原因**: 默认参数不适合当前数据

**解决**: 调整参数，例如增加`maxInstitutionSpread`

```json
{
  "competitionId": 21,
  "maxInstitutionSpread": 3
}
```
