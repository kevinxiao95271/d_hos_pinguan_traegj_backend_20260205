## 💡 前端实现最佳实践

### 方案: 分步选择 + 智能搜索

```vue
<template>
  <div class="institution-selector">
    <!-- 步骤1: 最近使用（优先展示） -->
    <div v-if="recentInstitutions.length" class="recent">
      <h4>最近使用</h4>
      <el-tag 
        v-for="inst in recentInstitutions" 
        :key="inst.id"
        @click="selectInstitution(inst)"
        class="recent-tag">
        {{ inst.name }}
      </el-tag>
    </div>
    
    <!-- 步骤2: 热门地区（快速筛选） -->
    <div class="regions">
      <h4>选择地区</h4>
      <el-button 
        v-for="item in hotRegions" 
        :key="item.region"
        @click="selectRegion(item.region)"
        :type="selectedRegion === item.region ? 'primary' : 'default'"
        size="small">
        {{ item.region }} ({{ item.count }})
      </el-button>
    </div>
    
    <!-- 步骤3: 搜索框（实时搜索） -->
    <el-input
      v-model="searchKeyword"
      @input="debounceSearch"
      placeholder="输入机构名称搜索"
      clearable
      prefix-icon="el-icon-search">
    </el-input>
    
    <!-- 步骤4: 结果列表（虚拟滚动） -->
    <div class="results" v-loading="loading">
      <virtual-scroller
        :items="institutions"
        :item-height="60"
        class="scroller"
        @scroll-end="loadMore">
        <template #default="{ item }">
          <div 
            @click="selectInstitution(item)" 
            class="institution-item">
            <div class="name">{{ item.name }}</div>
            <div class="meta">
              <span class="region">📍 {{ item.region }}</span>
              <span v-if="item.level" class="level">🏥 {{ item.level }}</span>
            </div>
          </div>
        </template>
      </virtual-scroller>
      
      <!-- 加载更多提示 -->
      <div v-if="hasMore && !loading" class="load-more">
        向下滚动加载更多...
      </div>
    </div>
  </div>
</template>

<script>
import { debounce } from 'lodash';
import { VirtualScroller } from 'vue-virtual-scroller';

export default {
  components: { VirtualScroller },
  
  data() {
    return {
      selectedRegion: null,
      searchKeyword: '',
      hotRegions: [],
      recentInstitutions: [],
      institutions: [],
      page: 0,
      loading: false,
      hasMore: true
    };
  },
  
  methods: {
    // 加载热门地区
    async loadHotRegions() {
      const res = await this.$http.get('/api/institutions/hot-regions?limit=10');
      this.hotRegions = res.data.data;
    },
    
    // 选择地区
    async selectRegion(region) {
      this.selectedRegion = region;
      this.searchKeyword = '';
      this.page = 0;
      this.institutions = [];
      await this.searchInstitutions();
    },
    
    // 搜索（带防抖）
    debounceSearch: debounce(async function() {
      this.page = 0;
      this.institutions = [];
      await this.searchInstitutions();
    }, 500),
    
    // 执行搜索
    async searchInstitutions() {
      if (this.loading) return;
      
      // 最少2个字符才搜索（除非已选地区）
      if (!this.selectedRegion && this.searchKeyword.length < 2) {
        return;
      }
      
      this.loading = true;
      try {
        const res = await this.$http.post('/api/institutions/search', {
          keyword: this.searchKeyword || null,
          region: this.selectedRegion || null,
          page: this.page,
          size: 20
        });
        
        const data = res.data.data;
        
        if (this.page === 0) {
          this.institutions = data.content;
        } else {
          this.institutions.push(...data.content);
        }
        
        this.hasMore = !data.last;
      } finally {
        this.loading = false;
      }
    },
    
    // 加载更多
    async loadMore() {
      if (!this.hasMore || this.loading) return;
      this.page++;
      await this.searchInstitutions();
    },
    
    // 选择机构
    selectInstitution(institution) {
      // 保存到最近使用
      this.saveToRecent(institution);
      
      // 触发选择事件
      this.$emit('select', institution);
      
      // 进入报名流程...
      this.$router.push({
        name: 'registration',
        params: { institutionId: institution.id }
      });
    },
    
    // 保存最近使用
    saveToRecent(institution) {
      let recent = JSON.parse(localStorage.getItem('recent_institutions') || '[]');
      recent = recent.filter(item => item.id !== institution.id);
      recent.unshift(institution);
      recent = recent.slice(0, 5);
      localStorage.setItem('recent_institutions', JSON.stringify(recent));
    },
    
    // 获取最近使用
    getRecentInstitutions() {
      return JSON.parse(localStorage.getItem('recent_institutions') || '[]');
    }
  },
  
  mounted() {
    // 加载初始数据
    this.recentInstitutions = this.getRecentInstitutions();
    this.loadHotRegions();
    
    // 如果没有最近使用，自动加载一些数据
    if (this.recentInstitutions.length === 0) {
      this.searchInstitutions();
    }
  }
};
</script>

<style scoped>

  max-width: 600px;
  margin: 20px auto;
}

.recent, .regions {
  margin-bottom: 20px;
}

.recent-tag, .region-button {
  margin: 5px;
  cursor: pointer;
}

.scroller {
  height: 500px;
  border: 1px solid #ddd;
  border-radius: 4px;

}

  border-bottom: 1px solid #f0f0f0;
  cursor: pointer;

}

}

.name {

  color: #909399;
}
</style>
```

## 💻 代码示例

### JavaScript/Fetch

```javascript
// 1. 搜索机构
async function searchInstitutions(keyword, region) {
  const response = await fetch('http://localhost:6031/api/institutions/search', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({
      keyword: keyword,
      region: region,
      page: 0,
      size: 20
    })
  });
  
  const result = await response.json();
  return result.data.content; // 返回机构列表
}

// 2. 自动完成
async function autocomplete(prefix) {
  const response = await fetch(
    `http://localhost:6031/api/institutions/autocomplete?prefix=${prefix}`,
    {
      headers: { 'Authorization': `Bearer ${token}` }
    }
  );
  
  const result = await response.json();
  return result.data; // 返回建议列表
}

// 3. 热门地区
async function getHotRegions() {
  const response = await fetch(
    'http://localhost:6031/api/institutions/hot-regions?limit=10',
    {
      headers: { 'Authorization': `Bearer ${token}` }
    }
  );
  
  const result = await response.json();
  return result.data; // 返回热门地区
}

// 4. 用户注册
async function register(userData) {
  const response = await fetch('http://localhost:6031/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      phone: userData.phone,
      name: userData.name,
      title: userData.title,
      role: 'CONTESTANT',
      institutionId: userData.institutionId
    })
  });
  
  const result = await response.json();
  if (result.success) {
    // 保存Token
    localStorage.setItem('token', result.data.token);
    // 进入报名流程
    window.location.href = '/registration';
  }
}
```

## ⚠️ 注意事项

### 前端开发

1. **必须防抖**: 用户输入时延迟500ms
2. **最少字符**: 至少2个字符才搜索
3. **取消请求**: 新请求时取消旧请求
4. **loading状态**: 显示加载动画
5. **错误处理**: 网络失败时重试

### 性能建议

1. **优先地区**: 先让用户选地区，缩小范围
2. **虚拟滚动**: 列表超过100条时使用
3. **本地缓存**: 缓存查询结果30分钟
4. **最近使用**: 优先展示最近5个
5. **分页加载**: 每次只加载20条

### API调用

1. **不要**调用 `GET /api/institutions` （返回全部36K+）
2. **推荐**使用 `POST /api/institutions/search` （分页）
3. **必须**传递Token认证
4. **建议**设置合理的size参数（10-50）

## 🐛 故障排查

### 服务无法启动

**症状**: Maven启动失败，NullPointerException  
**原因**: 数据库配置未正确读取

**解决方法**:
1. 检查环境变量是否设置
2. 或直接修改 `application.yml`
3. 确保在同一Shell会话中设置变量和启动服务

### 查询太慢

**症状**: 接口响应时间 > 1秒  
**原因**: 可能缺少索引

**解决**:
```bash
python scripts/add_indexes.py
```

### 搜索无结果

**症状**: 明明有数据但搜索不到  
**原因**: 关键词匹配问题

**解决**:
1. 检查是否有空格
2. 尝试简化关键词
3. 先选择地区再搜索
