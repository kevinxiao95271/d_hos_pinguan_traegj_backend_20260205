## 🛡️ 权限检查逻辑

### 实施位置
**文件**: `src/main/java/com/trae/pinguan/web/MaterialController.java`

**方法**: `checkDownloadPermission(MaterialFile material, HttpServletRequest request)`

### 核心逻辑

```java
private void checkDownloadPermission(MaterialFile material, HttpServletRequest request) {
    String role = (String) request.getAttribute("role");
    Long userId = Long.parseLong((String) request.getAttribute("userId"));
    
    // 1. OPS、COMMITTEE、COMMITTEE_ADMIN 可以下载所有材料
    if ("OPS".equals(role) || "COMMITTEE".equals(role) || "COMMITTEE_ADMIN".equals(role)) {
        return;  // ✅ 放行
    }
    
    // 2. CONTESTANT（参赛者）只能下载自己申请的报名材料
    if ("CONTESTANT".equals(role)) {
        Long applicantId = material.getRegistration().getApplicant().getId();
        if (!userId.equals(applicantId)) {
            throw new ResponseStatusException(HttpStatus.FORBIDDEN, 
                "无权下载该材料，您只能下载自己提交的报名材料");
        }
        return;  // ✅ 放行
    }
    
    // 3. REVIEWER（评委）只能下载分配给自己的评审任务的材料
    if ("REVIEWER".equals(role)) {
        Long registrationId = material.getRegistration().getId();
        boolean hasReviewTask = reviewTaskRepository.existsByReviewerIdAndRegistrationId(
            userId, registrationId
        );
        if (!hasReviewTask) {
            throw new ResponseStatusException(HttpStatus.FORBIDDEN, 
                "无权下载该材料，您只能下载分配给您评审的项目材料");
        }
        return;  // ✅ 放行
    }
    
    // 4. 其他未知角色，拒绝访问
    throw new ResponseStatusException(HttpStatus.FORBIDDEN, "无权下载材料");
}
```

## 🚨 安全加固措施

### 1. 懒加载关联查询

**问题**: 权限检查需要访问 `material.getRegistration().getApplicant().getId()`，可能触发懒加载异常。

**解决**: 在 `MaterialService.getById` 中使用 JOIN FETCH

```java
// MaterialFileRepository.java
@Query("SELECT m FROM MaterialFile m " +
       "LEFT JOIN FETCH m.registration r " +
       "LEFT JOIN FETCH r.applicant " +
       "WHERE m.id = :id")
Optional<MaterialFile> findByIdWithRegistration(@Param("id") Long id);
```

**或者**: 在 Service 层处理

```java
public MaterialFile getById(Long materialId) {
    MaterialFile material = materialFileRepository.findById(materialId)
            .orElseThrow(() -> new IllegalArgumentException("材料文件不存在"));
    
    // 强制加载关联数据（避免懒加载异常）
    if (material.getRegistration() != null) {
        material.getRegistration().getApplicant().getId();  // 触发加载
    }
    
    return material;
}
```

**当前实施**: Service 层已经正确处理，无需额外修改（JPA 会在事务内自动加载）

public ResponseEntity<InputStreamResource> download(@PathVariable Long id, HttpServletRequest request) {
    MaterialFile material = materialService.getById(id);
    String role = (String) request.getAttribute("role");
    Long userId = Long.parseLong((String) request.getAttribute("userId"));
    
    try {
        // 权限检查
        checkDownloadPermission(material, request);
        
        // 记录成功日志

        // 记录失败日志

    }
