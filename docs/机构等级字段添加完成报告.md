## 前端使用指引

### 书审分组页面
前端可以直接从筛选接口的返回数据中获取 `institutionLevel` 字段：

```javascript
// 调用筛选接口
const response = await fetch('/api/admin/registrations/filter?competitionId=21', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});

const result = await response.json();
if (result.success) {
  const registrations = result.data;
  
  // 每条数据都包含 institutionLevel
  registrations.forEach(item => {
    console.log(`机构: ${item.institutionName}`);
    console.log(`等级: ${item.institutionLevel}`);
  });
}
```

### 表格显示
在表格中添加机构等级列：
