核心变更
================================================================================

API: GET /api/reviews/tasks/stage

新增字段: reviewerTitle（评委职称）

返回示例:
{
  "reviewerId": 6,
  "reviewerName": "李明华",
  "reviewerTitle": "主任医师",          ⬅️ ⭐ 新增
  "reviewerInstitutionName": "浙江省中医院"
}

================================================================================
空值处理
================================================================================

如果评委未填写职称，字段返回 null

建议显示:

Vue:  {{ task.reviewerTitle || '未填写' }}
React: {task.reviewerTitle || '未填写'}
