## 二、API详细分析

### 2.1 评分排名列表（书审/面谈/决赛）

#### 当前实现

```java
@GetMapping("/rankings")
@Operation(summary = "后台评分排名")
public ApiResponse<List<ReviewRankingItem>> rankings(
    @RequestParam Long competitionId,
    @RequestParam ReviewStage stage,
    @RequestParam(required = false) GroupType groupType) {
    return ApiResponse.ok(reviewService.rankingByStage(competitionId, stage, groupType));
}
```

#### 问题分析

- ❌ **无分页参数**: 没有 `page` 和 `size` 参数
- ❌ **返回全量数据**: 返回所有匹配的项目
- ⚠️ **潜在性能问题**: 大赛事可能有数百个项目

#### 数据量预估

| 赛事规模 | 项目数 | 返回数据量 | 查询时间 | 传输时间 |
|---------|-------|-----------|---------|---------|
| 小型 | 50-100 | ~50KB | ~100ms | ~50ms |
| 中型 | 200-500 | ~250KB | ~300ms | ~150ms |
| 大型 | 1000+ | ~1MB | ~800ms | ~500ms |

#### 影响的功能

1. **书审评分列表** (`stage=BOOK`)
   - 管理员查看所有书审项目的评分情况
   - 需要分组、排序、筛选功能

2. **面谈评分列表** (`stage=INTERVIEW`)
   - 管理员查看面谈阶段项目评分
   - 通常数量较少（入围项目）

3. **决赛评分列表** (`stage=FINAL`)
   - 管理员查看决赛阶段评分
   - 数量最少（决赛项目）

#### 建议方案

**方案A：完全兼容分页**（推荐）

```java
@GetMapping("/rankings")
public ApiResponse<?> rankings(
    @RequestParam Long competitionId,
    @RequestParam ReviewStage stage,
    @RequestParam(required = false) GroupType groupType,
    @RequestParam(required = false) Integer page,      // ⭐ 新增
    @RequestParam(required = false) Integer size) {    // ⭐ 新增
    
    if (page == null) {
        // 不分页（兼容旧版）
        return ApiResponse.ok(reviewService.rankingByStage(...));
    }
    
    // 分页查询
    return ApiResponse.ok(reviewService.rankingByStageWithPagination(..., page, size));
}
```

**改动量**: 中等（需要修改Service和Repository）

### 2.2 入围管理 - 项目列表

#### 当前实现

```java
@GetMapping("/shortlist")
@Operation(summary = "后台入围名单")
public ApiResponse<List<ReviewRankingItem>> shortlist(
    @RequestParam Long competitionId,
    @RequestParam ReviewStage stage,
    @RequestParam(required = false) GroupType groupType,
    @RequestParam(required = false) Integer limit,          // 只有limit
    @RequestParam(required = false) Double minAvgTotal) {
    
    int size = limit == null ? 10 : Math.max(1, limit);
    List<ReviewRankingItem> rankings = reviewService.rankingByStage(...);
    return ApiResponse.ok(rankings.stream()
            .filter(item -> minAvgTotal == null || item.getAvgTotal() >= minAvgTotal)
            .limit(size)  // 只返回前N名
            .collect(Collectors.toList()));
}
```

#### 问题分析

- ✅ **有limit参数**: 可以控制返回数量
- ❌ **无分页功能**: 无法查看"后续"的项目
- ❌ **无totalCount**: 不知道总共有多少项目
- ⚠️ **内存过滤**: 先查全部数据，再在内存中过滤（效率低）

#### 使用场景

1. **入围名单查看**
   - 查看前N名入围项目
   - 通常N=10-50

2. **入围线设置**
   - 根据分数线筛选
   - 需要知道总数

#### 建议方案

**方案B：扩展为完整分页**

```java
@GetMapping("/shortlist")
public ApiResponse<?> shortlist(
    @RequestParam Long competitionId,
    @RequestParam ReviewStage stage,
    @RequestParam(required = false) GroupType groupType,
    @RequestParam(required = false) Integer limit,          // 保留（兼容）
    @RequestParam(required = false) Double minAvgTotal,
    @RequestParam(required = false) Integer page,           // ⭐ 新增
    @RequestParam(required = false) Integer size) {         // ⭐ 新增
    
    // 优先使用page/size，其次使用limit
    if (page != null) {
        return ApiResponse.ok(reviewService.shortlistWithPagination(..., page, size, minAvgTotal));
    }
    
    // 旧逻辑（使用limit）
    int limitSize = limit == null ? 10 : Math.max(1, limit);
    // ...
}
```

**改动量**: 中等

### 2.3 机构管理 - 机构列表

#### 当前实现

```java
@GetMapping("/export")
@Operation(summary = "导出机构列表")
public ApiResponse<List<Institution>> export(
    @RequestParam(required = false, defaultValue = "false") Boolean unknownRegionOnly) {
    
    List<Institution> all = institutionService.listAll();
    
    if (unknownRegionOnly != null && unknownRegionOnly) {
        return ApiResponse.ok(all.stream()
                .filter(inst -> inst.getRegion() == null || inst.getRegion().trim().isEmpty())
                .collect(Collectors.toList()));
    }
    
    return ApiResponse.ok(all);
}
```

#### 问题分析

- ❌ **无分页参数**: 返回所有机构
- ❌ **无筛选功能**: 只支持"未知地区"筛选
- ⚠️ **API命名问题**: 叫"export"但实际是查询

#### 数据量预估

| 机构数量 | 数据量 | 查询时间 |
|---------|-------|---------|
| 100-200 | ~100KB | ~50ms |
| 500-1000 | ~500KB | ~200ms |

#### 影响评估

- 🟢 **优先级较低**: 机构数量通常不多（数百个）
- 🟢 **性能尚可**: 目前性能问题不明显
- 🟡 **建议优化**: 为未来扩展做准备

#### 建议方案

**方案C：重构为标准API**

```java
// 新增：机构列表查询（支持分页和筛选）
@GetMapping
@Operation(summary = "机构列表")
public ApiResponse<?> list(
    @RequestParam(required = false) String region,         // 地区筛选
    @RequestParam(required = false) String level,          // 等级筛选
    @RequestParam(required = false) String name,           // 名称搜索
    @RequestParam(required = false) Integer page,
    @RequestParam(required = false) Integer size) {
    
    if (page == null) {
        return ApiResponse.ok(institutionService.listAll());
    }
    
    return ApiResponse.ok(institutionService.listWithPagination(region, level, name, page, size));
}

// 保留：导出功能（向后兼容）
@GetMapping("/export")
@Deprecated
public ApiResponse<List<Institution>> export(...) {
    // 保持原有逻辑
}
```

**改动量**: 较大（新增API）
