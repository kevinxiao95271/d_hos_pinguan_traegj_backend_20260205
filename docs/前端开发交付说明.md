## 4个应用场景

### 场景1: 参赛者 - 我的报名

**页面路径**: `/contestant/my-registrations` → 详情

**数据流程**:
1. 获取报名列表: `GET /api/registrations/my`
2. 点击详情: `GET /api/registrations/{id}`

**显示内容**:
- 基本信息
- 机构信息
- 活动说明（10个字段）
- 项目摘要（7个字段）
- 团队成员
- 材料附件

2. 点击项目详情: `GET /api/registrations/{id}`

**显示内容**: 与场景1相同

## 前端开发要点

### 1. 活动说明字段（10个）

```javascript
// 必须显示的字段
activityInfo: {
  theme,              // 活动主题
  keywords,           // 关键词
  subjectTypeCode,    // 主题类型代码
  subjectTypeLabel,   // 主题类型标签
  methodCode,         // 运用手法代码
  methodLabel,        // 运用手法标签
  experienceImproveCode,  // 改善就医环境代码
  qualityTopicCode,       // 医疗质量主题代码
  avgWorkYears,       // 平均工作年限
  avgAge,             // 平均年龄
  crossDepartment,    // 是否跨部门 (Boolean)
  relatedToDigitalAi  // 是否与数字化/AI相关 (Boolean) ← NEW!
}
```

### 2. 项目摘要字段（7个）

```javascript
// 必须显示的字段
projectSummary: {
  theme,        // 主题
  plan,         // 计划
  problem,      // 问题结构与对策措施探讨
  action,       // 对策行动过程
  success,      // 成果表现
  discussion,   // 讨论总结
  operation,    // 运作 ← NEW!
  presentation  // 展示 ← NEW!
}
```

### 3. 显示规则

#### Boolean字段
```javascript
// crossDepartment 和 relatedToDigitalAi
<el-tag :type="value ? 'success' : 'info'">
  {{ value ? '是' : '否' }}
</el-tag>
```

#### 数字字段
```javascript
// avgWorkYears
{{ activityInfo.avgWorkYears }} 年

// avgAge
{{ activityInfo.avgAge }} 岁
```

#### 字典字段
```javascript
// 优先显示Label，如果有Other则追加
{{ activityInfo.methodLabel || activityInfo.methodCode }}
<span v-if="activityInfo.methodOther">
  （{{ activityInfo.methodOther }}）
</span>
```

#### 长文本字段
```css
.summary-item p {
  white-space: pre-wrap;  /* 保留换行 */
  word-break: break-word; /* 自动换行 */
  line-height: 1.8;
}
```

#### 空值处理
```javascript
// activityInfo 为 null
<el-empty v-if="!detail.activityInfo" description="暂无活动说明" />

// projectSummary 为 null
<el-empty v-if="!detail.projectSummary" description="暂无项目摘要" />

// operation 或 presentation 为 null
{{ detail.projectSummary.operation || '未填写' }}
```

## 常见问题

### Q1: relatedToDigitalAi 显示为 null？

**A**: 需要执行 `add_digital_ai_field.sql` 并重启应用。

### Q2: operation 和 presentation 显示为 null？

**A**: 这是正常的，旧数据可能为空。前端需要显示"未填写"。

### Q3: 字典标签显示为 code？

**A**: 后端已经返回了 Label 字段（如 `methodLabel`），优先使用Label。

### Q4: 如何获取字典数据？

**A**: 调用 `/api/dictionary/experience_improve` 和 `/api/dictionary/quality_topic`。
