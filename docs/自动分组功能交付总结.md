## 功能概述

实现了智能自动分组算法，用于将竞赛报名项目自动分配到不同的细分组（A1/A2/B1/B2/C1/C2等），满足以下核心需求：

1. ✅ 同机构项目集中在1-2个分组（最多3个）
2. ✅ 分组大小均衡（20-31个项目，标准差≤2.5）
3. ✅ 按组别独立处理（基层组/综合组/进阶组）
4. ✅ 智能计算最优分组数量

## 算法设计依据

### 历史数据分析

基于2024-2025年历史数据（1818条记录）：

| 指标 | 数值 | 说明 |
|------|------|------|
| 机构项目数分布 | 56.7%机构报1-3个项目<br>43.2%机构报4-8个项目 | 大部分机构项目数较少 |
| 组别分布 | 基层组25%<br>综合组65%<br>进阶组10% | 综合组占主导 |
| 多项目负责人 | 1.5%负责人提交多个项目 | 极少数情况 |
| 项目分组特征 | 92.9%分布在2个细分组<br>78.6%在同一大类内 | 优先保持同一大类 |

### 核心约束条件

1. **机构散落限制**
   - 优选: 1-2个分组
   - 可接受: 3个分组
   - 避免: 4个以上分组

2. **分组大小限制**
   - 最小: 20个项目
   - 最大: 31个项目
   - 标准差: ≤2.5

3. **组别独立性**
   - 基层组(A)、综合组(B)、进阶组(C)分别独立处理

## 算法流程

### 1. 数据准备

```
获取待分组报名 → 按groupType分组 → 对每个groupType独立处理
```

### 2. 分组前缀确定

| 组别 | groupType | 前缀 |
|------|-----------|------|
| 基层组 | BASIC | A |
| 综合组 | COMPREHENSIVE | B |
| 进阶组 | ADVANCED | C |

### 3. 最优分组数计算

```
目标大小 = (minSize + maxSize) / 2
初始分组数 = (总项目数 + 目标大小 - 1) / 目标大小
最终分组数 = 在[最小分组数, 最大分组数]范围内调整
```

### 4. 机构项目分配

```
1. 按机构项目数降序排序（大机构优先）
2. 确定每个机构需要占用的分组数
3. 找到当前最空的N个桶
4. 将机构项目均匀分配到这N个桶
5. 分配group_code
```

## 算法特点

### 优点

1. ✅ **智能桶数计算**: 根据项目总数自动计算最优分组数量
2. ✅ **机构项目集中**: 同机构项目优先集中在1-2个分组
3. ✅ **负载均衡**: 使用最小负载优先策略，保持各分组均衡
4. ✅ **组别独立**: 基层组/综合组/进阶组分别独立处理
5. ✅ **参数可配置**: 支持自定义分组大小、散落限制等参数
