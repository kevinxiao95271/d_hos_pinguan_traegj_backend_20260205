## 使用示例

### Python示例
```python
import requests

# 登录
response = requests.post(
    'http://localhost:6031/api/auth/login',
    json={
        'phone': '13800002569',
        'name': '孙丽娟',
        'role': 'REVIEWER'
    }
)

token = response.json()['data']['token']

# 查询任务
headers = {'Authorization': f'Bearer {token}'}
response = requests.get(
    'http://localhost:6031/api/reviews/my-tasks',
    headers=headers
)

tasks = response.json()['data']
print(f"共有 {len(tasks)} 个评审任务")
```

### JavaScript示例
```javascript
// 登录
const loginResponse = await fetch('http://localhost:6031/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    phone: '13800002569',
    name: '孙丽娟',
    role: 'REVIEWER'
  })
});

const { data } = await loginResponse.json();
const token = data.token;

// 查询任务
const tasksResponse = await fetch('http://localhost:6031/api/reviews/my-tasks', {
  headers: { 'Authorization': `Bearer ${token}` }
});

const { data: tasks } = await tasksResponse.json();
console.log(`共有 ${tasks.length} 个评审任务`);
```

1. **手机号已混淆**

   - 无法反推原始号码

2. **Token有效期**
   - 默认有效期: 24小时（1440分钟）

3. **权限范围**
