## 🗂️ 数据结构

### 表结构
```sql
institutions
├── id (bigint, PK, AUTO_INCREMENT)
├── name (varchar(200), NOT NULL)
├── code (varchar(64), NOT NULL, UNIQUE)
├── uscc (varchar(32), NOT NULL, UNIQUE)
├── region (varchar(64), NULL)
├── level (varchar(32), NULL)
└── created_at (datetime(6), NOT NULL)
```

### 字段说明
- **id**: 自动生成的主键
- **name**: 机构名称（200字符）
- **code**: 机构代码，格式：INST_XXXXXXXX（系统生成的唯一标识）
- **uscc**: 统一社会信用代码（15-18位，唯一）
- **region**: 所属地区（如：杭州市、温州市）
- **level**: 机构等级（三甲、二甲、三乙、二乙、未定等等）
- **created_at**: 创建时间
