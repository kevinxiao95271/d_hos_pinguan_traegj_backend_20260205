### 第2步：清理Git历史（可选但推荐）

虽然已经从当前版本移除，但Git历史中仍包含敏感信息。

#### 方法1：使用 git filter-branch（内置）

```powershell
# 运行清理脚本
.\scripts\clean_git_history.ps1
```

或手动执行：

```bash
# 从历史中删除 application.yml
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch src/main/resources/application.yml" \
  --prune-empty --tag-name-filter cat -- --all

# 清理引用
git for-each-ref --format="delete %(refname)" refs/original | git update-ref --stdin
git reflog expire --expire=now --all
git gc --prune=now --aggressive

# 强制推送
git push --force --all
```

#### 方法2：使用 BFG Repo-Cleaner（更快）

```bash
# 下载 BFG
# https://rtyley.github.io/bfg-repo-cleaner/

# 创建密码替换文件
echo "Yiguo9527_" > passwords.txt

# 运行清理
java -jar bfg.jar --replace-text passwords.txt

# 清理和推送
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force --all
```
