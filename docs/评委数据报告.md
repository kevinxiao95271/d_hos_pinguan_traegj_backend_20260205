## API访问信息

### 评委列表接口

**路径:** `GET /api/admin/reviewers`

**权限:** COMMITTEE, COMMITTEE_ADMIN, OPS

**查询参数:**
- `institutionId` (可选): 按机构ID筛选
- `reviewerGroupCode` (可选): 按初审分组筛选
- `interviewGroupCode` (可选): 按终审分组筛选
- `expertBackground` (可选): 按专家背景筛选

**示例:**
```bash
# 获取所有评委
curl -H 'Authorization: Bearer <token>' http://localhost:6031/api/admin/reviewers

# 按管理背景筛选
curl -H 'Authorization: Bearer <token>' 'http://localhost:6031/api/admin/reviewers?expertBackground=管理'
```
