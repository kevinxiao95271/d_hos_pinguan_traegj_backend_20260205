================================================================================
                        书审得分功能 - 快速参考
================================================================================

【核心功能】
评委对分配给自己的报名项目进行评分

【需要的API（4个）】

1. GET /api/reviews/my-tasks
   → 获取我的评审任务列表
   → 返回：任务ID、报名ID、项目名、状态等

2. GET /api/registrations/{registrationId}
   → 查看报名完整信息
   → 返回：项目详情、成员、活动说明、总结等

3. POST /api/reviews/scores ⭐ 核心
   → 提交评分
   → 参数：
     {
       "reviewTaskId": 101,
       "scores": {
         "theme": 90,      // 主题选择 (0-100)
         "process": 85,    // 活动过程 (0-100)
         "method": 88,     // 改进方法 (0-100)
         "result": 92,     // 成果效果 (0-100)
         "innovation": 87  // 创新亮点 (0-100)
       },
       "comments": "综合评价（必填）",
       "suggestions": "改进建议（选填）"
     }

4. GET /api/reviews/scores/{reviewTaskId}
   → 查看已提交的评分
   → 返回：评分详情（只读）

================================================================================

【评分标准】

维度            权重    满分    说明
------------------------------------------------------------
theme           20%     100     主题选择（重要性、针对性）
process         20%     100     活动过程（PDCA完整性）
method          20%     100     改进方法（科学性、创新性）
result          25%     100     成果效果（量化指标、持续性）
innovation      15%     100     创新亮点（特色、可推广性）

总分计算公式:
总分 = theme×0.2 + process×0.2 + method×0.2 + result×0.25 + innovation×0.15

================================================================================

【前端页面（3个）】

1. 任务列表页 /reviewer/tasks
   - 展示所有评审任务
   - 筛选：阶段、状态
   - 操作：去评审、查看评分

2. 评审打分页 /reviewer/review/:taskId/:registrationId ⭐ 核心
   - 展示项目完整信息（只读）
   - 5个评分项（滑块 0-100）
   - 实时计算总分
   - 综合评价（必填，textarea）
   - 改进建议（选填，textarea）
   - 提交按钮

3. 评分详情页 /reviewer/score/:taskId
   - 展示已提交的评分（只读）
   - 各项得分（进度条）
   - 评审意见

【关键代码示例】

// 1. 计算总分
computed: {
  totalScore() {
    const s = this.scores;
    return (s.theme * 0.2 + s.process * 0.2 + s.method * 0.2 + 
            s.result * 0.25 + s.innovation * 0.15).toFixed(1);
  }
}

// 2. 提交评分
async submitScore() {
  const response = await fetch('/api/reviews/scores', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(this.scoreForm)
  });
  
  if (response.ok) {
    this.$message.success('评分提交成功！');
    this.$router.push('/reviewer/tasks');
  }
}

// 3. 滑块组件
<Slider 
  v-model="scoreForm.scores.theme" 
  :min="0" 
  :max="100" 
  show-input/>

【注意事项】

1. 评分范围：每项0-100分
2. 综合评价：必填，至少10个字
3. 改进建议：选填，最多500字
4. 提交后任务状态变为 COMPLETED
5. 已提交的评分不能修改（只读）
6. 需要完整的项目信息才能打分
