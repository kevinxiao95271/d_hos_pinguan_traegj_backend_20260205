## API使用指引

### 基本调用
```javascript
// 面谈得分列表
const response = await axios.get('/api/admin/reviews/interview-scores', {
  params: {
    competitionId: 21
  },
  headers: {
    'Authorization': `Bearer ${token}`
  }

```

### 带筛选条件
```javascript
const response = await axios.get('/api/admin/reviews/interview-scores', {
  params: {
    competitionId: 21,
    groupType: 'ADVANCED',  // 只看进阶组
    status: 'SCORED'        // 只看已评分
  }
});
```

### 前端组件复用示例
```vue
<template>
  <el-tabs v-model="activeTab" @tab-click="loadScores">
    <el-tab-pane label="书审得分" name="book"></el-tab-pane>
    <el-tab-pane label="面谈得分" name="interview"></el-tab-pane>
  </el-tabs>
  
  <!-- 复用同一个表格组件 -->
  <ScoreTable :data="scores" />
</template>

<script>
export default {
  data() {
    return {
      activeTab: 'book',
      scores: []
    };
  },
  methods: {
    async loadScores() {
      const endpoint = this.activeTab === 'book' 
        ? '/api/admin/reviews/book-scores'
        : '/api/admin/reviews/interview-scores';
      
      const { data } = await axios.get(endpoint, {
        params: { competitionId: 21 }
      });
      
      this.scores = data;
    }
  }
}
</script>
```

## 注意事项

### 1. 数据特点
- 面谈得分数量通常少于书审
- 面谈主要是进阶组（ADVANCED）项目
- 评分标准与书审相同（7项指标）

### 2. 筛选建议
- 默认筛选进阶组：`groupType=ADVANCED`
- 默认只显示已评分：`status=SCORED`

### 3. 权限控制
- 需要管理员权限（COMMITTEE_ADMIN）
- 需要JWT token认证

### 4. 错误处理
```javascript
try {
  const response = await axios.get('/api/admin/reviews/interview-scores', {
    params: { competitionId: 21 }
  });
  this.scores = response.data;
} catch (error) {
  if (error.response?.status === 401) {
    console.error('未授权，请先登录');
  } else if (error.response?.status === 404) {
    console.error('竞赛不存在');
  } else {
    console.error('获取面谈得分失败:', error.message);
  }
}
```
