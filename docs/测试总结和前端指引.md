## 📋 前端开发指引

### 1. API接口

所有场景使用同一个接口获取报名详情：

```
GET /api/registrations/{id}
Authorization: Bearer {token}
```

### 3. 字段显示规则

#### 活动信息字段

```javascript
// Boolean字段显示
<el-tag :type="activityInfo.crossDepartment ? 'success' : 'info'">
  {{ activityInfo.crossDepartment ? '是' : '否' }}
</el-tag>

<el-tag :type="activityInfo.relatedToDigitalAi ? 'success' : 'info'">
  {{ activityInfo.relatedToDigitalAi ? '是' : '否' }}
</el-tag>

// 数字字段显示
{{ activityInfo.avgWorkYears }} 年
{{ activityInfo.avgAge }} 岁

// 字典字段显示（优先使用Label，Label为空时显示Code）
{{ activityInfo.subjectTypeLabel || activityInfo.subjectTypeCode }}
{{ activityInfo.methodLabel || activityInfo.methodCode }}
{{ activityInfo.experienceImproveLabel || activityInfo.experienceImproveCode }}
{{ activityInfo.qualityTopicLabel || activityInfo.qualityTopicCode }}
```

#### 项目摘要字段

```javascript
// 长文本显示（保留换行）
<div class="summary-content">
  <div class="summary-item">
    <h4>计划</h4>
    <p>{{ projectSummary.plan || '未填写' }}</p>
  </div>
  <div class="summary-item">
    <h4>运作</h4>
    <p>{{ projectSummary.operation || '未填写' }}</p>
  </div>
  <div class="summary-item">
    <h4>展示</h4>
    <p>{{ projectSummary.presentation || '未填写' }}</p>
  </div>
</div>

// CSS样式
.summary-item p {
  white-space: pre-wrap;  /* 保留换行 */
  word-break: break-word; /* 自动换行 */
  line-height: 1.8;
}
```

### 4. 空值处理

```javascript
// activityInfo 为 null
if (!detail.activityInfo) {
  // 显示"暂无活动说明"
}

// projectSummary 为 null
if (!detail.projectSummary) {
  // 显示"暂无项目摘要"
}

// operation 或 presentation 为 null
{{ detail.projectSummary?.operation || '未填写' }}
{{ detail.projectSummary?.presentation || '未填写' }}
```
