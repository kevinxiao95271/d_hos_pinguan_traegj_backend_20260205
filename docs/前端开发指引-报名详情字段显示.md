## 场景1: 参赛者 - 我的报名

### 页面路径
`/contestant/my-registrations` → 点击详情 → `/contestant/registration-detail/{id}`

### 数据获取流程

1. 获取报名列表：`GET /api/registrations/my`
2. 点击详情按钮，跳转到详情页
3. 详情页调用：`GET /api/registrations/{id}`

<script setup>
import { ref, onMounted } from 'vue'
import { useRoute } from 'vue-router'
import { ElMessage } from 'element-plus'
import api from '@/api'

const route = useRoute()
const detail = ref({})

// 获取报名详情
const fetchDetail = async () => {
  try {
    const registrationId = route.params.id
    const response = await api.get(`/api/registrations/${registrationId}`)
    
    if (response.data.success) {
      detail.value = response.data.data
    } else {
      ElMessage.error(response.data.message || '获取详情失败')
    }
  } catch (error) {
    console.error('获取详情失败:', error)
    ElMessage.error('获取详情失败')
  }
}

// 格式化日期时间
const formatDateTime = (dateTime) => {
  if (!dateTime) return '-'
  return new Date(dateTime).toLocaleString('zh-CN')
}

// 获取组别标签
const getGroupTypeLabel = (type) => {
  const labels = {
    'COMPREHENSIVE': '综合组',
    'SPECIALIZED': '专科组'
  }
  return labels[type] || type
}

// 获取状态标签
const getStatusLabel = (status) => {
  const labels = {
    'DRAFT': '草稿',
    'SUBMITTED': '已提交',
    'RETURNED': '已退回',
    'APPROVED': '已通过'
  }
  return labels[status] || status
}

// 获取状态类型
const getStatusType = (status) => {
  const types = {
    'DRAFT': 'info',
    'SUBMITTED': 'warning',
    'RETURNED': 'danger',
    'APPROVED': 'success'
  }
  return types[status] || 'info'
}

// 获取成员角色标签
const getMemberRoleLabel = (role) => {
  const labels = {
    'LEADER': '组长',
    'MENTOR': '辅导员',
    'PARTICIPANT': '参与人员'
  }
  return labels[role] || role
}

// 获取改善就医环境标签（需要从字典接口获取）
const getExperienceImproveLabel = (code) => {
  // TODO: 从字典接口获取标签
  return code
}

// 获取医疗质量主题标签（需要从字典接口获取）
const getQualityTopicLabel = (code) => {
  // TODO: 从字典接口获取标签
  return code
}

// 下载文件
const downloadFile = (file) => {
  window.open(file.fileUrl, '_blank')
}

onMounted(() => {
  fetchDetail()
})
</script>

## 字段显示规则

### 活动说明字段（10个）

| 字段 | 显示规则 | 示例 |
|------|---------|------|
| theme | 直接显示 | "改善门诊就诊流程" |
| keywords | 直接显示 | "流程优化,患者满意度" |
| subjectTypeCode | 显示Label，如果有Other则显示 | "满意度" 或 "满意度（其他说明）" |
| methodCode | 显示Label，如果有Other则显示 | "流程改造" 或 "流程改造（其他说明）" |
| experienceImproveCode | 显示Label，如果有Other则显示 | "门诊就诊更加优化" 或 "门诊就诊更加优化（其他说明）" |
| qualityTopicCode | 显示Label，如果有Other则显示 | "降低住院患者围手术期死亡率" 或 "降低住院患者围手术期死亡率（其他说明）" |
| avgWorkYears | 显示数字 + "年" | "7 年" |
| avgAge | 显示数字 + "岁" | "32 岁" |
| crossDepartment | 显示"是"或"否"，可用Tag | "是" (绿色) / "否" (灰色) |
| relatedToDigitalAi | 显示"是"或"否"，可用Tag | "是" (绿色) / "否" (灰色) |

### 项目摘要字段（7个）

| 字段 | 显示规则 | 注意事项 |
|------|---------|---------|
| theme | 直接显示 | 标题样式 |
| plan | 直接显示 | 保留换行，长文本 |
| problem | 直接显示 | 保留换行，长文本 |
| action | 直接显示 | 保留换行，长文本 |
| success | 直接显示 | 保留换行，长文本 |
| discussion | 直接显示 | 保留换行，长文本 |
| operation | 直接显示，可能为空 | 保留换行，长文本，如果为空显示"未填写" |
| presentation | 直接显示，可能为空 | 保留换行，长文本，如果为空显示"未填写" |

### 空值处理

```javascript
// activityInfo 为 null
if (!detail.activityInfo) {
  // 显示"暂无活动说明"
}

// projectSummary 为 null
if (!detail.projectSummary) {
  // 显示"暂无项目摘要"
}

// operation 或 presentation 为 null
if (!detail.projectSummary.operation) {
  // 显示"未填写"
}
```

## 常见问题

### Q1: relatedToDigitalAi 显示为 null？

**A**: 需要先执行数据库迁移脚本 `add_digital_ai_field.sql`，然后重启应用。

### Q2: operation 和 presentation 显示为 null？

**A**: 这两个字段是新增的，旧数据可能为空。需要显示"未填写"。

### Q3: 字典标签显示为 code？
