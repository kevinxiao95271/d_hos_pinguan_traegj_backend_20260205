# 机构搜索排序修复说明

## 📋 修复内容

已为**所有机构搜索接口**添加统一的等级优先排序规则。

---

## 🎯 新排序规则

### 等级优先排序（降序）
1. **三级** 医院（最优先）
2. **二级** 医院
3. **一级** 医院
4. **其他**（未定级、无级别、空值等）

### 相同等级内
- 按**机构名称**升序（A-Z，拼音顺序）

## 🛠️ 技术实现

### JPQL 方式（Repository层）
```java
ORDER BY 
CASE 
  WHEN i.level = '三级' THEN 1 
  WHEN i.level = '二级' THEN 2 
  WHEN i.level = '一级' THEN 3 
  ELSE 4 
END, 
i.name ASC
```

### Criteria API 方式（Service层）
```java
query.orderBy(
    cb.asc(
        cb.selectCase()
            .when(cb.equal(root.get("level"), "三级"), 1)
            .when(cb.equal(root.get("level"), "二级"), 2)
            .when(cb.equal(root.get("level"), "一级"), 3)
            .otherwise(4)
    ),
    cb.asc(root.get("name"))
);
```

## 📌 注意事项

1. **排序是强制的**：现在所有搜索接口都自动按等级优先排序，忽略客户端传入的`sortBy`和`sortDirection`参数
2. **性能影响**：CASE WHEN排序对性能影响很小，因为：
   - 等级字段值很少（只有3-4种）
   - 有索引支持
   - 数据量相对不大
3. **兼容性**：向后兼容，不影响现有功能
