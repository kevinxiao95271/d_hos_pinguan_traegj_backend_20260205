  三个评审阶段

   - 筛选入围面谈的项目

🎤 面谈阶段（INTERVIEW）

🏆 决赛阶段（FINAL）
   - 查看决赛得分排名
   - 确定最终名次

================================================================================
  核心API
================================================================================

1. 获取评分排名（支持三阶段）
   GET /api/admin/reviews/rankings
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK" | "INTERVIEW" | "FINAL"（必填）⭐
     - groupType: "BASIC" | "ADVANCED" | "COMPREHENSIVE"（可选）
   
   返回：
     [
       {
         "rank": 1,
         "registrationId": 106,
         "projectName": "护理交接班规范化-1",
         "institutionName": "浙江大学医学院附属第一医院",
         "groupType": "BASIC",
         "stage": "BOOK",  // ⭐ 或 "INTERVIEW" 或 "FINAL"
         "avgTotal": 88.0
       }
     ]

2. 获取入围名单（支持三阶段）
   GET /api/admin/reviews/shortlist
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK" | "INTERVIEW" | "FINAL"（必填）⭐
     - groupType: 可选
     - limit: 10（可选，前N名）
     - minAvgTotal: 85.0（可选，最低分数线）

3. 获取项目详细评分（返回所有阶段）
   GET /api/registrations/{id}/review-details
   
   返回：⭐ 返回所有阶段的评分
     [
       {
         "stage": "BOOK",
         "avgPlan": 18.0,
         "avgProblem": 17.0,
         "avgAction": 19.0,
         "avgSuccess": 18.0,
         "avgReview": 16.0,
         "avgOperation": 0.0,
         "avgPresentation": 0.0,
         "avgTotal": 88.0,
         "highlights": ["亮点1"],
         "weaknesses": ["不足1"]
       },
       {
         "stage": "INTERVIEW",
         "avgTotal": 90.0,
         // ... 面谈阶段评分
       },
       {
         "stage": "FINAL",
         "avgTotal": 91.0,
         // ... 决赛阶段评分
       }
     ]

================================================================================
  前端调用示例（Vue 3）
================================================================================

// 当前阶段状态
const currentStage = ref('BOOK');  // BOOK、INTERVIEW、FINAL

// 1. 获取当前阶段排名
async function loadRankings() {
  const response = await axios.get('/api/admin/reviews/rankings', {
    params: {
      competitionId: 21,
      stage: currentStage.value,  // ⭐ 动态传递阶段
      groupType: filters.groupType || undefined
    },
    headers: {
      Authorization: `Bearer ${localStorage.getItem('token')}`
    }
  });
  
  return response.data.data;
}

// 2. 切换阶段
function switchStage(stage) {
  currentStage.value = stage;  // 'BOOK', 'INTERVIEW', 或 'FINAL'
  loadRankings();  // 重新加载数据
}

// 3. 查看项目所有阶段的评分
async function viewAllStageScores(registrationId) {
  const response = await axios.get(
    `/api/registrations/${registrationId}/review-details`,
    {
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    }
  );
  
  const allStages = response.data.data;
  // [
  //   { stage: 'BOOK', avgTotal: 88.0, ... },
  //   { stage: 'INTERVIEW', avgTotal: 90.0, ... },
  //   { stage: 'FINAL', avgTotal: 91.0, ... }
  // ]
  
  // 查找当前阶段的评分
  const currentStageScore = allStages.find(d => d.stage === currentStage.value);
  
  return { allStages, currentStageScore };
}

================================================================================
  常见问题
================================================================================

Q: 面谈/决赛阶段返回空数据？
A: 正常现象，说明该阶段还没有开始评分。前端应该显示友好提示，
   如"面谈阶段还未开始"或"暂无评分数据"。

Q: 如何判断项目是否入围下一阶段？
A: 根据当前阶段的排名和筛选条件（分数线、数量）判断。
   - 书审入围 → 进入面谈
   - 面谈入围 → 进入决赛

Q: 详情对话框如何展示多个阶段？
A: 使用 Tabs 或 Collapse 组件，每个阶段一个标签页。
   默认展示当前阶段的评分。

Q: 如何统计各阶段进度？
A: 可以分别调用三个阶段的 rankings API 统计数量，
   或者后端提供专门的统计接口。
