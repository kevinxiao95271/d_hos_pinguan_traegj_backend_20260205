## 🎨 前端实现方案

### 方案1：两级联动（推荐）

**适用场景**: 用户希望先选城市，再选具体机构

```vue
<template>
  <div class="region-selector">
    <!-- 第一级：选择城市 -->
    <el-select 
      v-model="selectedCity" 
      placeholder="选择城市"
      @change="onCityChange"
    >
      <el-option
        v-for="city in cities"
        :key="city"
        :label="city"
        :value="city"
      />
    </el-select>
    
    <!-- 第二级：搜索机构 -->
    <el-autocomplete
      v-if="selectedCity"
      v-model="institutionKeyword"
      :fetch-suggestions="searchInstitutions"
      placeholder="输入机构名称搜索"
      @select="onSelectInstitution"
    >
      <template #default="{ item }">
        <div class="institution-item">
          <div class="name">{{ item.name }}</div>
          <div class="meta">{{ item.region }} · {{ item.level }}</div>
        </div>
      </template>
    </el-autocomplete>
  </div>
</template>

<script>
export default {
  data() {
    return {
      cities: [],
      selectedCity: '',
      institutionKeyword: '',
      selectedInstitution: null
    }
  },
  
  async mounted() {
    // 加载城市列表
    const res = await fetch('http://localhost:6031/api/institutions/cities')
    const data = await res.json()
    if (data.success) {
      this.cities = data.data
    }
  },
  
  methods: {
    onCityChange() {
      // 城市切换时清空机构选择
      this.institutionKeyword = ''
      this.selectedInstitution = null
    },
    
    async searchInstitutions(queryString, cb) {
      // 防抖搜索
      if (!queryString || queryString.length < 2) {
        cb([])
        return
      }
      
      const res = await fetch('http://localhost:6031/api/institutions/search', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          keyword: queryString,
          region: this.selectedCity,  // 在选定城市内搜索
          page: 0,
          size: 10
        })
      })
      
      const data = await res.json()
      cb(data.success ? data.data.content : [])
    },
    
    onSelectInstitution(institution) {
      this.selectedInstitution = institution
      console.log('选择的机构:', institution)
    }
  }
}
</script>
```

**优点**: 
- ✅ 性能好（先缩小范围到城市）
- ✅ 用户操作简单清晰
- ✅ 每次搜索只在5千家内查询

### 方案2：智能搜索（简洁）

**适用场景**: 用户可以直接搜索城市或机构名称

```vue
<template>
  <div class="smart-search">
    <el-autocomplete
      v-model="keyword"
      :fetch-suggestions="searchInstitutions"
      placeholder="输入城市或机构名称（如'杭州'、'上城区'、'浙江省人民医院'）"
      @select="onSelect"
      style="width: 100%"
    >
      <template #default="{ item }">
        <div class="institution-item">
          <div class="name">{{ item.name }}</div>
          <div class="meta">
            <span>{{ item.region }}</span>
            <span v-if="item.level"> · {{ item.level }}</span>
            <span v-if="item.category"> · {{ item.category }}</span>
          </div>
        </div>
      </template>
    </el-autocomplete>
  </div>
</template>

<script>
export default {
  data() {
    return {
      keyword: '',
      selectedInstitution: null,
      debounceTimer: null
    }
  },
  
  methods: {
    searchInstitutions(queryString, cb) {
      // 防抖
      clearTimeout(this.debounceTimer)
      
      if (!queryString || queryString.length < 2) {
        cb([])
        return
      }
      
      this.debounceTimer = setTimeout(async () => {
        try {
          // 智能搜索：支持城市、区县、机构名称
          const res = await fetch('http://localhost:6031/api/institutions/search', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
              keyword: queryString,   // 可以是"杭州"、"上城区"、"人民医院"等
              page: 0,
              size: 15
            })
          })
          
          const data = await res.json()
          cb(data.success ? data.data.content : [])
        } catch (error) {
          console.error('搜索失败:', error)
          cb([])
        }
      }, 300)  // 300ms防抖
    },
    
    onSelect(institution) {
      this.selectedInstitution = institution
      console.log('选择的机构:', institution)
    }
  }
}
</script>

<style scoped>
.institution-item {
  padding: 8px 0;
}
.institution-item .name {
  font-size: 14px;
  font-weight: 500;
  color: #303133;
}
.institution-item .meta {
  font-size: 12px;
  color: #909399;
  margin-top: 4px;
}
</style>
```

**优点**:
- ✅ 操作极简（一个输入框搞定）
- ✅ 智能匹配（输入"杭州"自动匹配5,786家）
- ✅ 灵活度高（支持各种查询方式）

## 📈 性能优化

### 1. 防抖（必须）

```javascript
// 300ms防抖，避免频繁请求
debounceTimer = setTimeout(async () => {
  // 执行搜索
}, 300)
```

先选城市（11选1），再搜索机构（缩小范围）

### 3. 限制返回条数

搜索时 `size: 10~15` 即可，用户很少翻页
