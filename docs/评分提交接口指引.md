# 评分提交接口完整指引

**接口:** `POST /api/reviews/scores`  
**认证:** 需要 Bearer Token  
**角色:** REVIEWER（评委）

---

## 🎯 完整请求示例

### 标准请求（所有字段）

```http
POST http://localhost:6031/api/reviews/scores
Authorization: Bearer {token}
Content-Type: application/json

{
  "reviewTaskId": 115,
  "plan": 18,
  "problem": 17,
  "action": 19,
  "success": 18,
  "review": 16,
  "operation": 0,
  "presentation": 0,
  "highlight": "项目主题明确，改进措施得当，成效显著。",
  "weakness": "建议进一步量化成本效益分析。"
}
```

---

## 📋 字段说明

### 必填字段 ⭐

| 字段名 | 类型 | 验证规则 | 说明 | 示例 |
|--------|------|----------|------|------|
| **reviewTaskId** | Long | @NotNull | 评审任务ID（不是registrationId！） | 115 |
| **highlight** | String | @NotBlank | 亮点评价（不能为空） | "主题明确，成效显著" |
| **weakness** | String | @NotBlank | 不足之处（不能为空） | "建议量化分析" |

### 评分字段（可选，但建议填写）

| 字段名 | 类型 | 验证规则 | 说明 | 示例 |
|--------|------|----------|------|------|
| plan | Integer | @Min(0) @Max(100) | 计划得分 | 18 |
| problem | Integer | @Min(0) @Max(100) | 问题得分 | 17 |
| action | Integer | @Min(0) @Max(100) | 措施得分 | 19 |
| success | Integer | @Min(0) @Max(100) | 成效得分 | 18 |
| review | Integer | @Min(0) @Max(100) | 回顾得分 | 16 |
| operation | Integer | @Min(0) @Max(100) | 操作得分 | 0 |
| presentation | Integer | @Min(0) @Max(100) | 展示得分 | 0 |

**注意：**
- 评分字段如果不传，默认为 null（后端会处理）
- 总分 = plan + problem + action + success + review + operation + presentation（后端自动计算）

---

## ⚠️ 常见错误

### 错误1: 缺少必填字段

```json
// ❌ 错误：缺少 highlight 和 weakness
{
  "reviewTaskId": 115,
  "plan": 18,
  "problem": 17
}
```

**错误信息：** `"参数校验失败"`

**解决方法：** 必须提供 `highlight` 和 `weakness` 字段，且不能为空字符串

```json
// ✅ 正确
{
  "reviewTaskId": 115,
  "plan": 18,
  "problem": 17,
  "highlight": "优点描述",
  "weakness": "不足描述"
}
```

### 错误2: 字段值为空字符串

```json
// ❌ 错误：highlight 和 weakness 为空字符串
{
  "reviewTaskId": 115,
  "highlight": "",
  "weakness": ""
}
```

**错误信息：** `"参数校验失败"`

**解决方法：** `highlight` 和 `weakness` 必须有实际内容

### 错误3: 使用错误的ID

```json
// ❌ 错误：使用了 registrationId 而不是 reviewTaskId
{
  "reviewTaskId": 106,  // 这是 registrationId，不是 taskId！
  "highlight": "...",
  "weakness": "..."
}
```

**解决方法：** 
- 从任务列表中获取 `id` 字段（这是 `taskId`）
- 不要使用 `registrationId`

## 🐍 Python测试脚本

创建文件 `scripts/test_submit_score.py`：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""测试评分提交接口"""

import requests
import json

BASE = "http://localhost:6031"

# 1. 登录
print("登录...")
login_resp = requests.post(f"{BASE}/api/auth/login", json={
    "phone": "13800000021",
    "name": "李明华",
    "role": "REVIEWER"
})

token = login_resp.json()['data']['token']
print(f"✅ Token获取成功\n")

headers = {
    "Authorization": f"Bearer {token}",
    "Content-Type": "application/json"
}

# 2. 获取任务
print("获取任务列表...")
tasks_resp = requests.get(f"{BASE}/api/reviews/my-tasks", headers=headers)
tasks = tasks_resp.json()['data']

if not tasks:
    print("❌ 没有可用任务")
    exit(1)

task = tasks[0]
task_id = task['id']
project_name = task['projectName']

print(f"✅ 任务ID: {task_id}")
print(f"   项目: {project_name}\n")

# 3. 提交评分
print("提交评分...")

score_data = {
    "reviewTaskId": task_id,  # ⭐ 使用 taskId
    "plan": 18,
    "problem": 17,
    "action": 19,
    "success": 18,
    "review": 16,
    "operation": 0,
    "presentation": 0,
    "highlight": "项目主题明确，改进措施得当，成效显著。",  # ⭐ 必填
    "weakness": "建议进一步量化成本效益分析。"  # ⭐ 必填
}

score_resp = requests.post(
    f"{BASE}/api/reviews/scores",
    headers=headers,
    json=score_data
)

print(f"状态码: {score_resp.status_code}")

if score_resp.status_code == 200:
    result = score_resp.json()['data']
    print(f"✅ 评分提交成功！")
    print(f"   评分ID: {result['id']}")
    print(f"   总分: {result['total']}")
else:
    print(f"❌ 提交失败")
    print(f"   错误: {score_resp.json()}")
```

**运行：**
```bash
python scripts/test_submit_score.py
```

## 📱 前端Vue组件示例

```vue
<template>
  <el-form :model="scoreForm" @submit.prevent="submitScore">
    <!-- 评分项 -->
    <el-form-item label="计划 (0-100)">
      <el-input-number v-model="scoreForm.plan" :min="0" :max="100" />
    </el-form-item>
    
    <el-form-item label="问题 (0-100)">
      <el-input-number v-model="scoreForm.problem" :min="0" :max="100" />
    </el-form-item>
    
    <el-form-item label="措施 (0-100)">
      <el-input-number v-model="scoreForm.action" :min="0" :max="100" />
    </el-form-item>
    
    <el-form-item label="成效 (0-100)">
      <el-input-number v-model="scoreForm.success" :min="0" :max="100" />
    </el-form-item>
    
    <el-form-item label="回顾 (0-100)">
      <el-input-number v-model="scoreForm.review" :min="0" :max="100" />
    </el-form-item>
    
    <!-- 亮点和不足（必填！） -->
    <el-form-item label="亮点" required>
      <el-input 
        v-model="scoreForm.highlight" 
        type="textarea" 
        :rows="3"
        placeholder="请描述项目的亮点和优势（必填）"
      />
    </el-form-item>
    
    <el-form-item label="不足" required>
      <el-input 
        v-model="scoreForm.weakness" 
        type="textarea" 
        :rows="3"
        placeholder="请指出项目的不足之处和改进建议（必填）"
      />
    </el-form-item>
    
    <el-form-item>
      <el-button type="primary" @click="submitScore">提交评分</el-button>
    </el-form-item>
  </el-form>
</template>

<script setup>
import { ref } from 'vue';
import { ElMessage } from 'element-plus';
import axios from 'axios';

const props = defineProps({
  taskId: {
    type: Number,
    required: true
  }
});

const scoreForm = ref({
  plan: 0,
  problem: 0,
  action: 0,
  success: 0,
  review: 0,
  operation: 0,
  presentation: 0,
  highlight: '',  // ⭐ 必填
  weakness: ''    // ⭐ 必填
});

const submitScore = async () => {
  // ⭐ 验证必填字段
  if (!scoreForm.value.highlight || !scoreForm.value.highlight.trim()) {
    ElMessage.error('请填写项目亮点');
    return;
  }
  
  if (!scoreForm.value.weakness || !scoreForm.value.weakness.trim()) {
    ElMessage.error('请填写项目不足');
    return;
  }
  
  try {
    await axios.post('/api/reviews/scores', {
      reviewTaskId: props.taskId,  // ⭐ 使用 taskId
      ...scoreForm.value
    }, {
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    });
    
    ElMessage.success('评分提交成功');
    // 跳转或刷新页面
  } catch (error) {
    console.error('提交失败:', error);
    ElMessage.error(error.response?.data?.message || '提交失败');
  }
};
</script>
```

## 🆘 故障排查

### 问题：返回 400 "参数校验失败"

**可能原因：**
1. 缺少 `highlight` 或 `weakness` 字段
2. `highlight` 或 `weakness` 为空字符串
3. 缺少 `reviewTaskId` 字段
4. 评分字段超出范围（0-100）

**解决方法：**
```javascript
// 检查请求数据
console.log('提交的数据:', JSON.stringify(scoreData, null, 2));

// 确保必填字段有值
if (!scoreData.highlight || !scoreData.weakness) {
  console.error('缺少必填字段');
}
```

### 问题：返回 401 "未登录"

**解决方法：**
- 检查 token 是否正确
- 检查 Authorization header 格式：`Bearer {token}`

### 问题：返回 404 "评审任务不存在"

**解决方法：**
- 确认使用的是正确的 `reviewTaskId`
- 检查该任务是否属于当前登录的评委
