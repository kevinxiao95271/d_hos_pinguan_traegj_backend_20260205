# 注册登录功能实施清单

## 核心设计决策

✅ **注册流程**：验证码验证 → 设置密码 + 填写信息 + 选择机构（必填）  
✅ **登录方式**：密码登录 OR 验证码登录（双通道）  
✅ **密码管理**：支持修改密码、重置密码  
✅ **手机号唯一性**：数据库unique约束 + 业务层校验  

## 实施步骤

### Step 1: 数据库变更 ⏱️ 30分钟

```sql
-- 1. user_accounts表新增字段
ALTER TABLE user_accounts 
ADD COLUMN password_hash VARCHAR(128),
ADD COLUMN is_password_set BOOLEAN DEFAULT FALSE,
ADD COLUMN last_login_at TIMESTAMP,
ADD COLUMN updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP;

-- 2. 创建验证码表（通用：支持邮箱和短信）
CREATE TABLE verification_codes (
    id BIGSERIAL PRIMARY KEY,
    recipient VARCHAR(128) NOT NULL,  -- 邮箱或手机号
    code VARCHAR(6) NOT NULL,
    purpose VARCHAR(32) NOT NULL,
    is_used BOOLEAN DEFAULT FALSE,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_recipient_purpose ON verification_codes(recipient, purpose);
CREATE INDEX idx_expires_at ON verification_codes(expires_at);
```

## 关键业务规则

### 注册规则
1. 邮箱/手机号必须唯一（数据库约束 + 业务校验）
2. 机构必选（institutionId不能为空）
3. 密码强度：8-20位，包含大小写字母和数字
4. 验证码5分钟有效，验证后立即失效

### 验证码规则
1. 6位随机数字
2. 同一邮箱/手机号60秒内只能发送一次
3. 每天同一邮箱/手机号最多10次
4. 开发环境固定验证码：888888
5. Phase 1使用邮箱，Phase 2切换到短信（配置切换）

### 密码规则
1. 长度：8-20位
2. 必须包含：大写字母、小写字母、数字
3. 使用BCrypt加密（自动加盐）
4. 登录失败5次锁定30分钟（可选）

### 登录规则
1. 支持密码登录
2. 支持验证码登录（忘记密码场景）
3. 登录成功更新last_login_at
4. 返回JWT token

## 技术选型

- **密码加密**：BCrypt（Spring Security内置）
- **验证码**：6位随机数字
- **验证码发送**：
  - Phase 1: 邮件服务（Spring Mail + QQ邮箱/163邮箱）
  - Phase 2: 短信服务（阿里云短信）
  - 架构：抽象接口 + 策略模式，配置切换
- **Token**：JWT（现有实现）

## 风险和注意事项

⚠️ **邮箱/手机号唯一性**：注册时需要先检查是否已存在  
⚠️ **机构必选**：前端必须提供机构选择器  
⚠️ **旧数据兼容**：现有用户password_hash为NULL，首次登录需引导设置密码  
⚠️ **邮箱到达率**：可能进垃圾箱，提醒用户检查（Phase 1）  
⚠️ **短信成本**：生产环境需要申请短信服务并控制成本（Phase 2）  
⚠️ **验证码防刷**：需要严格的频率限制和每日上限  
⚠️ **平滑迁移**：邮箱→短信切换只需改配置，无需改代码
