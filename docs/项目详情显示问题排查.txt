================================================================================
  前端正确解析方式
================================================================================

步骤1: 调用API
  const response = await axios.get(
    `/api/registrations/${registrationId}/review-details`,
    { headers: { Authorization: `Bearer ${token}` } }
  );

步骤2: 获取书审阶段数据
  const allStages = response.data.data;  // 注意是 data.data
  const bookStage = allStages.find(s => s.stage === 'BOOK');

步骤3: 显示分项得分
  计划: bookStage?.avgPlan ?? '-'
  问题: bookStage?.avgProblem ?? '-'
  行动: bookStage?.avgAction ?? '-'
  成效: bookStage?.avgSuccess ?? '-'
  回顾: bookStage?.avgReview ?? '-'
  运作: bookStage?.avgOperation ?? '-'
  展示: bookStage?.avgPresentation ?? '-'
  总分: bookStage?.avgTotal ?? '-'

步骤4: 显示评委意见
  亮点: bookStage?.highlights || []
  改进建议: bookStage?.weaknesses || []

================================================================================
  常见错误
================================================================================

❌ 错误1: 字段名拼写错误
   错误: bookStage.plan
   正确: bookStage.avgPlan

❌ 错误2: 未找到正确的stage
   错误: data.data[0]  // 直接取第一个
   正确: data.data.find(s => s.stage === 'BOOK')

❌ 错误3: 未处理null值
   错误: avgPlan.toFixed(1)  // avgPlan可能是null
   正确: (avgPlan ?? 0).toFixed(1) 或 avgPlan === null ? '-' : avgPlan

❌ 错误4: 空数组判断错误
   错误: if (!highlights) { 显示"暂无" }
   正确: if (!highlights || highlights.length === 0) { 显示"暂无" }
