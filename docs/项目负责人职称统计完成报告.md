# 项目负责人职称统计功能 - 完成报告

## 功能概述

在报名统计API中新增了按项目负责人职称分布的统计维度，前端可以使用该数据绘制饼图展示职称分布情况。

## 实现方案

采用方案1：在现有统计API中添加新字段 `leaderTitleCounts`

### 优点
- 前端无需修改调用方式
- 数据一次性获取，性能最优
- 与现有字段（regionCounts、methodCounts等）保持一致

## API变更

### 接口地址
```
GET /api/admin/stats/summary
GET /api/admin/stats/summary?competitionId={id}
```

### 新增响应字段

在 `StatsSummaryResponse` 中新增：

```json
{
  "leaderTitleCounts": {
    "主管护师": 19,
    "主治医师": 10,
    "药师": 9,
    "技师": 4,
    "医师": 3,
    "未知": 1
  }
}
```

### 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| leaderTitleCounts | Map<String, Integer> | 项目负责人职称分布统计 |

- Key: 职称名称（如"主管护师"、"主治医师"等）
- Value: 该职称的项目数量
- 统计规则：每个报名项目只统计一个负责人（role=PARTICIPANT的第一个成员）

## 前端对接指引

### 1. API调用示例

```javascript
// 获取最新赛事统计
const response = await fetch('/api/admin/stats/summary', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});

const result = await response.json();
const stats = result.data;

// 获取项目负责人职称分布
const leaderTitleCounts = stats.leaderTitleCounts;
```

### 2. 数据处理示例

```javascript
// 转换为图表数据格式
const chartData = Object.entries(leaderTitleCounts).map(([title, count]) => ({
  name: title,
  value: count
}));

// 按数量排序
chartData.sort((a, b) => b.value - a.value);

// 计算百分比
const total = chartData.reduce((sum, item) => sum + item.value, 0);
chartData.forEach(item => {
  item.percentage = ((item.value / total) * 100).toFixed(1);
});
```

## 代码变更

### 1. StatsSummaryResponse.java
```java
@Data
@AllArgsConstructor
public class StatsSummaryResponse {
    // ... 其他字段
    private Map<String, Integer> leaderTitleCounts;  // 新增
    // ... 其他字段
}
```

### 2. StatsService.java
```java
// 新增依赖注入
private final RegistrationMemberRepository memberRepository;

// 在 summaryForCompetition 方法中新增统计逻辑
Map<String, Integer> leaderTitleCounts = new HashMap<>();
for (Registration registration : registrations) {
    List<RegistrationMember> members = memberRepository.findByRegistrationId(registration.getId());
    for (RegistrationMember member : members) {
        if (member.getRole() == MemberRole.PARTICIPANT) {
            String title = member.getTitle();
            if (title == null || title.trim().isEmpty()) {
                title = "未知";
            }
            leaderTitleCounts.put(title, leaderTitleCounts.getOrDefault(title, 0) + 1);
            break;  // 每个项目只统计一个负责人
        }
    }
}
```

## 注意事项

1. 职称数据来源于 `registration_members` 表的 `title` 字段
2. 每个报名项目只统计一个负责人（role=PARTICIPANT的第一个成员）
3. 如果职称为空，统计为"未知"
4. 返回的是 Map 结构，前端需要自行转换为数组格式用于图表展示
5. 空数据时返回空对象 `{}`，不是 null
