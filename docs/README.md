## 🔗 快速链接

### API访问

- **Swagger文档:** http://localhost:6031/swagger
- **健康检查:** http://localhost:6031/actuator/health
- **API基础路径:** http://localhost:6031/api

### 测试账号（李明华 - 有任务的评委）

```json
POST http://localhost:6031/api/auth/login
{
  "phone": "13800000021",
  "name": "李明华",
  "role": "REVIEWER"
}
```

### 常用API

```bash
# 获取评审任务列表
GET /api/reviews/my-tasks

# 获取报名详情
GET /api/registrations/{registrationId}

# 提交评分
POST /api/reviews/scores

# 获取评委列表（组委会/运维）
GET /api/admin/reviewers
```
