# 面谈分组和书审分组接口 - 使用范例

## 📋 接口信息

### 1. 面谈分组接口
- **接口地址**: `GET /api/admin/registrations/interview-groups`
- **参数**: `competitionId` (赛事ID)
- **权限**: 需要登录（COMMITTEE_ADMIN 或 OPS）

### 2. 书审分组接口  
- **接口地址**: `GET /api/admin/registrations/final-groups`
- **参数**: `competitionId` (赛事ID)
- **权限**: 需要登录（COMMITTEE_ADMIN 或 OPS）

## 🎯 返回数据结构

### 响应格式
```json
{
  "success": true,
  "data": [
    {
      "groupCode": "A1",
      "items": [
        {
          "registrationId": 106,
          "projectName": "护理交接班规范化-1",
          "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
          "institutionLevel": "三级甲等",
          "groupType": "BASIC",
          "groupCode": "A1"
        }
      ]
    }
  ],
  "message": null
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| groupCode | String | 分组代码（如：A1, B2） |
| items | Array | 该分组下的项目列表 |
| registrationId | Long | 报名ID |
| projectName | String | 项目名称 |
| institutionName | String | 机构名称 |
| **institutionLevel** | **String** | **机构等级（如：三级甲等）** |
| groupType | String | 组别类型（BASIC/ADVANCED） |

## 💻 使用示例

### JavaScript/前端调用

```javascript
// 1. 登录获取Token
const loginResponse = await fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    phone: '13800000041',
    name: 'CommitteeAdmin A',
    role: 'COMMITTEE_ADMIN'
  })
});
const loginData = await loginResponse.json();
const token = loginData.data.token;

// 2. 获取赛事列表
const competitionsResponse = await fetch('/api/competitions', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const competitions = await competitionsResponse.json();
const competitionId = competitions.data[0].id;

// 3. 获取面谈分组数据
const interviewGroupsResponse = await fetch(
  `/api/admin/registrations/interview-groups?competitionId=${competitionId}`,
  {
    headers: { 'Authorization': `Bearer ${token}` }
  }
);
const interviewGroups = await interviewGroupsResponse.json();

if (interviewGroups.success) {
  const groups = interviewGroups.data;
  
  groups.forEach(group => {
    console.log(`分组: ${group.groupCode}`);
    
    group.items.forEach(item => {
      console.log(`  - ${item.projectName}`);
      console.log(`    医院: ${item.institutionName}`);
      console.log(`    等级: ${item.institutionLevel}`);  // ✅ 机构等级
      console.log(`    类型: ${item.groupType}`);
    });
  });
}
```

### Python 调用示例

```python
import requests

# 1. 登录
login_data = {
    "phone": "13800000041",
    "name": "CommitteeAdmin A",
    "role": "COMMITTEE_ADMIN"
}
response = requests.post("http://localhost:6031/api/auth/login", json=login_data)
token = response.json()['data']['token']

headers = {"Authorization": f"Bearer {token}"}

# 2. 获取赛事列表
response = requests.get("http://localhost:6031/api/competitions", headers=headers)
competitions = response.json()['data']
competition_id = competitions[0]['id']

# 3. 获取面谈分组
url = f"http://localhost:6031/api/admin/registrations/interview-groups?competitionId={competition_id}"
response = requests.get(url, headers=headers)
result = response.json()

if result['success']:
    groups = result['data']
    
    for group in groups:
        print(f"分组: {group['groupCode']}")
        
        for item in group['items']:
            print(f"  - {item['projectName']}")
            print(f"    医院: {item['institutionName']}")
            print(f"    等级: {item['institutionLevel']}")  # ✅ 机构等级
            print(f"    类型: {item['groupType']}")
```

### Vue.js 示例

```vue
<template>
  <div>
    <h2>面谈分组列表</h2>
    
    <div v-for="group in groups" :key="group.groupCode" class="group">
      <h3>分组: {{ group.groupCode }}</h3>
      
      <el-table :data="group.items" border>
        <el-table-column prop="registrationId" label="ID" width="80"></el-table-column>
        <el-table-column prop="projectName" label="项目名称"></el-table-column>
        <el-table-column prop="institutionName" label="医院"></el-table-column>
        <el-table-column prop="institutionLevel" label="等级" width="120"></el-table-column>
        <el-table-column prop="groupType" label="类型" width="100"></el-table-column>
      </el-table>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      groups: [],
      competitionId: null
    }
  },
  methods: {
    async loadInterviewGroups() {
      const response = await fetch(
        `/api/admin/registrations/interview-groups?competitionId=${this.competitionId}`,
        {
          headers: {
            'Authorization': `Bearer ${this.$store.state.token}`
          }
        }
      );
      
      const result = await response.json();
      if (result.success) {
        this.groups = result.data;
      }
    }
  },
  mounted() {
    this.loadInterviewGroups();
  }
}
</script>
```

### React 示例

```jsx
import React, { useState, useEffect } from 'react';

function InterviewGroups({ competitionId, token }) {
  const [groups, setGroups] = useState([]);

  useEffect(() => {
    const loadGroups = async () => {
      const response = await fetch(
        `/api/admin/registrations/interview-groups?competitionId=${competitionId}`,
        {
          headers: {
            'Authorization': `Bearer ${token}`
          }
        }
      );
      
      const result = await response.json();
      if (result.success) {
        setGroups(result.data);
      }
    };
    
    loadGroups();
  }, [competitionId, token]);

  return (
    <div>
      <h2>面谈分组列表</h2>
      
      {groups.map(group => (
        <div key={group.groupCode} className="group">
          <h3>分组: {group.groupCode}</h3>
          
          <table>
            <thead>
              <tr>
                <th>ID</th>
                <th>项目名称</th>
                <th>医院</th>
                <th>等级</th>
                <th>类型</th>
              </tr>
            </thead>
            <tbody>
              {group.items.map(item => (
                <tr key={item.registrationId}>
                  <td>{item.registrationId}</td>
                  <td>{item.projectName}</td>
                  <td>{item.institutionName}</td>
                  <td>{item.institutionLevel}</td>
                  <td>{item.groupType}</td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      ))}
    </div>
  );
}

export default InterviewGroups;
```

## 🔍 机构等级说明

### 常见等级值
- `三级甲等` - 三甲医院
- `三级乙等` - 三乙医院
- `二级甲等` - 二甲医院
- `二级乙等` - 二乙医院
- 等等...

### 获取方式
机构等级来自 `institutions` 表的 `level` 字段，在报名时关联的机构信息中获取。

## ⚠️ 注意事项

1. **必须先登录**: 需要先调用登录接口获取 Token
2. **权限要求**: 仅限 COMMITTEE_ADMIN 和 OPS 角色
3. **赛事ID**: 需要先获取赛事列表，然后使用赛事ID查询分组
4. **机构等级**: 如果机构没有设置等级，该字段可能为 `null`

## 📝 相关接口

- 登录接口: `POST /api/auth/login`
- 赛事列表: `GET /api/competitions`
- 面谈分组: `GET /api/admin/registrations/interview-groups`
- 决赛分组: `GET /api/admin/registrations/final-groups`
