## 🎯 性能优化

### 评委列表接口优化效果

| 指标 | 优化前 | 优化后 | 提升 |
|-----|-------|-------|------|
| 平均响应时间 | 747ms | **238ms** | **↓68%** |
| 数据库查询次数 | 17次（N+1问题） | **1次** | **↓94%** |

**优化方法：**
```java
// 使用 JOIN FETCH 一次性加载关联数据
@Query("SELECT u FROM UserAccount u LEFT JOIN FETCH u.institution WHERE u.role = :role")
List<UserAccount> findByRoleWithInstitution(@Param("role") RoleType role);
```

## 🔄 如何访问

### 通过API获取评委列表

```bash
# 1. 登录获取token
curl -X POST http://localhost:6031/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "13800000009",
    "name": "组委会",
    "role": "COMMITTEE"
  }'

# 2. 获取评委列表
curl -X GET http://localhost:6031/api/admin/reviewers \
  -H "Authorization: Bearer <token>"
```

### 按背景筛选

```bash
# 只看医疗背景的评委
curl -X GET "http://localhost:6031/api/admin/reviewers?expertBackground=MEDICAL" \
  -H "Authorization: Bearer <token>"

# 只看A1组的评委
curl -X GET "http://localhost:6031/api/admin/reviewers?reviewerGroupCode=A1" \
  -H "Authorization: Bearer <token>"
```
