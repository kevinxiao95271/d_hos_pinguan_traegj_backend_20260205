## 二、兼容性方案设计

### 方案A：可选分页参数（推荐）⭐

**核心思路**: 新增可选的分页参数，**不传参数时保持原有行为**，传参数时返回分页结果。

#### 分页参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `page` | Integer | null | 页码（从0开始），不传则返回全部 |
| `size` | Integer | 20 | 每页数量（仅当page不为null时生效） |
| `sort` | String | null | 排序字段，格式：`fieldName,asc/desc` |

#### 响应格式

**不传分页参数（兼容旧版）**:
```json
{
  "success": true,
  "data": [
    { "id": 1, "name": "..." },
    { "id": 2, "name": "..." }
  ]
}
```

**传分页参数（新版）**:
```json
{
  "success": true,
  "data": {
    "content": [
      { "id": 1, "name": "..." },
      { "id": 2, "name": "..." }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 156,
    "totalPages": 8,
    "hasNext": true,
    "hasPrevious": false
  }
}
```

#### 优点
- ✅ **完全兼容**: 旧代码无需修改
- ✅ **渐进式升级**: 前端可按需迁移
- ✅ **灵活性高**: 支持不分页（全量导出）场景

#### 缺点
- ⚠️ 响应格式不一致（但通过泛型可处理）
- ⚠️ 需要前端判断返回类型

---

### 方案B：始终返回分页格式（不推荐）

**核心思路**: 所有API统一返回分页格式，不传参数时默认返回第一页。

#### 缺点
- ❌ **破坏兼容性**: 所有旧代码必须修改
- ❌ **无法全量查询**: 不适合导出场景
- ❌ **迁移成本高**: 需要同步修改前端

---

### 方案C：新增独立分页API（折中方案）

**核心思路**: 保留旧API不变，新增带 `/paged` 后缀的分页API。

**示例**:
- 旧API: `GET /api/reviews/tasks/stage` （返回全部）
- 新API: `GET /api/reviews/tasks/stage/paged` （返回分页）

#### 优点
- ✅ **完全兼容**: 旧API不受影响
- ✅ **清晰分离**: 新旧逻辑独立

#### 缺点
- ⚠️ **API数量翻倍**: 维护成本高
- ⚠️ **代码重复**: Service层逻辑基本相同

### 3.2 新增通用分页DTO

**文件**: `src/main/java/com/trae/pinguan/web/dto/PageResult.java`

```java
package com.trae.pinguan.web.dto;

import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;
import org.springframework.data.domain.Page;
import java.util.List;

@Data
@NoArgsConstructor
@AllArgsConstructor
public class PageResult<T> {
    private List<T> content;
    private Integer page;
    private Integer size;
    private Long totalElements;
    private Integer totalPages;
    private Boolean hasNext;
    private Boolean hasPrevious;
    
    public static <T> PageResult<T> of(Page<T> springPage) {
        return new PageResult<>(
            springPage.getContent(),
            springPage.getNumber(),
            springPage.getSize(),
            springPage.getTotalElements(),
            springPage.getTotalPages(),
            springPage.hasNext(),
            springPage.hasPrevious()
        );
    }
}
```

### 🔄 前端兼容处理示例

#### 不分页（旧代码，无需修改）

```typescript
// 旧代码保持不变
const response = await axios.get('/api/reviews/tasks/stage', {
  params: { competitionId: 21, stage: 'BOOK' }
});

const tasks = response.data.data;  // 直接是数组
console.log(tasks.length);  // 6
```

#### 分页（新代码）

```typescript
// 新代码传入分页参数
const response = await axios.get('/api/reviews/tasks/stage', {
  params: { 
    competitionId: 21, 
    stage: 'BOOK',
    page: 0,      // 第1页
    size: 20      // 每页20条
  }
});

const pageResult = response.data.data;  // PageResult对象
console.log(pageResult.content.length);  // 20
console.log(pageResult.totalElements);   // 156
console.log(pageResult.totalPages);      // 8
```

#### 通用处理函数

```typescript
function getTaskList(data: any): ReviewTaskItem[] {
  // 判断是否为分页结果
  if (data.content && Array.isArray(data.content)) {
    return data.content;  // 分页格式
  }
  return data;  // 数组格式
}

// 使用
const tasks = getTaskList(response.data.data);
```
