【已修复的问题】

1. ✅ 评委端 - 我的任务列表
   问题: GET /api/reviews/tasks 返回400，需要手动传reviewerId参数
   修复: 新增 GET /api/reviews/my-tasks，自动从token获取当前评委ID
   
   前端使用:
   fetch('/api/reviews/my-tasks', {
     headers: { 'Authorization': `Bearer ${token}` }
   })

2. ✅ 参赛者端 - 我的报名列表
   问题: GET /api/registrations/by-applicant 需要手动传applicantId参数
   修复: 新增 GET /api/registrations/my，自动从token获取当前参赛者ID
   
   前端使用:
   fetch('/api/registrations/my', {
     headers: { 'Authorization': `Bearer ${token}` }
   })

3. ✅ 参赛者端 - 创建报名
   问题: POST /api/registrations 需要传applicantId，前端不知道当前用户ID
   修复: applicantId改为从token自动获取，前端只需传4个参数
   
   前端使用:
   fetch('/api/registrations', {
     method: 'POST',
     headers: {
       'Authorization': `Bearer ${token}`,
       'Content-Type': 'application/json'
     },
     body: JSON.stringify({
       competitionId: 21,         // 赛事ID
       institutionId: 1,          // 机构ID
       projectName: '项目名称',   // 项目名称（最多100字）
       groupType: 'BASIC'         // 组别：BASIC 或 ADVANCED
     })
   })

【关键参数说明】

GroupType 组别:
  - BASIC     基础组
  - ADVANCED  高级组

报名状态:
  - DRAFT           草稿（可编辑）
  - PENDING_REVIEW  待审核（不可编辑）
  - APPROVED        已通过
  - REJECTED        已驳回（可退回草稿）
