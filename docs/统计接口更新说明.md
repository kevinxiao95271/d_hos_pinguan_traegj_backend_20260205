# 统计接口更新说明

## 更新时间
2026-02-08 18:58

## 更新内容

### ✅ 新增功能：支持指定赛事ID查询

统计接口 `GET /api/admin/stats/summary` 现在支持通过 `competitionId` 参数查询指定赛事的统计数据。

## 接口变更

### 之前（v1.0）
```
GET /api/admin/stats/summary
```
- 无参数
- 固定返回ID最大的赛事（最新赛事）

### 现在（v1.1）
```
GET /api/admin/stats/summary?competitionId={赛事ID}
```
- 新增可选参数 `competitionId`
- 不传参数：返回ID最大的赛事（保持向后兼容）
- 传参数：返回指定赛事的统计数据

## 使用示例

### 1. 不带参数（默认行为）

```javascript
// 返回最新赛事（ID最大）
fetch('/api/admin/stats/summary', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})

// 响应
{
  "success": true,
  "data": {
    "competitionId": 29,  // 最新赛事
    "competitionName": "2026年省级质量改进赛-2",
    ...
  }
}
```

### 2. 指定赛事ID

```javascript
// 返回赛事21的统计数据
fetch('/api/admin/stats/summary?competitionId=21', {

    'Authorization': `Bearer ${token}`
  }

// 响应
{
  "success": true,

    "competitionId": 21,  // 指定的赛事

    "registrationCount": 45,
    "regionCounts": {
      "杭州": 17,
      "舟山": 15,
      ...
    },
    ...
  }
}
```

## 前端集成建议

### Vue 3 示例

```vue
<template>
  <div>
    <!-- 赛事选择器 -->
    <select v-model="selectedCompetitionId" @change="loadStats">
      <option :value="21">2026浙江品管大赛</option>
      <option :value="29">2026年省级质量改进赛-2</option>
    </select>
    
    <!-- 统计图表 -->
    <div v-if="statsData">
      <h2>{{ statsData.competitionName }}</h2>
      <p>报名总数: {{ statsData.registrationCount }}</p>
      <!-- 图表组件 -->
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { useAuthStore } from '@/stores/auth';

const authStore = useAuthStore();
const selectedCompetitionId = ref(21); // 默认选中赛事21
const statsData = ref(null);

const loadStats = async () => {
  const url = selectedCompetitionId.value 
    ? `/api/admin/stats/summary?competitionId=${selectedCompetitionId.value}`
    : '/api/admin/stats/summary';
  
  const response = await fetch(url, {
    headers: {
      'Authorization': `Bearer ${authStore.token}`
    }
  });
  
  const result = await response.json();
  if (result.success) {
    statsData.value = result.data;
  }
};

// 初始加载
loadStats();
</script>
```

### 通用函数封装

```javascript
/**
 * 获取统计数据
 * @param {number|null} competitionId - 赛事ID，不传则返回最新赛事
 * @param {string} token - 认证token
 * @returns {Promise<Object>} 统计数据
 */
async function getStats(competitionId = null, token) {
  const url = competitionId 
    ? `/api/admin/stats/summary?competitionId=${competitionId}`
    : '/api/admin/stats/summary';
  
  const response = await fetch(url, {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  
  const result = await response.json();
  
  if (result.success) {
    return result.data;
  } else {
    throw new Error(result.message || '获取统计数据失败');
  }
}

// 使用示例
const token = localStorage.getItem('token');

// 获取最新赛事统计
const latestStats = await getStats(null, token);

// 获取指定赛事统计
const competition21Stats = await getStats(21, token);
```

## 后端代码变更

### StatsService.java

```java
// 新增方法：按赛事ID查询
@Transactional(readOnly = true)
public StatsSummaryResponse summaryForCompetition(Long competitionId) {
    Competition competition = competitionRepository.findById(competitionId)
            .orElseThrow(() -> new IllegalArgumentException("赛事不存在"));
    // ... 统计逻辑
}

// 原有方法：查询最新赛事（调用新方法）
@Transactional(readOnly = true)
public StatsSummaryResponse summaryForLatestCompetition() {
    Competition competition = competitionRepository.findAll().stream()
            .max(Comparator.comparing(Competition::getId))
            .orElseThrow(() -> new IllegalArgumentException("暂无赛事"));
    return summaryForCompetition(competition.getId());
}
```

### AdminController.java

```java
@GetMapping("/stats/summary")
@Operation(summary = "统计汇总")
public ApiResponse<StatsSummaryResponse> summary(
    @RequestParam(required = false) Long competitionId
) {
    if (competitionId != null) {
        return ApiResponse.ok(statsService.summaryForCompetition(competitionId));
    }
    return ApiResponse.ok(statsService.summaryForLatestCompetition());
}
```

## 错误处理

### 赛事不存在

```javascript
// 请求
GET /api/admin/stats/summary?competitionId=999

// 响应
{
  "success": false,
  "data": null,
  "message": "赛事不存在"
}
```

### 前端错误处理示例

```javascript
async function loadStats(competitionId) {
  try {
    const url = competitionId 
      ? `/api/admin/stats/summary?competitionId=${competitionId}`
      : '/api/admin/stats/summary';
    
    const response = await fetch(url, {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    
    const result = await response.json();
    
    if (!result.success) {
      // 赛事不存在或其他错误
      alert(result.message || '获取统计数据失败');
      return null;
    }
    
    return result.data;
    
  } catch (error) {
    console.error('获取统计数据失败:', error);
    alert('获取统计数据失败，请稍后重试');
    return null;
  }
}
```
