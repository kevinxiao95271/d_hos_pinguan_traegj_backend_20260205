# 注册登录功能 - 快速开始（邮箱版）

## 一、为什么选择邮箱优先？

✅ **零成本**：无需申请短信服务，立即可用  
✅ **快速验证**：先跑通业务流程，再优化体验  
✅ **平滑迁移**：架构设计保证未来切换到短信只需改配置  
✅ **开发友好**：本地测试方便，无需真实短信账号  

## 二、架构设计（关键）

```
VerificationService (接口)
    ├── EmailVerificationService (Phase 1 - 当前)
    └── SmsVerificationService (Phase 2 - 未来)
```

**核心优势**：业务层只依赖接口，切换实现无需改代码！

## 三、数据库设计（通用）

```sql
-- 验证码表（邮箱和短信共用）
CREATE TABLE verification_codes (
    id BIGSERIAL PRIMARY KEY,
    recipient VARCHAR(128) NOT NULL,  -- 邮箱或手机号
    code VARCHAR(6) NOT NULL,
    purpose VARCHAR(32) NOT NULL,
    is_used BOOLEAN DEFAULT FALSE,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**设计要点**：
- `recipient` 字段既能存邮箱也能存手机号
- 表名和字段名都是通用的，不含"email"或"sms"
- 未来切换到短信，表结构无需改动

## 四、快速配置邮件服务

### 方案1：QQ邮箱（推荐）

1. 登录QQ邮箱 → 设置 → 账户
2. 开启"POP3/SMTP服务"
3. 生成授权码（不是QQ密码！）
4. 配置application.yml：

```yaml
spring:
  mail:
    host: smtp.qq.com
    port: 587
    username: your_email@qq.com
    password: your_authorization_code  # 授权码
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
            required: true

app:
  verification:
    type: email
    code:
      length: 6
      expires-in-seconds: 300
      rate-limit-seconds: 60
      daily-limit: 10
```

### 方案2：163邮箱

```yaml
spring:
  mail:
    host: smtp.163.com
    port: 465
    username: your_email@163.com
    password: your_authorization_code
    properties:
      mail:
        smtp:
          auth: true
          ssl:
            enable: true
```

## 五、核心代码实现

### 5.1 抽象接口
```java
public interface VerificationService {
    String sendCode(String recipient, VerificationPurpose purpose);
    boolean verifyCode(String recipient, String code, VerificationPurpose purpose);
    boolean checkRateLimit(String recipient);
}
```

### 5.2 邮箱实现
```java
@Service
@ConditionalOnProperty(name = "app.verification.type", havingValue = "email")
public class EmailVerificationService implements VerificationService {
    
    @Autowired
    private JavaMailSender mailSender;
    
    @Autowired
    private VerificationCodeRepository codeRepository;
    
    @Value("${spring.mail.username}")
    private String fromEmail;
    
    @Override
    public String sendCode(String email, VerificationPurpose purpose) {
        // 1. 检查频率限制
        if (!checkRateLimit(email)) {
            throw new BusinessException("发送过于频繁，请稍后再试");
        }
        
        // 2. 生成验证码
        String code = generateCode();
        
        // 3. 保存到数据库
        VerificationCode entity = VerificationCode.builder()
            .recipient(email)
            .code(code)
            .purpose(purpose)
            .expiresAt(LocalDateTime.now().plusMinutes(5))
            .build();
        codeRepository.save(entity);
        
        // 4. 发送邮件
        sendEmail(email, code, purpose);
        
        return entity.getId().toString();
    }
    
    private void sendEmail(String to, String code, VerificationPurpose purpose) {
        SimpleMailMessage message = new SimpleMailMessage();
        message.setFrom(fromEmail);
        message.setTo(to);
        message.setSubject(getSubject(purpose));
        message.setText(getEmailContent(code, purpose));
        mailSender.send(message);
    }
    
    private String getEmailContent(String code, VerificationPurpose purpose) {
        String action = switch (purpose) {
            case REGISTER -> "注册";
            case LOGIN -> "登录";
            case RESET_PASSWORD -> "重置密码";
        };
        
        return String.format("""
            您好！
            
            您正在进行%s操作，验证码为：
            
            【%s】
            
            验证码5分钟内有效，请勿泄露给他人。
            
            如非本人操作，请忽略此邮件。
            
            ---
            品管圈评审平台
            """, action, code);
    }
}
```

### 5.3 开发环境Mock

@Profile("dev")
public class MockVerificationService implements VerificationService {
    
    private static final String MOCK_CODE = "888888";

    }

## 十、常见问题

### Q1: 邮件发送失败？
A: 检查授权码是否正确，确认开启了SMTP服务

### Q2: 邮件进垃圾箱？
A: 正常现象，提醒用户检查垃圾箱

### Q3: 验证码收不到？
A: 
1. 检查邮箱地址是否正确
2. 查看后端日志是否有异常
3. 检查邮件服务器配置

### Q4: 开发环境如何测试？
A: 使用Mock服务，固定验证码888888

### Q5: 切换到短信需要改数据库吗？
A: 不需要！表结构完全兼容
