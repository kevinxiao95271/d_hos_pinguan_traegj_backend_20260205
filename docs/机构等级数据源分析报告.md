## 📋 SQL 脚本示例

### 查询所有三级医院的报名

```sql
SELECT 
    r.id,
    r.project_name,
    i.name as institution_name,
    i.level,
    r.status,
    r.group_type
FROM registrations r
JOIN const_init_institutions i ON r.institution_id = i.id
WHERE r.competition_id = 1
AND i.level LIKE '%三级%'
ORDER BY r.id;
```

### 统计各等级的分布

```sql
SELECT 
    i.level,
    COUNT(*) as count,
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER(), 2) as percentage
FROM registrations r
JOIN const_init_institutions i ON r.institution_id = i.id
WHERE r.competition_id = 1
GROUP BY i.level
ORDER BY count DESC;
```
