## 📝 技术细节

### 问题根源

**历史遗留代码**:
```java
// 字典标签查询已移除，直接使用code作为label
methodLabel = activity.getMethodCode();
```

这个注释和实现表明曾经有人"移除"了字典查询，直接使用 code 作为 label。但这是错误的设计，因为：
1. label 的目的就是显示人类可读的文本
2. 其他方法（`filterRegistrations()`, `StatsService`）都正确使用了字典查询
3. 前端需要中文标签来显示给用户

### 修复原理

使用 `getLabel()` 方法：
```java
private String getLabel(String code) {
    if (code == null || code.trim().isEmpty()) {
        return "未知";
    }
    return dictionaryItemRepository.findByCode(code)
            .map(item -> item.getLabel())
            .orElse(code);  // 如果字典中找不到，fallback 到 code
}
```

这个方法：
1. 从 `dictionary_items` 表查询 code 对应的 label
2. 如果找到，返回中文 label
3. 如果找不到，返回原始 code（比直接抛错更健壮）
