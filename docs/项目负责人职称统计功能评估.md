# 项目负责人职称统计功能评估

## 需求描述

在报名统计API中，增加按项目负责人职称分布的统计维度，用于前端展示饼图。

## 数据分析

### 当前数据情况

通过查询数据库，项目负责人（PARTICIPANT角色）的职称分布如下：

| 职称 | 数量 |
|------|------|
| 主管护师 | 40 |
| 药师 | 28 |
| 技师 | 21 |
| 护师 | 15 |
| 主治医师 | 15 |
| 医师 | 13 |
| 康复治疗师 | 3 |
| **总计** | **135** |

### 数据来源

- **表**: `registration_members`
- **字段**: `title` (职称)
- **筛选条件**: `role = 'PARTICIPANT'` (项目负责人)
- **关联**: 通过 `registration_id` 关联到 `registrations` 表

## 实现细节

### 1. 数据获取逻辑

```java
// 为每个报名找到项目负责人（PARTICIPANT角色）
for (Registration registration : registrations) {
    List<RegistrationMember> members = memberRepository
        .findByRegistrationId(registration.getId());
    
    // 找到第一个PARTICIPANT角色的成员
    for (RegistrationMember member : members) {
        if (member.getRole() == MemberRole.PARTICIPANT) {
            String title = member.getTitle();
            if (title == null || title.trim().isEmpty()) {
                title = "未知";
            }
            leaderTitleCounts.put(title, 
                leaderTitleCounts.getOrDefault(title, 0) + 1);
            break;  // 每个项目只统计一个负责人
        }
    }
}
```

### 2. 空值处理

- 如果成员的 `title` 为空，统计为"未知"
- 如果项目没有PARTICIPANT角色的成员，不计入统计

### 3. 性能优化（可选）

如果数据量增大，可以优化为批量查询：

