## 前端对接

### 快速开始

```javascript
// 1. 调用API
const response = await fetch('/api/admin/stats/summary', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const stats = await response.json().data;

// 2. 获取数据
const leaderTitleCounts = stats.leaderTitleCounts;

// 3. 转换为图表数据
const chartData = Object.entries(leaderTitleCounts).map(([title, count]) => ({
  name: title,
  value: count
}));

// 4. 绘制饼图（ECharts）
const option = {
  title: { text: '项目负责人职称分布' },
  series: [{
    type: 'pie',
    data: chartData
  }]
};
```

## 注意事项

1. **统计规则：** 每个报名项目只统计一个负责人（role=PARTICIPANT的第一个成员）
2. **空值处理：** 职称为空时统计为"未知"
3. **数据格式：** 返回 Map<String, Integer>，前端需转换为数组
4. **空数据：** 无数据时返回空对象 `{}`，不是 null
5. **兼容性：** 不影响现有字段，前端可选择性使用
