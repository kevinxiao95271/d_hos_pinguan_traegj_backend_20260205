# 用户注册登录功能设计方案

## 一、现状分析

### 当前问题
1. **无密码机制**：现有`user_accounts`表没有密码字段
2. **无验证码机制**：没有短信验证码发送和验证功能
3. **loginOrCreate混乱**：登录和注册混在一起，逻辑不清晰
4. **无手机号唯一性校验**：虽然数据库有unique约束，但业务层没有明确处理

### 现有表结构
```sql
user_accounts:
- id (主键)
- phone (唯一，必填)
- name (必填)
- title (职称)
- role (角色，必填)
- institution_id (机构ID，外键)
- reviewer_group_code (评审分组)
- interview_group_code (面谈分组)
- expert_background (专业背景)
- created_at (创建时间)
```

## 二、设计方案

### 方案选择：验证码注册 + 密码/验证码双登录

**核心流程**：
1. 首次注册：手机号 + 验证码 → 设置密码 + 选择机构 → 完成注册
2. 后续登录：手机号 + 密码 OR 手机号 + 验证码
3. 修改密码：旧密码验证 OR 验证码验证 → 设置新密码

**优势**：
- 安全性高：密码+验证码双重保障
- 用户体验好：忘记密码可用验证码登录
- 灵活性强：支持多种登录方式

## 三、数据库变更

### 3.1 user_accounts表新增字段
```sql
ALTER TABLE user_accounts 
ADD COLUMN password_hash VARCHAR(128),  -- 密码哈希（BCrypt）
ADD COLUMN password_salt VARCHAR(64),   -- 密码盐值
ADD COLUMN is_password_set BOOLEAN DEFAULT FALSE,  -- 是否已设置密码
ADD COLUMN last_login_at TIMESTAMP,     -- 最后登录时间
ADD COLUMN updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP;  -- 更新时间
```

### 3.2 新建sms_verification_codes表
```sql
CREATE TABLE sms_verification_codes (
    id BIGSERIAL PRIMARY KEY,
    phone VARCHAR(32) NOT NULL,
    code VARCHAR(6) NOT NULL,
    purpose VARCHAR(32) NOT NULL,  -- REGISTER, LOGIN, RESET_PASSWORD
    is_used BOOLEAN DEFAULT FALSE,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_phone_purpose (phone, purpose),
    INDEX idx_expires_at (expires_at)
);
```

## 四、API接口设计

### 4.1 发送验证码
```
POST /api/auth/send-code
Request:
{
  "phone": "13800138000",
  "purpose": "REGISTER"  // REGISTER, LOGIN, RESET_PASSWORD
}
Response:
{
  "code": 200,
  "message": "验证码已发送",
  "data": {
    "expiresIn": 300  // 5分钟有效期
  }
}
```

**业务规则**：
- 同一手机号60秒内只能发送一次
- 验证码5分钟有效
- 每天同一手机号最多发送10次
- 验证码6位数字

### 4.2 注册（第一步：验证手机号）
```
POST /api/auth/register/verify-phone
Request:
{
  "phone": "13800138000",
  "code": "123456"
}
Response:
{
  "code": 200,
  "message": "验证成功",
  "data": {
    "verifyToken": "xxx",  // 临时token，用于下一步
    "expiresIn": 600  // 10分钟有效
  }
}
```

### 4.3 注册（第二步：完成注册）
```
POST /api/auth/register/complete
Request:
{
  "verifyToken": "xxx",
  "password": "Abc123456",
  "name": "张三",
  "title": "主任医师",
  "institutionId": 1,  // 必填
  "role": "PARTICIPANT"
}
Response:
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": 123,
    "phone": "13800138000",
    "name": "张三",
    "token": "jwt_token_here"
  }
}
```

**业务规则**：
- 手机号唯一性校验
- 机构必选
- 密码强度：8-20位，包含大小写字母和数字
- verifyToken验证通过后立即失效

### 4.4 密码登录
```
POST /api/auth/login/password
Request:
{
  "phone": "13800138000",
  "password": "Abc123456"
}
Response:
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userId": 123,
    "phone": "13800138000",
    "name": "张三",
    "role": "PARTICIPANT",
    "institutionId": 1,
    "institutionName": "浙江省人民医院",
    "token": "jwt_token_here"
  }
}
```

### 4.5 验证码登录
```
POST /api/auth/login/code
Request:
{
  "phone": "13800138000",
  "code": "123456"
}
Response:
{
  "code": 200,
  "message": "登录成功",
  "data": {
    // 同密码登录
  }
}
```

### 4.6 修改密码
```
POST /api/auth/change-password
Headers: Authorization: Bearer {token}
Request:
{
  "oldPassword": "Abc123456",  // 可选，如果提供则验证
  "newPassword": "Xyz789012",
  "verifyCode": "123456"  // 可选，如果没有oldPassword则必填
}
Response:
{
  "code": 200,
  "message": "密码修改成功"
}
```

### 4.7 重置密码（忘记密码）
```
POST /api/auth/reset-password
Request:
{
  "phone": "13800138000",
  "code": "123456",
  "newPassword": "Xyz789012"
}
Response:
{
  "code": 200,
  "message": "密码重置成功"
}
```

## 七、安全考虑

### 7.1 密码安全
- 使用BCrypt加密，自动加盐
- 密码强度校验：8-20位，大小写字母+数字
- 密码不能与手机号相同
- 密码错误5次锁定账号30分钟

### 7.2 验证码安全
- 6位随机数字
- 5分钟有效期
- 验证后立即失效
- 同一手机号60秒内只能发送一次
- 每天最多发送10次

### 7.3 接口安全
- 注册接口需要图形验证码（防机器注册）
- 登录失败记录IP和次数
- 敏感操作需要二次验证

## 八、前端对接要点

### 8.1 注册流程
1. 用户输入手机号 → 点击"获取验证码"
2. 输入验证码 → 点击"下一步"
3. 设置密码 + 填写姓名/职称 + 选择机构 → 点击"完成注册"
4. 自动登录，跳转到首页

### 8.2 登录流程
- Tab切换：密码登录 / 验证码登录
- 密码登录：手机号 + 密码
- 验证码登录：手机号 + 验证码
- "忘记密码"链接 → 重置密码流程

### 8.3 修改密码
- 个人中心 → 修改密码
- 输入旧密码 + 新密码 + 确认新密码
- 或者：获取验证码 + 新密码
