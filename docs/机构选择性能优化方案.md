# 机构选择性能优化方案

## 📊 背景

- **机构总数**: 36,076 家
- **挑战**: 大数据量下拉选择、模糊搜索的性能问题
- **目标**: 实现流畅的用户体验，响应时间 < 500ms

## 🚀 优化方案

### 1. 后端优化

#### 1.1 数据库索引优化

```sql
-- 已有索引
CREATE UNIQUE INDEX idx_uscc ON institutions(uscc);
CREATE UNIQUE INDEX idx_code ON institutions(code);

-- 建议添加的索引（提升搜索性能）
CREATE INDEX idx_name ON institutions(name);
CREATE INDEX idx_region ON institutions(region);
CREATE INDEX idx_level ON institutions(level);
CREATE INDEX idx_name_region ON institutions(name, region);
```

#### 1.2 分页查询

所有查询接口都支持分页，避免一次性加载全部数据：

```java
// 默认每页20条，最大50条
GET /api/institutions/search?page=0&size=20
```

#### 1.3 数据传输优化

使用 `InstitutionSimpleDTO` 代替完整实体，减少70%的数据传输量：

```json
{
  "id": 123,
  "name": "杭州市第一人民医院",
  "region": "杭州市",
  "level": "三甲",
  "usccLast4": "234X",
  "displayText": "杭州市第一人民医院 (杭州市) [三甲]"
}
```

#### 1.4 查询接口分级

| 接口 | 用途 | 返回量 | 性能 |
|------|------|--------|------|
| `/autocomplete` | 输入建议 | 最多20条 | ⚡⚡⚡ |
| `/search` (POST) | 高级搜索 | 分页20-50条 | ⚡⚡ |
| `/hot-regions` | 热门地区 | 10条 | ⚡⚡⚡ |
| `/by-region/{region}` | 地区筛选 | 可能上千条 | ⚡ |
| `/list` (GET) | 全部列表 | 36K+条 | ❌ 慎用 |

### 2. 前端优化

#### 2.1 防抖（Debounce）

用户输入时延迟500ms再发起请求，减少无效请求：

```javascript
// Vue.js 示例
import { debounce } from 'lodash';

export default {
  methods: {
    searchInstitutions: debounce(async function(keyword) {
      if (keyword.length < 2) return; // 至少2个字符才搜索
      
      const response = await this.$http.post('/api/institutions/search', {
        keyword: keyword,
        page: 0,
        size: 20
      });
      
      this.institutions = response.data.data.content;
    }, 500) // 延迟500ms
  }
}
```

#### 2.2 虚拟滚动

对于大列表，使用虚拟滚动只渲染可见区域：

```vue

        {{ item.displayText }}
```

#### 2.3 懒加载 + 无限滚动

```javascript
// 使用 IntersectionObserver 实现无限滚动
export default {
  data() {
    return {
      institutions: [],
      page: 0,
      loading: false,
      hasMore: true
    };
  },
  methods: {
    async loadMore() {
      if (this.loading || !this.hasMore) return;
      
      this.loading = true;
      try {
        const response = await this.$http.post('/api/institutions/search', {
          keyword: this.searchKeyword,
          region: this.selectedRegion,
          page: this.page,
          size: 20
        });
        
        const data = response.data.data;
        this.institutions.push(...data.content);
        this.page++;
        this.hasMore = !data.last;
      } finally {
        this.loading = false;
      }
    }
  },
  mounted() {
    // 监听滚动到底部
    const observer = new IntersectionObserver((entries) => {
      if (entries[0].isIntersecting) {
        this.loadMore();
      }
    });
    observer.observe(this.$refs.loadMoreTrigger);
  }
};
```

#### 2.4 本地缓存

缓存已加载的数据和用户的选择历史：

```javascript
// 使用 localStorage 缓存
const CACHE_KEY = 'institution_cache';
const CACHE_DURATION = 30 * 60 * 1000; // 30分钟

export default {
  methods: {
    async searchInstitutions(keyword) {
      // 检查缓存
      const cacheKey = `${CACHE_KEY}_${keyword}`;
      const cached = this.getCache(cacheKey);
      if (cached) {
        this.institutions = cached;
        return;
      }
      
      // 请求API
      const response = await this.$http.post('/api/institutions/search', {
        keyword: keyword,
        page: 0,
        size: 20
      });
      
      const data = response.data.data.content;
      this.institutions = data;
      
      // 缓存结果
      this.setCache(cacheKey, data);
    },
    
    getCache(key) {
      const item = localStorage.getItem(key);
      if (!item) return null;
      
      const { data, timestamp } = JSON.parse(item);
      if (Date.now() - timestamp > CACHE_DURATION) {
        localStorage.removeItem(key);
        return null;
      }
      
      return data;
    },
    
    setCache(key, data) {
      localStorage.setItem(key, JSON.stringify({
        data: data,
        timestamp: Date.now()
      }));
    }
  }
};
```

#### 2.5 最近使用记录

保存用户最近选择的机构，优先展示：

```javascript
const RECENT_KEY = 'recent_institutions';
const MAX_RECENT = 5;

export default {
  methods: {
    // 保存最近选择
    saveRecentInstitution(institution) {
      let recent = JSON.parse(localStorage.getItem(RECENT_KEY) || '[]');
      
      // 移除重复项
      recent = recent.filter(item => item.id !== institution.id);
      
      // 添加到开头
      recent.unshift(institution);
      
      // 只保留最近5个
      recent = recent.slice(0, MAX_RECENT);
      
      localStorage.setItem(RECENT_KEY, JSON.stringify(recent));
    },
    
    // 获取最近选择
    getRecentInstitutions() {
      return JSON.parse(localStorage.getItem(RECENT_KEY) || '[]');
    }
  }
};
```

### 3. 推荐的用户交互流程

#### 流程 A: 地区优先（推荐）

```
1. 显示热门地区列表 (GET /api/institutions/hot-regions)
   ↓
2. 用户选择地区
   ↓
3. 在该地区内搜索机构 (POST /api/institutions/search)
   - 参数: { region: "杭州市", page: 0, size: 20 }
   ↓
4. 用户输入关键词进一步筛选
   - 参数: { keyword: "人民", region: "杭州市", page: 0, size: 20 }
   ↓
5. 选择机构
```

**优点**: 
- 分步查询，每次返回数据量小
- 符合用户认知习惯
- 性能最优

#### 流程 B: 直接搜索

```
1. 显示搜索框 + 最近使用
   ↓
2. 用户输入关键词（至少2个字符）
   ↓
3. 实时搜索（防抖500ms）
   - GET /api/institutions/autocomplete?prefix=杭州
   或
   - POST /api/institutions/search { keyword: "杭州", page: 0, size: 20 }
   ↓
4. 选择机构
```

**优点**: 
- 快速直达
- 适合明确知道机构名称的用户

#### 流程 C: 组合方式（最佳体验）

```html

    <!-- 步骤1：最近使用 -->
    <div v-if="recentInstitutions.length" class="recent-section">

      <el-tag 
        v-for="region in hotRegions" 
        :key="region.region"
        @click="selectRegion(region.region)"
        class="region-tag">
        {{ region.region }} ({{ region.count }})
      </el-tag>
      
      <el-select v-model="selectedRegion" 
                 placeholder="或选择其他地区"
                 filterable
                 @change="onRegionChange">
        <el-option v-for="r in allRegions" 
                   :key="r" 
                   :value="r" 
                   :label="r">
        </el-option>
      </el-select>
    </div>
    
    <!-- 步骤3：搜索机构 -->
    <div class="search-section">
      <el-input
        v-model="searchKeyword"
        placeholder="输入机构名称搜索"
        @input="onSearch"
        clearable>
        <template #prefix>
          <i class="el-icon-search"></i>
        </template>
      </el-input>
      
      <!-- 自动完成建议 -->
      <div v-if="suggestions.length" class="suggestions">
        <div v-for="inst in suggestions" 
             :key="inst.id"
             @click="selectInstitution(inst)"
             class="suggestion-item">
          <span class="name">{{ inst.name }}</span>
          <span class="region">{{ inst.region }}</span>
          <span class="level">{{ inst.level }}</span>
        </div>
      </div>
    </div>
    
    <!-- 步骤4：结果列表（虚拟滚动） -->
    <div v-if="institutions.length" class="result-section">
      <virtual-scroller
        :items="institutions"
        :item-height="60"
        class="institution-list"
        @scroll-end="loadMore">
        <template #default="{ item }">
          <div @click="selectInstitution(item)" class="institution-item">
            <div class="name">{{ item.name }}</div>
            <div class="meta">
              <span class="region">{{ item.region }}</span>
              <span v-if="item.level" class="level">{{ item.level }}</span>
            </div>
          </div>
        </template>
      </virtual-scroller>
      
      <div v-if="loading" class="loading">加载中...</div>
    </div>
  </div>

<script>
import { debounce } from 'lodash';
import { VirtualScroller } from 'vue-virtual-scroller';

export default {
  components: { VirtualScroller },
  
  data() {
    return {
      selectedRegion: null,
      searchKeyword: '',
      recentInstitutions: [],
      hotRegions: [],
      allRegions: [],
      suggestions: [],
      institutions: [],
      page: 0,
      loading: false,
      hasMore: true
    };
  },
  
  methods: {
    // 加载热门地区
    async loadHotRegions() {
      const response = await this.$http.get('/api/institutions/hot-regions?limit=10');
      this.hotRegions = response.data.data;
    },
    
    // 选择地区
    async selectRegion(region) {
      this.selectedRegion = region;
      this.page = 0;
      this.institutions = [];
      await this.loadInstitutions();
    },
    
    // 搜索（带防抖）
    onSearch: debounce(async function() {
      if (this.searchKeyword.length >= 2) {
        // 显示自动完成建议
        await this.loadSuggestions();
      } else {
        this.suggestions = [];
      }
      
      // 重新搜索
      this.page = 0;
      this.institutions = [];
      await this.loadInstitutions();
    }, 500),
    
    // 加载建议
    async loadSuggestions() {
      const response = await this.$http.get('/api/institutions/autocomplete', {
        params: { prefix: this.searchKeyword }
      });
      this.suggestions = response.data.data;
    },
    
    // 加载机构列表
    async loadInstitutions() {
      if (this.loading || !this.hasMore) return;
      
      this.loading = true;
      try {
        const response = await this.$http.post('/api/institutions/search', {
          keyword: this.searchKeyword || null,
          region: this.selectedRegion || null,
          page: this.page,
          size: 20
        });
        
        const data = response.data.data;
        this.institutions.push(...data.content);
        this.hasMore = !data.last;
      } finally {
        this.loading = false;
      }
    },
    
    // 加载更多
    async loadMore() {
      if (!this.hasMore || this.loading) return;
      this.page++;
      await this.loadInstitutions();
    },
    
    // 选择机构
    selectInstitution(institution) {
      // 保存到最近使用
      this.saveRecentInstitution(institution);
      
      // 触发选择事件
      this.$emit('select', institution);
      
      // 继续原有的报名流程...
    }
  },
  
  mounted() {
    // 加载初始数据
    this.recentInstitutions = this.getRecentInstitutions();
    this.loadHotRegions();
  }
};
</script>
```

## 🔧 数据库优化建议

### 添加索引（提升查询性能）

```sql
-- 机构名称索引（用于LIKE查询）
CREATE INDEX idx_name ON institutions(name);

-- 地区索引
CREATE INDEX idx_region ON institutions(region);

-- 等级索引
CREATE INDEX idx_level ON institutions(level);

-- 组合索引（地区+名称，用于组合查询）
CREATE INDEX idx_region_name ON institutions(region, name);

-- 查看索引效果
EXPLAIN SELECT * FROM institutions 
WHERE region = '杭州市' AND name LIKE '%人民%' 
LIMIT 20;
```

### 查询优化

```sql
-- 优化前（慢）
SELECT * FROM institutions WHERE name LIKE '%医院%';

-- 优化后（快）
SELECT * FROM institutions WHERE name LIKE '杭州%'; -- 使用前缀匹配

-- 或者
SELECT * FROM institutions 
WHERE region = '杭州市' -- 先用精确匹配缩小范围
  AND name LIKE '%医院%' 
LIMIT 20;
```

## 🎯 最佳实践

### DO ✅

1. **使用分页**: 每次只加载20-50条
2. **地区优先**: 先选地区，再搜机构
3. **防抖**: 输入延迟500ms再搜索
4. **虚拟滚动**: 大列表使用虚拟滚动
5. **缓存**: 缓存已加载的数据
6. **最近使用**: 优先展示最近选择

### DON'T ❌

1. **不要**一次性加载全部36K机构
2. **不要**每次输入都立即请求
3. **不要**在下拉框中使用 `v-for` 渲染大列表
4. **不要**忽略loading状态
5. **不要**忘记错误处理

## 🚨 常见问题

### Q1: 用户输入太快，请求太多怎么办？

**A**: 使用防抖（debounce），延迟500ms再发起请求，并在新请求时取消旧请求。

### Q2: 某些地区机构太多，怎么办？

**A**: 结合关键词搜索，比如"杭州市"有844家，用户输入"人民"后缩小到几十家。

### Q3: 用户网络慢，加载很久怎么办？

**A**: 
1. 显示loading状态
2. 实现骨架屏
3. 启用本地缓存
4. 压缩响应数据（Gzip）

### Q4: 数据库查询太慢？

**A**: 
1. 添加数据库索引
2. 使用前缀匹配代替 `%keyword%`
3. 限制结果数量（LIMIT）
4. 考虑使用Redis缓存热门查询
