# 品管工具重复数据清理报告

## 问题描述

前端反馈：`GET /api/dictionaries/method` 接口返回的品管工具数据重复，14个品管工具label重复出现2次。

## 问题原因

数据库中存在两套品管工具字典数据：

1. **旧数据** (ID 12-28): 使用 `method_X` 格式的code
   - method_1, method_2, method_3, ...
   - 共17条记录

2. **新数据** (ID 56, 70-84): 使用语义化的code
   - qc_problem, qc_topic, project_improve, ...
   - 共16条记录

两套数据的label相同，导致API返回重复数据。

## 清理方案

### 1. 检查数据使用情况

检查 `activity_infos` 表中是否有项目使用旧code：

```sql
SELECT method_code, COUNT(*) as count
FROM activity_infos
WHERE method_code LIKE 'method_%'
GROUP BY method_code;
```

**结果**: 发现11个旧code被17个项目使用

### 2. 更新项目数据

将使用旧code的项目更新为新code：

| 旧Code | 新Code | 更新项目数 |
|--------|--------|-----------|

**总计**: 更新了17个项目

### 3. 删除旧数据

删除 `dictionary_items` 表中的旧数据（ID 12-28，共17条）

```sql
DELETE FROM dictionary_items
WHERE type = 'method' AND code LIKE 'method_%';
```
