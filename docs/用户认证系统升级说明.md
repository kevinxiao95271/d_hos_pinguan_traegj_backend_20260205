# 用户认证系统升级说明

## 🔒 安全问题与解决方案

### 问题描述

原系统**没有密码认证机制**，存在严重安全隐患：
- ❌ UserAccount实体没有password字段
- ❌ 登录接口无密码验证（只需手机号）
- ❌ 任何人知道手机号就能冒充登录

### 解决方案

实施**基础密码认证**机制：
- ✅ 添加password字段（BCrypt加密）
- ✅ 新增注册接口（必须设置密码）
- ✅ 新增密码登录接口
- ✅ 添加修改密码功能

## 🚀 新的用户注册和登录流程

### 注册流程

```
步骤1: 选择机构
  ↓ 使用机构选择API
  POST /api/institutions/search
  
步骤2: 填写注册信息
  ↓
  - 手机号（唯一）
  - 密码（6-20位）
  - 确认密码
  - 姓名
  - 职称（可选）
  - 所属机构
  - 其他信息
  
步骤3: 提交注册
  ↓
  POST /api/auth/register
  
步骤4: 自动登录
  ↓
  返回JWT Token
```

### 登录流程

```
步骤1: 输入账号密码
  ↓
  - 手机号
  - 密码
  
步骤2: 提交登录
  ↓
  POST /api/auth/login-with-password
  
步骤3: 验证成功
  ↓
  返回JWT Token + 用户信息
```

## 📡 API接口详解

### 1. 用户注册 ⭐

```http
POST /api/auth/register
Content-Type: application/json

{
  "phone": "13800138000",
  "password": "password123",
  "confirmPassword": "password123",
  "name": "张三",
  "title": "主任医师",
  "role": "CONTESTANT",
  "institutionId": 123,
  "expertBackground": "心内科"
}
```

**字段说明**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | ✅ | 手机号（11位，唯一） |
| password | String | ✅ | 密码（6-20位） |
| confirmPassword | String | ✅ | 确认密码 |
| name | String | ✅ | 真实姓名 |
| title | String | ❌ | 职称 |
| role | Enum | ✅ | 角色（CONTESTANT/REVIEWER/COMMITTEE_ADMIN/OPS） |
| institutionId | Long | ✅ | 所属机构ID |
| reviewerGroupCode | String | ❌ | 评委组代码（评委必填） |
| interviewGroupCode | String | ❌ | 面试组代码（评委可选） |
| expertBackground | String | ❌ | 专家背景（评委可选） |

**响应示例**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "phone": "13800138000",
    "name": "张三",
    "title": "主任医师",
    "role": "CONTESTANT",
    "institutionId": 123,
    "institutionName": "杭州市第一人民医院",
    "institutionCode": "INST_ABC123",
    "institutionUscc": "91330100470001234X",
    "expertBackground": null,
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

**错误响应**:
```json
{
  "success": false,
  "message": "该手机号已注册"
}
```

## 💻 前端集成示例

### Vue.js 完整注册流程

```vue
<template>
  <div class="register-page">
    <!-- 步骤1: 选择机构 -->
    <el-card v-if="step === 1">
      <h2>选择所属机构</h2>
      <institution-selector @select="onInstitutionSelect" />
    </el-card>
    
    <!-- 步骤2: 填写注册信息 -->
    <el-card v-if="step === 2">
      <h2>注册信息</h2>
      <el-form :model="form" :rules="rules" ref="registerForm">
        <el-form-item label="手机号" prop="phone">
          <el-input v-model="form.phone" placeholder="请输入手机号" />
        </el-form-item>
        
        <el-form-item label="密码" prop="password">
          <el-input 
            type="password" 
            v-model="form.password" 
            placeholder="6-20位密码"
            show-password />
        </el-form-item>
        
        <el-form-item label="确认密码" prop="confirmPassword">
          <el-input 
            type="password" 
            v-model="form.confirmPassword" 
            placeholder="再次输入密码"
            show-password />
        </el-form-item>
        
        <el-form-item label="姓名" prop="name">
          <el-input v-model="form.name" placeholder="请输入真实姓名" />
        </el-form-item>
        
        <el-form-item label="职称" prop="title">
          <el-input v-model="form.title" placeholder="如：主任医师" />
        </el-form-item>
        
        <el-form-item label="角色" prop="role">
          <el-select v-model="form.role" placeholder="请选择角色">
            <el-option label="参赛者" value="CONTESTANT" />
            <el-option label="评委" value="REVIEWER" />
          </el-select>
        </el-form-item>
        
        <el-form-item label="所属机构">
          <el-input :value="selectedInstitution.name" disabled />
        </el-form-item>
        
        <el-form-item v-if="form.role === 'REVIEWER'" 
                      label="专家背景" 
                      prop="expertBackground">
          <el-input 
            v-model="form.expertBackground" 
            placeholder="如：心内科" />
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="submitRegister" :loading="loading">
            注册
          </el-button>
          <el-button @click="step = 1">返回</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script>
import InstitutionSelector from './InstitutionSelector.vue';

export default {
  components: { InstitutionSelector },
  
  data() {
    // 自定义密码验证
    const validatePassword = (rule, value, callback) => {
      if (value.length < 6 || value.length > 20) {
        callback(new Error('密码长度必须在6-20位之间'));
      } else {
        callback();
      }
    };
    
    // 确认密码验证
    const validateConfirmPassword = (rule, value, callback) => {
      if (value !== this.form.password) {
        callback(new Error('两次输入的密码不一致'));
      } else {
        callback();
      }
    };
    
    return {
      step: 1,
      selectedInstitution: null,
      loading: false,
      form: {
        phone: '',
        password: '',
        confirmPassword: '',
        name: '',
        title: '',
        role: 'CONTESTANT',
        institutionId: null,
        expertBackground: ''
      },
      rules: {
        phone: [
          { required: true, message: '请输入手机号', trigger: 'blur' },
          { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
        ],
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' },
          { validator: validatePassword, trigger: 'blur' }
        ],
        confirmPassword: [
          { required: true, message: '请再次输入密码', trigger: 'blur' },
          { validator: validateConfirmPassword, trigger: 'blur' }
        ],
        name: [
          { required: true, message: '请输入姓名', trigger: 'blur' }
        ],
        role: [
          { required: true, message: '请选择角色', trigger: 'change' }
        ]
      }
    };
  },
  
  methods: {
    // 机构选择回调
    onInstitutionSelect(institution) {
      this.selectedInstitution = institution;
      this.form.institutionId = institution.id;
      this.step = 2;
    },
    
    // 提交注册
    async submitRegister() {
      // 表单验证
      const valid = await this.$refs.registerForm.validate();
      if (!valid) return;
      
      this.loading = true;
      
      try {
        const response = await this.$http.post('/api/auth/register', this.form);
        
        if (response.data.success) {
          // 保存Token
          const token = response.data.data.token;
          localStorage.setItem('token', token);
          localStorage.setItem('user', JSON.stringify(response.data.data));
          
          this.$message.success('注册成功！');
          
          // 跳转到主页
          this.$router.push('/dashboard');
        } else {
          this.$message.error(response.data.message);
        }
      } catch (error) {
        this.$message.error('注册失败：' + (error.response?.data?.message || error.message));
      } finally {
        this.loading = false;
      }
    }
  }
};
</script>
```

### 登录页面示例

```vue
<template>
  <div class="login-page">
    <el-card class="login-card">
      <h2>用户登录</h2>
      <el-form :model="form" :rules="rules" ref="loginForm">
        <el-form-item prop="phone">
          <el-input 
            v-model="form.phone" 
            placeholder="请输入手机号"
            prefix-icon="el-icon-phone">
          </el-input>
        </el-form-item>
        
        <el-form-item prop="password">
          <el-input 
            type="password"
            v-model="form.password" 
            placeholder="请输入密码"
            prefix-icon="el-icon-lock"
            show-password
            @keyup.enter="submitLogin">
          </el-input>
        </el-form-item>
        
        <el-form-item>
          <el-button 
            type="primary" 
            @click="submitLogin" 
            :loading="loading"
            style="width: 100%">
            登录
          </el-button>
        </el-form-item>
        
        <div class="login-footer">
          <el-link type="primary" @click="$router.push('/register')">
            还没有账号？立即注册
          </el-link>
          <el-link type="info" @click="handleForgotPassword">
            忘记密码？
          </el-link>
        </div>
      </el-form>
    </el-card>
  </div>
</template>

<script>
export default {
  data() {
    return {
      loading: false,
      form: {
        phone: '',
        password: ''
      },
      rules: {
        phone: [
          { required: true, message: '请输入手机号', trigger: 'blur' }
        ],
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' }
        ]
      }
    };
  },
  
  methods: {
    async submitLogin() {
      const valid = await this.$refs.loginForm.validate();
      if (!valid) return;
      
      this.loading = true;
      
      try {
        const response = await this.$http.post(
          '/api/auth/login-with-password', 
          this.form
        );
        
        if (response.data.success) {
          // 保存Token和用户信息
          const token = response.data.data.token;
          localStorage.setItem('token', token);
          localStorage.setItem('user', JSON.stringify(response.data.data));
          
          // 设置axios默认header
          this.$http.defaults.headers.common['Authorization'] = `Bearer ${token}`;
          
          this.$message.success('登录成功！');
          
          // 跳转到主页
          this.$router.push('/dashboard');
        } else {
          this.$message.error(response.data.message);
        }
      } catch (error) {
        this.$message.error('登录失败：' + (error.response?.data?.message || error.message));
      } finally {
        this.loading = false;
      }
    },
    
    handleForgotPassword() {
      this.$message.info('密码重置功能开发中，请联系管理员');
    }
  }
};
</script>
```

## 🔒 密码安全

### 加密方式

使用**BCrypt**加密：
- 强度高：每次加密结果不同
- 抗暴力破解：计算成本高
- 不可逆：无法解密

### 密码要求

**基础要求**:
- 长度：6-20位
- 字符：不限制类型

**建议要求**（可选）:
- 包含数字和字母
- 包含特殊字符
- 定期修改密码

### 安全建议

1. **前端**:
   - 输入密码时使用`<input type="password">`
   - 提供密码强度提示
   - 密码可见/隐藏切换

2. **后端**:
   - 使用BCrypt加密存储
   - 错误信息模糊化（不区分账号不存在还是密码错误）
   - 添加登录失败次数限制（可选）

3. **传输**:
   - 使用HTTPS
   - 不在URL中传递密码
   - 不在日志中记录密码

## 📞 常见问题

### Q1: 现有用户如何登录？

**A**: 三种方式
1. 使用旧的`/api/auth/login`接口（不推荐）
2. 联系管理员重置密码
3. 重新注册新账号

### Q2: 忘记密码怎么办？

**A**: 当前版本需要联系管理员。未来可添加：
- 短信验证码重置
- 邮箱重置链接
- 管理员重置

### Q3: 密码加密可以解密吗？

**A**: 不可以。BCrypt是单向加密，无法解密。忘记密码只能重置。

### Q4: 多次登录失败会锁定账号吗？

**A**: 当前版本没有锁定机制。建议后续添加：
- 5次失败锁定15分钟
- 10次失败锁定1小时
- 需要验证码解锁
