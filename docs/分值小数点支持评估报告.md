# 分值小数点支持评估报告

## 需求说明

- **存储精度**: 支持小数点后一位（如 8.5）
- **展示精度**: 返回给前端小数点后一位（如 8.5）
- **简化方案**: 统一使用一位小数，无需格式化转换

## 当前状态

```sql
plan: int
```

## 改动范围评估

### 1. 数据库改动 (8个字段)

**SQL脚本**:
```sql
ALTER TABLE review_scores 
  MODIFY COLUMN plan DECIMAL(4,1),
  MODIFY COLUMN problem DECIMAL(4,1),
  MODIFY COLUMN action DECIMAL(4,1),
  MODIFY COLUMN success DECIMAL(4,1),
  MODIFY COLUMN review DECIMAL(4,1),
  MODIFY COLUMN operation DECIMAL(4,1),
  MODIFY COLUMN presentation DECIMAL(4,1),
  MODIFY COLUMN total DECIMAL(5,1);
```

**说明**: 
- `DECIMAL(4,1)` 支持 0.0 ~ 999.9
- `DECIMAL(5,1)` 用于total，支持 0.0 ~ 9999.9
- **优势**: 统一精度，无需格式化转换

### 2. Java代码改动

#### 实体类 (1个文件)
- `ReviewScore.java` - 8个字段从 `Integer` 改为 `Double`

#### DTO类 (1个文件)
- `ReviewScoreRequest.java` - 8个字段从 `Integer` 改为 `Double`

#### Service类 (2个文件)
- `ReviewService.java` - 评分提交和统计逻辑
- `StatsService.java` - 统计计算逻辑（已经是Double，无需改动）

#### 响应DTO (无需改动)
- `StatsSummaryResponse.java` - 平均分字段已经是 `Double`
- `ReviewStageScoreSummary.java` - 平均分字段已经是 `Double`
- `ReviewSummaryItem.java` - avgTotal已经是 `Double`
- `ReviewRankingItem.java` - avgTotal已经是 `Double`

### 3. 数据格式化

**无需格式化！**

统一使用1位小数：
- 前端输入: 8.5
- 数据库存储: 8.5
- API返回: 8.5

**前端验证**:
```javascript
// 前端输入框限制

```

### 4. 数据迁移

**现有数据处理**:


## 优势对比

### 方案1: 存储2位，返回1位
- ❌ 需要格式化逻辑（~20行代码）
- ❌ 6个API都需要处理
- ❌ 容易遗漏某个接口
- ✅ 存储精度更高

### 方案2: 统一1位小数 ⭐推荐
- ✅ 无需格式化逻辑
- ✅ 代码改动最小
- ✅ 不会遗漏
- ✅ 前后端一致
- ⚠️ 精度稍低（但对评分场景足够）

## 风险评估

### 低风险
- ✅ 数据库类型兼容：int -> decimal 自动转换
- ✅ Java类型兼容：Integer -> Double 向上兼容
- ✅ 现有数据保留：8 -> 8.0
- ✅ 无需格式化：统一精度，代码简单

### 需注意
- ⚠️ 前端验证：需要支持小数输入（step="0.1"）
- ⚠️ 总分计算：需要处理小数相加（Java自动处理）
- ⚠️ 校验规则：@Min/@Max 对 Double 同样有效

## 涉及的API接口

### 1. 评分提交和查询 (ReviewController)

#### POST /api/reviews/scores
- **功能**: 提交评分
- **请求**: ReviewScoreRequest (8个分值字段)
- **响应**: ReviewScore (8个分值字段)
- **改动**: 请求和响应都需要支持小数

#### GET /api/reviews/scores/{reviewTaskId}
- **功能**: 查询评分详情
- **响应**: ReviewScore (8个分值字段)
- **改动**: 响应需要格式化为1位小数

### 2. 评分汇总和排名 (ReviewController)

#### GET /api/reviews/summary
- **功能**: 阶段评分汇总
- **响应**: List<ReviewSummaryItem>
  - `avgTotal`: Double (平均总分)
- **改动**: 需要格式化为1位小数

#### GET /api/reviews/rankings
- **功能**: 阶段评分排名
- **响应**: List<ReviewRankingItem>
  - `avgTotal`: Double (平均总分)
- **改动**: 需要格式化为1位小数

### 3. 报名评审详情 (RegistrationController)

#### GET /api/registrations/{id}/review-details
- **功能**: 报名评审详情
- **响应**: List<ReviewStageScoreSummary>
  - `avgPlan`, `avgProblem`, `avgAction`, `avgSuccess`
  - `avgReview`, `avgOperation`, `avgPresentation`, `avgTotal`
- **改动**: 8个平均分字段需要格式化为1位小数

### 4. 统计汇总 (AdminController)

#### GET /api/admin/stats/summary
- **功能**: 统计汇总
- **响应**: StatsSummaryResponse
  - `avgPlan`, `avgProblem`, `avgAction`, `avgSuccess`
  - `avgReview`, `avgOperation`, `avgPresentation`
- **改动**: 7个平均分字段需要格式化为1位小数

### 5. 后台退回评分 (AdminReviewController)

#### POST /api/admin/reviews/scores/return
- **功能**: 后台退回评审评分
- **响应**: ReviewTask
- **改动**: 无直接影响（不返回分值）
