================================================================================
  核心API
================================================================================

1. 获取书审排名
   GET /api/admin/reviews/rankings
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK"（必填）
     - groupType: "BASIC" | "ADVANCED" | "COMPREHENSIVE"（可选）
   
   返回：
     [
       {
         "rank": 1,
         "registrationId": 106,
         "projectName": "护理交接班规范化-1",
         "institutionName": "浙江大学医学院附属第一医院",
         "groupType": "BASIC",
         "stage": "BOOK",
         "avgTotal": 88.0
       }
     ]

2. 获取入围名单（带筛选）
   GET /api/admin/reviews/shortlist
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK"（必填）
     - groupType: "BASIC" | "ADVANCED" | "COMPREHENSIVE"（可选）
     - limit: 10（可选，默认10，前N名）
     - minAvgTotal: 85.0（可选，最低分数线）
   
   返回：同上，但只返回符合条件的项目

3. 获取项目详细评分
   GET /api/registrations/{id}/review-details
   
   返回：
     [
       {
         "stage": "BOOK",
         "avgPlan": 18.0,
         "avgProblem": 17.0,
         "avgAction": 19.0,
         "avgSuccess": 18.0,
         "avgReview": 16.0,
         "avgOperation": 0.0,
         "avgPresentation": 0.0,
         "avgTotal": 88.0,
         "highlights": ["亮点1", "亮点2"],
         "weaknesses": ["不足1", "不足2"]
       }
     ]

  前端调用示例（Vue 3）
================================================================================

// 1. 获取所有排名
async function loadRankings() {
  const response = await axios.get('/api/admin/reviews/rankings', {
    params: {
      competitionId: 21,
      stage: 'BOOK',
      groupType: filters.groupType || undefined
    },
    headers: {
      Authorization: `Bearer ${localStorage.getItem('token')}`
    }
  });
  
  return response.data.data;
}

// 2. 获取入围名单（前10名，85分以上）
async function loadShortlist() {
  const response = await axios.get('/api/admin/reviews/shortlist', {
    params: {
      competitionId: 21,
      stage: 'BOOK',
      limit: 10,
      minAvgTotal: 85.0
    },
    headers: {
      Authorization: `Bearer ${localStorage.getItem('token')}`
    }
  });
  
  return response.data.data;
}

// 3. 查看项目详细评分
async function viewDetail(registrationId) {
  const response = await axios.get(
    `/api/registrations/${registrationId}/review-details`,
    {
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    }
  );
  
  const details = response.data.data;
  return details.find(d => d.stage === 'BOOK');
}

================================================================================
  常见问题
================================================================================

Q: 返回空数据？
A: 检查：
   - 是否有完成的评分数据
   - 赛事ID是否正确（21）
   - stage参数是否为"BOOK"
   - token是否有效

Q: 分数线筛选不生效？
A: 确认：
   - 使用 /api/admin/reviews/shortlist 而不是 rankings
   - minAvgTotal参数类型为Double（85.0）

Q: 组别筛选不生效？
A: 确认：
   - groupType参数值为"BASIC"/"ADVANCED"/"COMPREHENSIVE"
   - 使用大写

Q: 详情查看失败？
A: 确认：
   - registrationId正确
   - 该项目已有评分数据
   - 从返回的数组中筛选stage为"BOOK"的数据
