**版本:** v1.0  
**日期:** 2026-02-06

---

## 📋 功能概述

**书审得分**是评委端的核心功能，允许评委对分配给自己的报名项目进行评分。

### 业务流程

```
1. 评委登录系统
   ↓
2. 查看我的评审任务列表
   ↓
3. 选择一个待评审的项目
   ↓
4. 查看项目完整信息（报名表、成员、活动说明、总结等）
   ↓
5. 对项目进行打分（多个维度）
   ↓
6. 填写评审意见和建议
   ↓
7. 提交评分
   ↓
8. 评分状态变为"已完成"
```

### 3. 提交评分 ⭐ 核心接口

```javascript
POST /api/reviews/scores

// 请求
Headers: {
  "Authorization": "Bearer <评委token>",
  "Content-Type": "application/json"
}

Body: {
  "reviewTaskId": 101,           // 评审任务ID（必填）
  
  // 评分项（根据实际评分标准调整）
  "scores": {
    "theme": 90,                  // 主题选择得分 (0-100)
    "process": 85,                // 活动过程得分 (0-100)
    "method": 88,                 // 改进方法得分 (0-100)
    "result": 92,                 // 成果效果得分 (0-100)
    "innovation": 87              // 创新性得分 (0-100)
  },
  
  // 评审意见
  "comments": "项目主题明确，改进措施得当，成效显著。建议进一步深化成果推广。",
  
  // 改进建议
  "suggestions": "1. 建议量化成本效益分析\n2. 加强长期效果跟踪\n3. 扩大应用范围"
}

// 返回
{
  "success": true,
  "data": {
    "id": 201,                    // 评分记录ID
    "reviewTaskId": 101,
    "totalScore": 88.4,           // 总分（加权平均）
    "submittedAt": "2026-02-06T14:30:00",
    "status": "COMPLETED"
  }
}
```

**评分维度说明:**

| 维度 | 权重建议 | 满分 | 说明 |
|-----|----------|------|------|
| theme | 20% | 100 | 主题选择（重要性、针对性） |
| process | 20% | 100 | 活动过程（PDCA完整性） |
| method | 20% | 100 | 改进方法（科学性、创新性） |
| result | 25% | 100 | 成果效果（量化指标、持续性） |
| innovation | 15% | 100 | 创新亮点（特色、可推广性） |

**总分计算公式:**
```
总分 = theme×0.2 + process×0.2 + method×0.2 + result×0.25 + innovation×0.15
```

## 🎨 前端页面设计

### 页面1: 评审任务列表页

**路由:** `/reviewer/tasks`

**页面结构:**
```vue
<template>
  <div class="reviewer-tasks">
    <h2>我的评审任务</h2>
    
    <!-- 筛选器 -->
    <div class="filters">
      <Select v-model="filterStage">
        <Option value="">全部阶段</Option>
        <Option value="BOOK_REVIEW">书面评审</Option>
        <Option value="INTERVIEW">现场答辩</Option>
        <Option value="FINAL">现场决赛</Option>
      </Select>
      
      <Select v-model="filterStatus">
        <Option value="">全部状态</Option>
        <Option value="PENDING">待评审</Option>
        <Option value="COMPLETED">已完成</Option>
      </Select>
    </div>
    
    <!-- 任务列表 -->
    <Table :data="filteredTasks">
      <Column prop="projectName" label="项目名称" width="300"/>
      <Column prop="institutionName" label="机构" width="200"/>
      <Column prop="stage" label="评审阶段" width="120">
        <template #default="{ row }">
          <Tag v-if="row.stage === 'BOOK_REVIEW'" type="primary">书面评审</Tag>
          <Tag v-else-if="row.stage === 'INTERVIEW'" type="warning">现场答辩</Tag>
          <Tag v-else type="danger">现场决赛</Tag>
        </template>
      </Column>
      <Column prop="status" label="状态" width="100">
        <template #default="{ row }">
          <Tag v-if="row.status === 'PENDING'" type="warning">待评审</Tag>
          <Tag v-else type="success">已完成</Tag>
        </template>
      </Column>
      <Column prop="createdAt" label="分配时间" width="180"/>
      <Column label="操作" width="150" fixed="right">
        <template #default="{ row }">
          <Button 
            v-if="row.status === 'PENDING'" 
            type="primary" 
            @click="goToReview(row.id, row.registrationId)">
            去评审
          </Button>
          <Button 
            v-else 
            type="default" 
            @click="viewScore(row.id)">
            查看评分
          </Button>
        </template>
      </Column>
    </Table>
  </div>
</template>

<script>
export default {
  data() {
    return {
      tasks: [],
      filterStage: '',
      filterStatus: ''
    };
  },
  
  computed: {
    filteredTasks() {
      return this.tasks.filter(task => {
        if (this.filterStage && task.stage !== this.filterStage) return false;
        if (this.filterStatus && task.status !== this.filterStatus) return false;
        return true;
      });
    }
  },
  
  async mounted() {
    await this.loadTasks();
  },
  
  methods: {
    async loadTasks() {
      const response = await fetch('/api/reviews/my-tasks', {
        headers: { 'Authorization': `Bearer ${this.$token}` }
      });
      const { data } = await response.json();
      this.tasks = data;
    },
    
    goToReview(taskId, registrationId) {
      this.$router.push(`/reviewer/review/${taskId}/${registrationId}`);
    },
    
    viewScore(taskId) {
      this.$router.push(`/reviewer/score/${taskId}`);
    }
  }
};
</script>
```

export default {

      project: {},

        suggestions: ''

      scoreRules: {
        'scores.theme': [
          { required: true, message: '请为主题选择打分', trigger: 'change' }
        ],
        'scores.process': [
          { required: true, message: '请为活动过程打分', trigger: 'change' }
        ],
        'scores.method': [
          { required: true, message: '请为改进方法打分', trigger: 'change' }
        ],
        'scores.result': [
          { required: true, message: '请为成果效果打分', trigger: 'change' }
        ],
        'scores.innovation': [
          { required: true, message: '请为创新亮点打分', trigger: 'change' }
        ],
        comments: [
          { required: true, message: '请输入综合评价', trigger: 'blur' },
          { min: 10, message: '评价不能少于10个字', trigger: 'blur' }
        ]
      },
      submitting: false
    };
  },
  
  computed: {
    calculatedScore() {
      const s = this.scoreForm.scores;
      return s.theme * 0.2 + s.process * 0.2 + s.method * 0.2 + 
             s.result * 0.25 + s.innovation * 0.15;
    }
  },
  
  async mounted() {
    this.taskId = this.$route.params.taskId;
    this.registrationId = this.$route.params.registrationId;
    this.scoreForm.reviewTaskId = parseInt(this.taskId);
    
    await this.loadProject();
  },
  
  methods: {
    async loadProject() {
      const response = await fetch(`/api/registrations/${this.registrationId}`, {
        headers: { 'Authorization': `Bearer ${this.$token}` }
      });
      const { data } = await response.json();
      this.project = data;
    },
    
    async submitScore() {
      this.$refs.scoreForm.validate(async (valid) => {
        if (!valid) return;
        
        this.submitting = true;
        try {
          const response = await fetch('/api/reviews/scores', {
            method: 'POST',
            headers: {
              'Authorization': `Bearer ${this.$token}`,
              'Content-Type': 'application/json'

            body: JSON.stringify(this.scoreForm)

            this.$message.success('评分提交成功！');
            this.$router.push('/reviewer/tasks');
          } else {
            const error = await response.json();
            this.$message.error(error.message || '提交失败');
          }
        } catch (error) {
          this.$message.error('网络错误');
        } finally {
          this.submitting = false;
        }
      });
    }
  }
};
</script>

          <span style="font-size: 24px; color: #f56c6c; font-weight: bold;">
            {{ score.totalScore }} 分
          </span>
        </DescriptionsItem>
        <DescriptionsItem label="提交时间">{{ score.submittedAt }}</DescriptionsItem>
      </Descriptions>
      
      <Divider/>
      
      <h3>各项得分</h3>
      <Table :data="scoreItems" :show-header="false">
        <Column prop="label" label="项目" width="150"/>
        <Column prop="score" label="得分">
          <template #default="{ row }">
            <Progress 
              :percentage="row.score" 
              :stroke-width="20"
              :text-inside="true"/>
          </template>
        </Column>
      </Table>
      
      <Divider/>
      
      <h3>评审意见</h3>
      <p>{{ score.comments }}</p>
      
      <h3>改进建议</h3>
      <p>{{ score.suggestions || '无' }}</p>
      
      <Button @click="$router.back()">返回</Button>
    </Card>
  </div>
</template>

<script>
export default {
  data() {
    return {
      taskId: null,
      score: {},
      scoreItems: []
    };
  },
  
  async mounted() {
    this.taskId = this.$route.params.taskId;
    await this.loadScore();
  },
  
  methods: {
    async loadScore() {
      const response = await fetch(`/api/reviews/scores/${this.taskId}`, {
        headers: { 'Authorization': `Bearer ${this.$token}` }
      });
      const { data } = await response.json();
      this.score = data;
      
      this.scoreItems = [
        { label: '主题选择', score: data.scores.theme },
        { label: '活动过程', score: data.scores.process },
        { label: '改进方法', score: data.scores.method },
        { label: '成果效果', score: data.scores.result },
        { label: '创新亮点', score: data.scores.innovation }
      ];
    }
  }
};
</script>

## 🎯 关键点总结

1. **4个核心API:**
   - 获取任务列表（myTasks）
   - 查看报名详情（registrations/{id}）
   - 提交评分（scores）⭐
   - 查看评分（scores/{taskId}）

2. **3个核心页面:**
   - 任务列表页（展示、筛选、跳转）
   - 评审打分页（阅读、评分、提交）⭐
   - 评分详情页（只读展示）

3. **评分标准:**
   - 5个维度：主题、过程、方法、成果、创新
   - 每项0-100分
   - 加权计算总分

4. **交互流程:**
   - 查看任务 → 阅读项目 → 打分评价 → 提交 → 完成
