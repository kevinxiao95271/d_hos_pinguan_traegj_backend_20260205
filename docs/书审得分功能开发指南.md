# 书审得分功能开发指南

## 需求分析

### 功能描述
书审得分Tab需要展示书审阶段的评分列表，支持筛选和驳回操作。

### 核心功能
1. **列表展示**：显示所有书审评分记录
2. **筛选功能**：按状态、评委、机构等维度筛选
3. **驳回功能**：管理员可以驳回已提交的评分

## 现有API分析

### 1. 已分配任务列表API
```
GET /api/admin/reviews/tasks?competitionId={id}&stage=BOOK&status={status}
```

**返回字段（AdminReviewTaskItem）：**
- 任务信息：id, stage, status, createdAt
- 报名信息：registrationId, projectName, institutionName, groupType, groupCode
- 评委信息：reviewerId, reviewerName, reviewerTitle, reviewerInstitutionName

**问题：** 缺少评分详情（分数、总分、提交时间等）

### 2. 驳回评分API（已存在）
```
POST /api/admin/reviews/scores/return
Body: { reviewTaskId: Long }
```

**功能：** 删除评分记录，将任务状态改为RETURNED

✅ **此API已存在，无需开发，直接使用即可**

## 需要新增的功能

### 新增API：书审得分列表（带评分详情）

**接口设计：**
```
GET /api/admin/reviews/book-scores
```

**查询参数：**
- competitionId (必填): 赛事ID
- status (可选): 评审状态 (PENDING/CONFIRMED/SCORED/RETURNED)
- reviewerId (可选): 评委ID
- institutionId (可选): 机构ID
- groupType (可选): 组别类型
- reviewerGroupCode (可选): 评委分组代码

**响应DTO（BookScoreItem）：**

## 实现方案

### 方案1：扩展现有API（推荐）
在 `AdminReviewController` 中新增专门的书审得分列表接口。

**优点：**
- 专门针对书审得分场景优化
- 返回数据包含完整的评分信息
- 支持更灵活的筛选条件

### 方案2：前端调用多个API组合
前端先调用任务列表API，再逐个查询评分详情。

**缺点：**
- 性能差（N+1查询问题）
- 前端逻辑复杂
- 不推荐

## 开发步骤

### 1. 创建DTO

创建 `BookScoreItem.java`

### 2. 在ReviewService中添加方法
```java
public List<BookScoreItem> listBookScores(
    Long competitionId,
    ReviewStatus status,
    Long reviewerId,
    Long institutionId,
    GroupType groupType,
    String reviewerGroupCode
)
```

### 3. 在AdminReviewController中添加接口
```java
@GetMapping("/book-scores")
@Operation(summary = "书审得分列表")
public ApiResponse<List<BookScoreItem>> listBookScores(...)
```

### 4. 前端对接

**列表展示：**
- 表格列：项目名称、机构、组别、评委、各项得分、总分、提交时间、状态、操作
- 支持排序：按总分、提交时间排序
- 支持分页

**筛选功能：**
- 状态筛选：全部/待确认/已评分/已驳回
- 评委筛选：下拉选择
- 机构筛选：下拉选择
- 组别筛选：医院组/社区组/其他

**驳回操作：**
- 点击"驳回"按钮
- 弹出确认对话框
- 调用 `POST /api/admin/reviews/scores/return`
- 刷新列表

## 测试要点

1. 列表数据完整性：所有字段正确返回
2. 筛选功能：各筛选条件生效
3. 驳回功能：驳回后状态变为RETURNED，评分记录删除
4. 权限控制：只有管理员可访问
5. 边界情况：无数据、单条数据、大量数据

## 前端示例代码

```javascript
// 获取书审得分列表
const fetchBookScores = async (filters) => {
  const params = new URLSearchParams({
    competitionId: currentCompetitionId,
    ...filters
  });
  
  const response = await fetch(
    `/api/admin/reviews/book-scores?${params}`,
    { headers: { Authorization: `Bearer ${token}` } }
  );
  
  const result = await response.json();
  return result.data;
};

// 驳回评分
const returnScore = async (taskId) => {
  const confirmed = await confirm('确定要驳回此评分吗？');
  if (!confirmed) return;
  
  await fetch('/api/admin/reviews/scores/return', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`
    },
    body: JSON.stringify({ reviewTaskId: taskId })
  });
  
  // 刷新列表
  await fetchBookScores(currentFilters);
};
```

## 注意事项

1. 只返回status=SCORED的任务（已评分）
2. 驳回后任务状态变为RETURNED，不再显示在列表中
3. 评分详情中的operation和presentation在书审阶段为0
4. 支持按总分降序排列，方便查看高分项目
