# 书审得分列表功能 - 交付说明

## 功能概述

为管理员提供书审得分列表页面的后端支持，包括：
1. 展示所有书审评分记录（带完整评分详情）
2. 支持多维度筛选
3. 支持驳回操作（使用现有API）

## 新增API

### 书审得分列表

**接口地址：**
```
GET /api/admin/reviews/book-scores
```

**查询参数：**
- `competitionId` (必填): 赛事ID
- `status` (可选): 评审状态 (PENDING/CONFIRMED/SCORED/RETURNED)
- `reviewerId` (可选): 评委ID
- `institutionId` (可选): 机构ID
- `groupType` (可选): 组别类型 (HOSPITAL/BASIC/COMMUNITY)
- `reviewerGroupCode` (可选): 评委分组代码

### 1. 获取书审得分列表

```javascript
const fetchBookScores = async (competitionId, filters = {}) => {
  const params = new URLSearchParams({
    competitionId,
    ...filters
  });
  
  const response = await fetch(
    `/api/admin/reviews/book-scores?${params}`,
    {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    }
  );
  
  const result = await response.json();
  if (result.success) {
    return result.data;
  }
  throw new Error(result.message);
};
```

```javascript
  const confirmed = confirm('确定要驳回此评分吗？驳回后评委需要重新评分。');

      method: 'POST',
```

## 注意事项

1. **只显示已评分记录**：列表默认只返回 `status=SCORED` 的任务
2. **驳回后状态变更**：驳回后任务状态变为 `RETURNED`，不再出现在列表中
3. **评分记录删除**：驳回操作会删除评分记录，评委需要重新评分
4. **权限控制**：只有管理员可以访问这些接口
5. **排序规则**：列表按提交时间降序排列
6. **机构等级字段**：已包含在响应中，可直接显示
