## 三、API使用说明

### 3.1 批量分组API

**端点**: `POST /api/admin/registrations/batch-classify`

**请求体**:
```json
{
  "registrationIds": [138, 139, 140],  // 项目ID数组
  "groupCode": "C1"                    // 目标分组代码
}
```

**权限要求**: OPS角色

**响应示例**:
```json
{
  "success": true,
  "data": [
    {
      "id": 138,
      "projectName": "住院服务效率提升-33",
      "groupType": "ADVANCED",
      "groupCode": "C1",
      "status": "APPROVED"
    }
  ]
}
```

---

### 3.2 前端字段名注意事项

⚠️ **重要**: 不同API返回的ID字段名不同：

| API | ID字段名 |
|-----|---------|
| `/api/registrations/{id}` | `id` |
| `/api/admin/registrations/filter` | `registrationId` |
| `/api/admin/registrations/batch-classify` | `id` |

前端需要兼容两种字段名：
```javascript
const id = item.id || item.registrationId;
```
