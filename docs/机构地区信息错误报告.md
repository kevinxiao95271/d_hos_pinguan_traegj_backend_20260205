# 机构地区信息错误报告

## 问题描述

报名统计接口返回的地区分布数据不准确，经核查发现是**数据库中机构的地区字段填写错误**。

## 核查结果

### 数据库状态
- 总机构数: 40 个
- 地区字段为空: 0 个
- 有地区信息: 40 个

**结论**: 所有机构都有地区字段，但是**地区信息填写错误**。

## 后端逻辑说明

后端统计接口 (`StatsService.summaryForLatestCompetition()`) 的逻辑：

```java
String region = null;
if (registration.getInstitution() != null) {
    region = registration.getInstitution().getRegion();
}
if (region == null || region.trim().isEmpty()) {
    region = "未知";
}
regionCounts.put(region, regionCounts.getOrDefault(region, 0) + 1);
```

**后端逻辑是正确的**，问题在于数据源。

## 前端显示

前端可能将"未知"翻译为"其他"，但当前数据库中没有地区为空的情况，所以不会出现"未知"或"其他"。

如果前端看到"其他"，可能是：
1. 前端自己的分类逻辑
2. 或者是在测试其他赛事的数据

## 解决方案

### 需要数据维护

请数据管理员更新 `institutions` 表的 `region` 字段，确保：

1. **省级医院**（名称包含"浙江"、"省"）→ 应该标记为 **杭州**
2. **市级医院**（名称包含城市名）→ 应该标记为对应的城市
