# 用户管理系统说明

## 📋 系统概述

根据实际需求调整后的用户管理方案：

### 用户类型

| 用户类型 | 注册方式 | 密码设置 | 说明 |
|---------|---------|---------|------|
| **参赛者（CONTESTANT）** | 自助注册 | 用户自己设置 | 选择机构后直接注册，无需审核 |
| **评委（REVIEWER）** | 管理员创建 | 系统分配 | 固定群体，不开放注册 |
| **管理员（COMMITTEE_ADMIN/OPS）** | 管理员创建 | 系统分配 | 系统管理员 |

### 核心特性

✅ **无需审核** - 参赛者注册后直接可用  
✅ **账号管理** - 管理员可查看、禁用、启用用户  
✅ **评委管理** - 管理员创建评委账号并分配密码  
✅ **状态追踪** - 记录最后登录时间

## 🚀 用户注册流程

### 参赛者注册（自助）

```
1. 选择机构
   ↓
   POST /api/institutions/search
   选择所属医疗机构
   
2. 填写信息
   ↓
   - 手机号（唯一）
   - 密码（6-20位）
   - 姓名
   - 职称（可选）
   
3. 提交注册
   ↓
   POST /api/auth/register
   {
     "phone": "13800138000",
     "password": "password123",
     "confirmPassword": "password123",
     "name": "张三",
     "title": "主任医师",
     "role": "CONTESTANT",
     "institutionId": 123
   }
   
4. 注册成功
   ↓
   自动登录，返回Token
   账号状态：enabled = true（默认启用）
```

### 评委创建（管理员）

```
1. 管理员登录
   ↓
   POST /api/auth/login-with-password
   
2. 创建评委账号
   ↓
   POST /api/admin/users/reviewers
   {
     "phone": "13900139000",
     "name": "李教授",
     "title": "主任医师",
     "institutionId": 456,
     "reviewerGroupCode": "GROUP_A",
     "expertBackground": "心内科"
   }
   
3. 系统返回
   ↓
   {
     "userId": 10,
     "phone": "13900139000",
     "name": "李教授",
     "initialPassword": "123456",  // 6位随机数字
     "institutionName": "某医院"
   }
   
4. 通知评委
   ↓
   管理员通过邮件/短信/电话告知：
   - 手机号：13900139000
   - 初始密码：123456
   - 提醒尽快修改密码
```

## 📡 API接口

### 认证接口（公开）

#### 1. 参赛者注册

```http
POST /api/auth/register
Content-Type: application/json

{
  "phone": "13800138000",
  "password": "password123",
  "confirmPassword": "password123",
  "name": "张三",
  "title": "主任医师",
  "role": "CONTESTANT",
  "institutionId": 123
}
```

**限制**: 仅允许`role: CONTESTANT`，其他角色返回错误

**响应**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "phone": "13800138000",
    "name": "张三",
    "role": "CONTESTANT",
    "institutionId": 123,
    "institutionName": "杭州市第一人民医院",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

---

#### 2. 密码登录

```http
POST /api/auth/login-with-password
Content-Type: application/json

{
  "phone": "13800138000",
  "password": "password123"
}
```

**验证**:
- ✅ 手机号和密码正确
- ✅ 账号未被禁用（enabled = true）
- ✅ 更新最后登录时间

**响应**: 同注册接口

---

#### 3. 修改密码

```http
POST /api/auth/change-password/{userId}
Authorization: Bearer {token}
Content-Type: application/json

{
  "oldPassword": "password123",
  "newPassword": "newpassword456",
  "confirmPassword": "newpassword456"
}
```

**用途**: 
- 用户修改自己的密码
- 评委首次登录后修改初始密码

#### 4. 禁用用户

```http
PUT /api/admin/users/{userId}/disable
Authorization: Bearer {token}
```

**效果**: 
- 用户状态变为 `enabled: false`
- 用户无法登录
- 已登录的Token仍然有效（直到过期）

**用途**: 
- 违规用户处理
- 临时限制访问
- 账号安全管理

---

#### 5. 启用用户

```http
PUT /api/admin/users/{userId}/enable
Authorization: Bearer {token}
```

**效果**: 解除禁用，用户可以正常登录

## 💻 前端集成示例

### Vue.js - 参赛者注册页面

```vue
<template>
  <div class="register-page">
    <!-- 步骤1: 选择机构 -->
    <el-card v-if="step === 1">
      <h2>选择所属机构</h2>
      <institution-selector @select="onInstitutionSelect" />
    </el-card>
    
    <!-- 步骤2: 注册信息 -->
    <el-card v-if="step === 2">
      <h2>注册信息</h2>
      <el-form :model="form" :rules="rules" ref="formRef">
        <el-form-item label="手机号" prop="phone">
          <el-input v-model="form.phone" placeholder="请输入手机号" />
        </el-form-item>
        
        <el-form-item label="密码" prop="password">
          <el-input 
            type="password" 
            v-model="form.password" 
            placeholder="6-20位密码"
            show-password />
        </el-form-item>
        
        <el-form-item label="确认密码" prop="confirmPassword">
          <el-input 
            type="password" 
            v-model="form.confirmPassword" 
            placeholder="再次输入密码"
            show-password />
        </el-form-item>
        
        <el-form-item label="姓名" prop="name">
          <el-input v-model="form.name" placeholder="请输入真实姓名" />
        </el-form-item>
        
        <el-form-item label="职称">
          <el-input v-model="form.title" placeholder="如：主任医师" />
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="register" :loading="loading">
            注册
          </el-button>
          <el-button @click="step = 1">返回</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script>
export default {
  data() {
    return {
      step: 1,
      selectedInstitution: null,
      loading: false,
      form: {
        phone: '',
        password: '',
        confirmPassword: '',
        name: '',
        title: ''
      },
      rules: {
        phone: [
          { required: true, message: '请输入手机号', trigger: 'blur' },
          { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
        ],
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' },
          { min: 6, max: 20, message: '密码长度6-20位', trigger: 'blur' }
        ],
        confirmPassword: [
          { required: true, message: '请再次输入密码', trigger: 'blur' }
        ],
        name: [
          { required: true, message: '请输入姓名', trigger: 'blur' }
        ]
      }
    };
  },
  
  methods: {
    onInstitutionSelect(institution) {
      this.selectedInstitution = institution;
      this.step = 2;
    },
    
    async register() {
      const valid = await this.$refs.formRef.validate();
      if (!valid) return;
      
      if (this.form.password !== this.form.confirmPassword) {
        this.$message.error('两次密码不一致');
        return;
      }
      
      this.loading = true;
      
      try {
        const response = await this.$http.post('/api/auth/register', {
          phone: this.form.phone,
          password: this.form.password,
          confirmPassword: this.form.confirmPassword,
          name: this.form.name,
          title: this.form.title,
          role: 'CONTESTANT',
          institutionId: this.selectedInstitution.id
        });
        
        if (response.data.success) {
          // 保存Token
          localStorage.setItem('token', response.data.data.token);
          localStorage.setItem('user', JSON.stringify(response.data.data));
          
          this.$message.success('注册成功！');
          this.$router.push('/dashboard');
        } else {
          this.$message.error(response.data.message);
        }
      } catch (error) {
        this.$message.error('注册失败：' + (error.response?.data?.message || error.message));
      } finally {
        this.loading = false;
      }
    }
  }
};
</script>
```

        this.createReviewerVisible = false;
        this.passwordVisible = true;
        
        this.loadUsers();
        this.loadStats();
      } finally {
        this.creating = false;
      }
    }
  },
  
  mounted() {
    this.loadStats();
    this.loadUsers();
  }
};
</script>
