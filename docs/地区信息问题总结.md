# 地区信息问题总结

## 问题描述

前端反馈：报名统计接口返回的地区分布中出现"其他"分类。

## 核查结果

### 1. 后端接口逻辑 ✅ 正确

**接口**: `GET /api/admin/stats/summary`

**逻辑**:
```java
String region = registration.getInstitution().getRegion();
if (region == null || region.trim().isEmpty()) {
    region = "未知";
}
```

- 如果机构地区为空，会标记为"未知"
- 前端可能将"未知"翻译为"其他"

### 2. 数据库字段状态 ✅ 字段存在

- `institutions` 表有 `region` 字段
- 所有40个机构都有地区值（无空值）

### 3. 数据质量问题 ❌ **地区信息错误**

**发现17个机构的地区信息填写错误！**
