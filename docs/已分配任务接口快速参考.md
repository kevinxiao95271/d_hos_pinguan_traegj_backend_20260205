# 已分配任务接口 - 快速参考

## 🚀 新接口

```
GET /api/admin/reviews/tasks
```

## 📝 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| competitionId | Long | ✅ | 赛事ID |
| stage | String | ✅ | BOOK/INTERVIEW/FINAL |
| status | String | ❌ | PENDING/SCORED/RETURNED |

## 📊 返回字段

### 任务信息
- `id` - 任务ID
- `stage` - 评审阶段
- `status` - 任务状态
- `createdAt` - 创建时间

### 报名信息
- `registrationId` - 报名ID
- `projectName` - 项目名称 ⭐
- `institutionName` - 医疗机构 ⭐
- `groupType` - 组别 ⭐
- `groupCode` - 分组 ⭐

### 评委信息
- `reviewerId` - 评委ID
- `reviewerName` - 评委姓名 ⭐
- `reviewerTitle` - 职称 ⭐
- `reviewerInstitutionName` - 评委机构 ⭐
- `reviewerGroupCode` - 书审分组
- `interviewGroupCode` - 面谈分组
- `expertBackground` - 专家背景

## 💻 快速调用

### JavaScript

```javascript
// 获取书审阶段所有任务
const response = await fetch(
  '/api/admin/reviews/tasks?competitionId=21&stage=BOOK',
  { headers: { 'Authorization': `Bearer ${token}` } }
);
const result = await response.json();
const tasks = result.data;
```

### Vue 3

```vue
<script setup>
const tasks = ref([]);

const loadTasks = async () => {
  const res = await fetch(
    `/api/admin/reviews/tasks?competitionId=21&stage=BOOK`,
    { headers: { 'Authorization': `Bearer ${token}` } }
  );
  const result = await res.json();
  tasks.value = result.data;
};
</script>
```

### React

```jsx
const [tasks, setTasks] = useState([]);

const loadTasks = async () => {
  const res = await fetch(
    `/api/admin/reviews/tasks?competitionId=21&stage=BOOK`,
    { headers: { 'Authorization': `Bearer ${token}` } }
  );
  const result = await res.json();
  setTasks(result.data);
};
```

## 📋 使用示例

### 查询书审阶段所有任务

```
GET /api/admin/reviews/tasks?competitionId=21&stage=BOOK
```

### 查询面谈阶段待评审任务

```
GET /api/admin/reviews/tasks?competitionId=21&stage=INTERVIEW&status=PENDING
```

### 查询决赛阶段已评分任务

```
GET /api/admin/reviews/tasks?competitionId=21&stage=FINAL&status=SCORED
```

## ⚠️ 注意事项

1. **必须传递 competitionId 和 stage 参数**
2. **使用管理端接口，不要使用评委端接口**
3. **所有字段都有值，不需要额外处理**

## 🔄 旧接口 vs 新接口

### ❌ 旧接口（不要使用）

```javascript
// 评委端接口，需要 reviewerId
GET /api/reviews/tasks?reviewerId={id}

// 返回 ReviewTask 实体，字段被隐藏
GET /api/reviews/tasks/stage?competitionId={id}&stage={stage}
```

### ✅ 新接口（应该使用）

```javascript
// 管理端专用接口，返回完整信息
GET /api/admin/reviews/tasks?competitionId={id}&stage={stage}
```
