# 前端调用统计接口检查清单

## 🔍 快速检查

### 步骤1: 打开浏览器开发者工具

按 `F12` 打开开发者工具，切换到 **Network** 标签

### 步骤2: 触发统计数据加载

刷新页面或切换赛事

### 步骤3: 查找统计接口请求

在 Network 面板中找到 `stats/summary` 请求

### 步骤4: 检查请求URL

#### ✅ 正确的URL（包含 competitionId）

```
http://localhost:6031/api/admin/stats/summary?competitionId=21
```

#### ❌ 错误的URL（缺少 competitionId）

```
http://localhost:6031/api/admin/stats/summary
```

**如果URL中没有 `?competitionId=21`，那就是问题所在！**

### 步骤5: 检查响应数据

点击请求，查看 **Response** 标签：

```json
{
  "success": true,
  "data": {
    "competitionId": 21,  // ← 这个值应该是你选中的赛事ID
    "competitionName": "2026浙江品管大赛",
    "registrationCount": 45,  // ← 赛事21有45条报名
    "regionCounts": {
      "杭州": 17,
      "舟山": 15,
      ...
    }
  }
}
```

## 🐛 常见问题排查

### 问题1: 看到的数据不是当前选中的赛事

**症状**: 选中赛事21，但看到的是赛事29的数据（只有1条报名）

**原因**: 没有传递 `competitionId` 参数

**解决**:
```javascript
// ❌ 错误
fetch('/api/admin/stats/summary')

// ✅ 正确
fetch(`/api/admin/stats/summary?competitionId=${currentCompetitionId}`)
```

### 问题2: 切换赛事后数据不更新

**症状**: 切换赛事后，统计数据没有变化

**原因**: 没有监听赛事切换事件

**解决**:
```javascript
// Vue 3
watch(currentCompetitionId, () => {
  loadStats();
});

// React
useEffect(() => {
  loadStats();
}, [currentCompetitionId]);
```

### 问题3: 地区分布中出现"其他"

**症状**: 地区分布饼图中有"其他"分类

**原因**: 可能是前端的图表配置或分类逻辑

**排查**:
1. 打印原始数据：`console.log(result.data.regionCounts)`
2. 检查是否有"其他"键：`'其他' in result.data.regionCounts`
3. 检查图表配置是否有自动合并选项

**如果原始数据中没有"其他"，那是前端图表的问题，不是后端的问题！**

### 问题4: 数据不匹配

**症状**: 返回的赛事ID与请求的不一致

**排查**:
```javascript
console.log('请求的赛事ID:', currentCompetitionId);
console.log('返回的赛事ID:', result.data.competitionId);

if (result.data.competitionId !== currentCompetitionId) {
  console.error('⚠️ 赛事ID不匹配！');
}
```

## 📝 完整的调试代码

将以下代码添加到你的统计数据加载函数中：

```javascript
async function loadStats() {
  console.group('📊 加载统计数据');
  
  // 1. 检查当前赛事ID
  console.log('1️⃣ 当前选中的赛事ID:', currentCompetitionId);
  
  if (!currentCompetitionId) {
    console.error('❌ 未选择赛事！');
    console.groupEnd();
    return;
  }
  
  // 2. 构建URL
  const url = `/api/admin/stats/summary?competitionId=${currentCompetitionId}`;
  console.log('2️⃣ 请求URL:', url);
  
  try {
    // 3. 发送请求
    console.log('3️⃣ 发送请求...');
    const response = await fetch(url, {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    });
    
    // 4. 检查响应
    console.log('4️⃣ 响应状态:', response.status);
    
    const result = await response.json();
    
    if (result.success) {
      const data = result.data;
      
      // 5. 验证返回的数据
      console.log('5️⃣ 返回的数据:');
      console.log('  - 赛事ID:', data.competitionId);
      console.log('  - 赛事名称:', data.competitionName);
      console.log('  - 报名总数:', data.registrationCount);
      
      // 6. 检查赛事ID是否匹配
      if (data.competitionId !== currentCompetitionId) {
        console.error('❌ 赛事ID不匹配！');
        console.error('  期望:', currentCompetitionId);
        console.error('  实际:', data.competitionId);
      } else {
        console.log('✅ 赛事ID匹配');
      }
      
      // 7. 检查地区分布
      console.log('6️⃣ 地区分布:');
      console.table(data.regionCounts);
      
      // 8. 检查是否有"其他"
      if ('其他' in data.regionCounts || '未知' in data.regionCounts) {
        console.warn('⚠️ 地区分布中包含"其他"或"未知"');
      } else {
        console.log('✅ 地区分布正常，没有"其他"分类');
      }
      
      console.log('✅ 数据加载成功');
      
    } else {
      console.error('❌ API返回失败:', result.message);
    }
    
  } catch (error) {
    console.error('❌ 请求失败:', error);
  }
  
  console.groupEnd();
}
```

## 🎯 快速验证

在浏览器控制台执行以下代码：

```javascript
// 快速验证当前的统计数据
(async function() {
  const token = localStorage.getItem('token');
  const competitionId = 21; // 改成你要测试的赛事ID
  
  const response = await fetch(
    `/api/admin/stats/summary?competitionId=${competitionId}`,
    { headers: { 'Authorization': `Bearer ${token}` } }
  );
  
  const result = await response.json();
  
  console.log('赛事ID:', result.data.competitionId);
  console.log('赛事名称:', result.data.competitionName);
  console.log('报名数:', result.data.registrationCount);
  console.log('地区分布:', result.data.regionCounts);
  
  // 检查是否有"其他"
  if ('其他' in result.data.regionCounts) {
    console.error('❌ 发现"其他"分类');
  } else {
    console.log('✅ 没有"其他"分类');
  }
})();
```
