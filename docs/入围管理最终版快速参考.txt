================================================================================
                   入围管理页面快速参考（最终版）
================================================================================

✅ 入围管理只包含两个阶段：书审入围 + 面谈入围

重要说明：
  - 入围管理 = 筛选进入下一阶段的项目
  - 书审入围 → 筛选进入面谈的项目
  - 面谈入围 → 筛选进入决赛的项目
  - 决赛不属于"入围"，是最终比赛阶段

================================================================================
  两个入围阶段
================================================================================

📘 书审入围
   - 查看书审得分排名
   - 设置入围分数线和数量
   - 筛选进入面谈的项目

🎤 面谈入围
   - 查看面谈得分排名
   - 设置入围分数线和数量
   - 筛选进入决赛的项目

================================================================================
  核心API
================================================================================

1. 获取评分排名
   GET /api/admin/reviews/rankings
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK" | "INTERVIEW"（必填）⭐ 只有这两个值
     - groupType: "BASIC" | "ADVANCED" | "COMPREHENSIVE"（可选）
   
   返回：
     [
       {
         "rank": 1,
         "registrationId": 106,
         "projectName": "护理交接班规范化-1",
         "institutionName": "浙江大学医学院附属第一医院",
         "groupType": "BASIC",
         "stage": "BOOK",  // 或 "INTERVIEW"
         "avgTotal": 88.0
       }
     ]

2. 获取入围名单
   GET /api/admin/reviews/shortlist
   
   参数：
     - competitionId: 21（必填）
     - stage: "BOOK" | "INTERVIEW"（必填）⭐
     - groupType: 可选
     - limit: 10（可选，前N名）
     - minAvgTotal: 85.0（可选，最低分数线）

3. 获取项目详细评分
   GET /api/registrations/{id}/review-details
   
   返回：所有阶段的评分（书审、面谈、决赛）
     [
       { "stage": "BOOK", "avgTotal": 88.0, ... },
       { "stage": "INTERVIEW", "avgTotal": 90.0, ... },
       { "stage": "FINAL", "avgTotal": 91.0, ... }  // 决赛也会返回
     ]
   
   ⭐ 前端处理：只展示书审和面谈，过滤掉决赛
     const scoreDetails = allDetails.filter(d => 
       d.stage === 'BOOK' || d.stage === 'INTERVIEW'
     );

================================================================================
  前端调用示例（Vue 3）
================================================================================

// 当前入围阶段（只有书审和面谈）
const currentStage = ref('BOOK');  // 'BOOK' 或 'INTERVIEW'

// 1. 获取当前阶段排名
async function loadRankings() {
  const response = await axios.get('/api/admin/reviews/rankings', {
    params: {
      competitionId: 21,
      stage: currentStage.value,  // 'BOOK' 或 'INTERVIEW'
      groupType: filters.groupType || undefined
    },
    headers: {
      Authorization: `Bearer ${localStorage.getItem('token')}`
    }
  });
  
  return response.data.data;
}

// 2. 切换入围阶段
function switchStage(stage) {
  currentStage.value = stage;  // 'BOOK' 或 'INTERVIEW'
  loadRankings();
}

// 3. 查看项目详情（只展示书审和面谈）
async function viewDetail(registrationId) {
  const response = await axios.get(
    `/api/registrations/${registrationId}/review-details`,
    {
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    }
  );
  
  const allDetails = response.data.data;
  // ⭐ 只保留书审和面谈，过滤掉决赛
  const scoreDetails = allDetails.filter(d => 
    d.stage === 'BOOK' || d.stage === 'INTERVIEW'
  );
  
  return scoreDetails;
}

================================================================================
  常见问题
================================================================================

Q: 为什么入围管理不包括决赛？
A: 入围 = 筛选进入下一阶段的项目。决赛是最终比赛阶段，
   不需要再"入围"下一阶段，所以决赛成绩应该在其他页面
   （如成绩管理、结果公示）查看。

Q: 查看详情时返回了决赛数据怎么办？
A: 后端会返回所有阶段的评分，前端需要过滤：
   scoreDetails = allDetails.filter(d => 
     d.stage === 'BOOK' || d.stage === 'INTERVIEW'
   );

Q: 如何区分书审入围和面谈入围？
A: 通过 stage 参数：
   - stage=BOOK → 书审入围（筛选进入面谈）
   - stage=INTERVIEW → 面谈入围（筛选进入决赛）

Q: 页面标题应该叫什么？
A: "入围管理" 或 "入围名单管理"
   不要叫"评分管理"或"成绩管理"
