# 分值小数点支持 - 前端对接文档

## 变更概述

**生效时间**: 2026-02-10  
**变更内容**: 所有评分字段从整数改为小数（支持1位小数）

---

## API变更清单

### 涉及的6个API

| API | 变更内容 |
|-----|---------|
| POST /api/reviews/scores | 请求和响应的8个分值字段改为小数 |
| GET /api/reviews/scores/{id} | 响应的8个分值字段改为小数 |
| GET /api/reviews/summary | avgTotal改为小数 |
| GET /api/reviews/rankings | avgTotal改为小数 |
| GET /api/registrations/{id}/review-details | 8个avg字段改为小数 |
| GET /api/admin/stats/summary | 7个avg字段改为小数 |

---

## 字段类型变更

### 变更前后对比

```json
// 变更前
{
  "plan": 18,           // Integer
  "problem": 17,        // Integer
  "total": 88           // Integer
}

// 变更后
{
  "plan": 18.5,         // Double (1位小数)
  "problem": 17.8,      // Double (1位小数)
  "total": 94.0         // Double (1位小数)
}
```

## 详细接口说明

### 1. POST /api/reviews/scores - 提交评分

**请求示例**:
```json
{
  "reviewTaskId": 101,
  "plan": 18.5,          // 支持小数
  "problem": 17.8,
  "action": 19.2,
  "success": 14.5,
  "review": 9.8,
  "operation": 9.5,
  "presentation": 4.7,
  "highlight": "优点",
  "weakness": "缺点"
}
```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "id": 49,
    "plan": 18.5,        // 返回小数
    "problem": 17.8,
    "action": 19.2,
    "success": 14.5,
    "review": 9.8,
    "operation": 9.5,
    "presentation": 4.7,
    "total": 94.0,       // 自动计算
    "highlight": "优点",
    "weakness": "缺点",
    "submittedAt": "2026-02-10T17:00:00"
  }
}
```

**字段说明**:
- 每个分值: 0.0 ~ 100.0
- 支持1位小数（如 8.5）
- total由后端自动计算

## 前端适配要点

### 1. 输入框配置
```html
<input 
  type="number" 
  step="0.1"           <!-- 步长0.1 -->
  min="0" 
  max="100"
/>
```

### 2. 显示格式化
```javascript
// 统一显示1位小数
score.toFixed(1)  // 18.5 → "18.5"
```

### 3. 表单验证
```javascript
// 范围: 0.0 ~ 100.0
// 精度: 最多1位小数
const isValid = /^\d+(\.\d{1})?$/.test(value) && 
                value >= 0 && value <= 100;
```
