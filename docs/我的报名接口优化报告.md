# 我的报名接口优化报告

## 📋 问题描述

参赛者端的"我的报名"接口（`GET /api/registrations/my`）返回的数据中，没有携带机构信息和机构等级。

## 🔍 问题原因

原接口直接返回 `Registration` 实体，该实体中的 `institution` 字段使用了 `@JsonIgnore` 注解，导致序列化时不包含机构信息。

```java
@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = "institution_id")
@JsonIgnore  // ← 这导致机构信息不会被序列化
private Institution institution;
```

## ✅ 解决方案

### 1. 创建新的 DTO

创建 `MyRegistrationItem` DTO，包含所有需要的字段：

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class MyRegistrationItem {
    private Long id;
    private String projectName;
    private GroupType groupType;
    private String groupCode;
    private RegistrationStatus status;
    private LocalDateTime submittedAt;
    private LocalDateTime createdAt;
    
    // 机构信息
    private Long institutionId;
    private String institutionName;
    private String institutionLevel;
    
    // 赛事信息
    private Long competitionId;
    private String competitionName;
}
```

### 2. 在 RegistrationService 中添加新方法

```java
@Transactional(readOnly = true)
public List<MyRegistrationItem> listMyRegistrations(Long applicantId) {
    List<Registration> registrations = registrationRepository.findByApplicantId(applicantId);
    
    return registrations.stream()
            .map(reg -> {
                Institution institution = reg.getInstitution();
                Competition competition = reg.getCompetition();
                
                return MyRegistrationItem.builder()
                        .id(reg.getId())
                        .projectName(reg.getProjectName())
                        .groupType(reg.getGroupType())
                        .groupCode(reg.getGroupCode())
                        .status(reg.getStatus())
                        .submittedAt(reg.getSubmittedAt())
                        .createdAt(reg.getCreatedAt())
                        // 机构信息
                        .institutionId(institution != null ? institution.getId() : null)
                        .institutionName(institution != null ? institution.getName() : null)
                        .institutionLevel(institution != null ? institution.getLevel() : null)
                        // 赛事信息
                        .competitionId(competition != null ? competition.getId() : null)
                        .competitionName(competition != null ? competition.getName() : null)
                        .build();
            })
            .collect(Collectors.toList());
}
```

### 3. 修改 RegistrationController

```java
@GetMapping("/my")
@Operation(summary = "我的报名列表（参赛者端）")
public ApiResponse<List<MyRegistrationItem>> myRegistrations() {
    Long applicantId = getCurrentUserId();
    return ApiResponse.ok(registrationService.listMyRegistrations(applicantId));
}
```

## 📝 接口说明

### 接口定义

```
GET /api/registrations/my
```

### 请求参数

无需参数，从token中自动获取当前登录用户ID。

### 返回数据

```json

### 字段说明

#### 报名信息
- `id`: 报名ID
- `projectName`: 项目名称
- `groupType`: 组别（BASIC=基层组, COMPREHENSIVE=综合组, ADVANCED=进阶组）
- `groupCode`: 分组代码（A1, A2, B1, B2等）
- `status`: 状态（DRAFT=草稿, SUBMITTED=已提交, APPROVED=已通过, REJECTED=已拒绝）
- `submittedAt`: 提交时间
- `createdAt`: 创建时间

#### 机构信息（新增）
- `institutionId`: 机构ID
- `institutionName`: 机构名称
- `institutionLevel`: 机构等级（三级甲等、三级乙等、二级甲等等）

#### 赛事信息（新增）
- `competitionId`: 赛事ID
- `competitionName`: 赛事名称

<script setup>
import { ref, onMounted } from 'vue';
import { useAuthStore } from '@/stores/auth';

const authStore = useAuthStore();
const registrations = ref([]);

const loadMyRegistrations = async () => {
  try {
    const response = await fetch('/api/registrations/my', {
      headers: {
        'Authorization': `Bearer ${authStore.token}`
      }
    });
    
    const result = await response.json();
    
    if (result.success) {
      registrations.value = result.data;
    } else {
      console.error('获取报名列表失败:', result.message);
    }
  } catch (error) {
    console.error('请求失败:', error);
  }
};

const groupTypeLabel = (type) => {
  const labels = {
    'BASIC': '基层组',
    'COMPREHENSIVE': '综合组',
    'ADVANCED': '进阶组'
  };
  return labels[type] || type;
};

const statusLabel = (status) => {
  const labels = {
    'DRAFT': '草稿',
    'SUBMITTED': '已提交',
    'APPROVED': '已通过',
    'REJECTED': '已拒绝'
  };
  return labels[status] || status;
};

onMounted(() => {
  loadMyRegistrations();
});
</script>
```

      setLoading(false);
    }
  };
  
  const groupTypeLabel = (type) => {
    const labels = {
      'BASIC': '基层组',
      'COMPREHENSIVE': '综合组',
      'ADVANCED': '进阶组'
    };
    return labels[type] || type;
  };
  
  const statusLabel = (status) => {

      'DRAFT': '草稿',

    return labels[status] || status;

  return (

      <thead>
        <tr>
          <th>项目名称</th>

            <td>{groupTypeLabel(reg.groupType)}</td>
            <td>{statusLabel(reg.status)}</td>
            <td>{reg.competitionName}</td>

        ))}

  );
}
