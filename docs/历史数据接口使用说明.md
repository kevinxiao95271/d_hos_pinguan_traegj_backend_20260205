## 📝 查询参数

| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| region | String | 否 | 地区（模糊匹配） | 杭州 |
| competitionGroup | String | 否 | 组别（精确匹配） | 综合组 |
| circleName | String | 否 | 品管工具/圈名（模糊） | 肾利圈 |
| dataStatus | String | 否 | 入围状态（精确） | 已提交 |
| institutionName | String | 否 | 医院名称（模糊） | 人民医院 |
| projectName | String | 否 | 项目名称（模糊） | 提高 |
| **year** | **String** | **否** | **年份（精确）** | **2024** |
| page | Integer | 否 | 页码（从0开始） | 0 |
| size | Integer | 否 | 每页大小 | 20 |
| sortBy | String | 否 | 排序字段 | id |
| sortDirection | String | 否 | 排序方向 | DESC |

## 🎯 使用示例

### 1. 登录获取 Token

```javascript
const response = await fetch('http://localhost:6031/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    phone: '13800000041',
    name: 'CommitteeAdmin A',
    role: 'COMMITTEE_ADMIN'
  })
});
const result = await response.json();
const token = result.data.token;
```

### 2. 基本查询

```javascript
const response = await fetch('http://localhost:6031/api/historical-data?page=0&size=10', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const result = await response.json();
console.log(`总记录数: ${result.data.totalElements}`);
```

### 3. 按年份查询

```javascript
// 查询2024年数据
const response = await fetch('http://localhost:6031/api/historical-data?year=2024&page=0&size=20', {
  headers: { 'Authorization': `Bearer ${token}` }
});
```

### 4. 按地区查询

```javascript
// 查询杭州地区
```

## 🎨 前端集成

### Vue.js 示例

```vue
<template>
  <div>
    <el-form :inline="true">
      <el-form-item label="年份">
        <el-select v-model="filters.year">
          <el-option label="全部" value=""></el-option>
          <el-option label="2025" value="2025"></el-option>
          <el-option label="2024" value="2024"></el-option>
        </el-select>
      </el-form-item>
      <el-form-item label="地区">
        <el-input v-model="filters.region" placeholder="如：杭州"></el-input>
      </el-form-item>
      <el-form-item label="组别">
        <el-select v-model="filters.competitionGroup">
          <el-option label="全部" value=""></el-option>
          <el-option label="综合组" value="综合组"></el-option>
          <el-option label="基层组" value="基层组"></el-option>
        </el-select>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" @click="queryData">查询</el-button>
      </el-form-item>
    </el-form>
    
    <el-table :data="tableData" border>
      <el-table-column prop="id" label="ID" width="80"></el-table-column>
      <el-table-column prop="year" label="年份" width="80"></el-table-column>
      <el-table-column prop="projectName" label="项目名称"></el-table-column>
      <el-table-column prop="institutionName" label="医院"></el-table-column>
      <el-table-column prop="competitionGroup" label="组别"></el-table-column>
    </el-table>
    
    <el-pagination
      @current-change="handlePageChange"
      :current-page="pagination.page + 1"
      :page-size="pagination.size"
      :total="pagination.total"
      layout="total, prev, pager, next">
    </el-pagination>
  </div>
</template>

<script>
export default {
  data() {
    return {
      filters: {
        year: '',
        region: '',
        competitionGroup: ''
      },
      tableData: [],
      pagination: {
        page: 0,
        size: 20,
        total: 0
      }
    }
  },
  methods: {
    async queryData() {
      const params = new URLSearchParams({
        ...this.filters,
        page: this.pagination.page,
        size: this.pagination.size
      });
      
      // 移除空值
      for (let [key, value] of params.entries()) {
        if (!value) params.delete(key);
      }
      
      const response = await fetch(`/api/historical-data?${params}`, {
        headers: {
          'Authorization': `Bearer ${this.$store.state.token}`
        }
      });
      
      const result = await response.json();
      if (result.success) {
        this.tableData = result.data.content;
        this.pagination.total = result.data.totalElements;
      }
    },
    handlePageChange(page) {
      this.pagination.page = page - 1;
      this.queryData();
    }
  },
  mounted() {
    this.queryData();
  }
}
</script>
```

### React 示例

```jsx
import React, { useState, useEffect } from 'react';

function HistoricalDataList() {
  const [filters, setFilters] = useState({
    year: '',
    region: '',
    competitionGroup: ''
  });
  const [data, setData] = useState([]);
  const [pagination, setPagination] = useState({
    page: 0,
    size: 20,
    total: 0
  });

  const queryData = async () => {
    const params = new URLSearchParams({
      ...filters,
      page: pagination.page,
      size: pagination.size
    });
    
    // 移除空值
    Object.keys(filters).forEach(key => {
      if (!filters[key]) params.delete(key);
    });
    
    const response = await fetch(`/api/historical-data?${params}`, {
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      }
    });
    
    const result = await response.json();
    if (result.success) {
      setData(result.data.content);
      setPagination(prev => ({
        ...prev,
        total: result.data.totalElements
      }));
    }
  };

  useEffect(() => {
    queryData();
  }, [pagination.page]);

  return (
    <div>
      <div className="filters">
        <select value={filters.year} onChange={e => setFilters({...filters, year: e.target.value})}>
          <option value="">全部年份</option>
          <option value="2025">2025</option>
          <option value="2024">2024</option>
        </select>
        <input 
          placeholder="地区" 
          value={filters.region}
          onChange={e => setFilters({...filters, region: e.target.value})}
        />
        <select value={filters.competitionGroup} onChange={e => setFilters({...filters, competitionGroup: e.target.value})}>
          <option value="">全部组别</option>
          <option value="综合组">综合组</option>
          <option value="基层组">基层组</option>
        </select>
        <button onClick={queryData}>查询</button>
      </div>
      
      <table>
        <thead>
          <tr>
            <th>ID</th>
            <th>年份</th>
            <th>项目名称</th>
            <th>医院</th>
            <th>组别</th>
          </tr>
        </thead>
        <tbody>
          {data.map(item => (
            <tr key={item.id}>
              <td>{item.id}</td>
              <td>{item.year}</td>
              <td>{item.projectName}</td>
              <td>{item.institutionName}</td>
              <td>{item.competitionGroup}</td>
            </tr>
          ))}
        </tbody>
      </table>
      
      <div className="pagination">
        总共 {pagination.total} 条记录
      </div>
    </div>
  );
}

export default HistoricalDataList;
```

1. **必须先登录获取 Token**
2. **Token 需要放在请求头的 Authorization 字段**
3. **只有 COMMITTEE_ADMIN 和 OPS 角色可以访问**

5. **年份、组别、状态为精确匹配，其他为模糊匹配**
