# 参赛者报名详情 - 机构信息显示指引

> 更新时间：2026-02-06  
> API版本：v1.0

---

## 📋 概述

参赛者查看报名详情时，**可以看到机构的完整信息**，包括：
- ✅ 医疗机构名称
- ✅ 机构编号
- ✅ 统一社会信用代码
- ✅ 地区

---

## 🔌 API接口

### 接口路径
```
GET /api/registrations/{id}
```

### 请求头
```http
Authorization: Bearer {token}
```

### 响应数据结构

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "registration": {
      "id": 116,
      "projectName": "门诊预约体验提升-11",
      "groupType": "COMPREHENSIVE",
      "groupCode": "B1",
      "status": "APPROVED",
      "submittedAt": "2026-02-05T01:38:52.604359",
      "createdAt": "2026-02-05T23:38:52.604359"
    },
    "institution": {
      "id": 11,
      "name": "嘉兴市第一医院",
      "code": "INS-0011",
      "uscc": "12330000470533493L",
      "region": "嘉兴"
    },
    "members": [...],
    "activityInfo": {...},
    "projectSummary": {...},
    "materials": [...]
  }
}
```

---

## 📦 数据字段说明

### `institution` 对象（⭐ 新增）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | Long | 机构ID | `11` |
| `name` | String | 医疗机构名称 | `"嘉兴市第一医院"` |
| `code` | String | 机构编号 | `"INS-0011"` |
| `uscc` | String | 统一社会信用代码 | `"12330000470533493L"` |
| `region` | String | 地区 | `"嘉兴"` |

**注意**：
- `institution` 对象可能为 `null`（如果报名时未关联机构）
- 前端应该做好空值处理

## 💻 前端代码示例

### Vue 3 示例

```vue
<template>
  <div class="registration-detail">
    <!-- 机构基本信息 -->
    <div class="section institution-info">
      <h3>机构基本信息</h3>
      <el-descriptions :column="2" border v-if="institution">
        <el-descriptions-item label="医疗机构名称">
          {{ institution.name || 'N/A' }}
        </el-descriptions-item>
        <el-descriptions-item label="机构编号">
          {{ institution.code || 'N/A' }}
        </el-descriptions-item>
        <el-descriptions-item label="统一社会信用代码">
          {{ institution.uscc || 'N/A' }}
        </el-descriptions-item>
        <el-descriptions-item label="地区">
          {{ institution.region || 'N/A' }}
        </el-descriptions-item>
      </el-descriptions>
      <el-empty v-else description="机构信息未设置" />
    </div>

    <!-- 项目基本信息 -->
    <div class="section">
      <h3>项目基本信息</h3>
      <el-descriptions :column="2" border>
        <el-descriptions-item label="项目名称">
          {{ registration.projectName }}
        </el-descriptions-item>
        <el-descriptions-item label="组别">
          {{ groupTypeLabel }}
        </el-descriptions-item>
        <el-descriptions-item label="状态">
          <el-tag :type="statusType">{{ statusLabel }}</el-tag>
        </el-descriptions-item>
      </el-descriptions>
    </div>

    <!-- 成员信息等其他部分... -->
  </div>
</template>

<script setup>
import { ref, computed, onMounted } from 'vue'
import { useRoute } from 'vue-router'
import axios from 'axios'

const route = useRoute()
const registrationId = route.params.id

// 响应式数据
const registration = ref({})
const institution = ref(null)
const members = ref([])
const activityInfo = ref(null)

// 获取报名详情
const fetchDetail = async () => {
  try {
    const response = await axios.get(`/api/registrations/${registrationId}`, {
      headers: {
        Authorization: `Bearer ${localStorage.getItem('token')}`
      }
    })
    
    const data = response.data.data
    registration.value = data.registration || {}
    institution.value = data.institution || null  // ⭐ 关键：获取机构信息
    members.value = data.members || []
    activityInfo.value = data.activityInfo || null
    
  } catch (error) {
    console.error('获取报名详情失败:', error)
  }
}

// 组别标签映射
const groupTypeLabel = computed(() => {
  const map = {
    'BASIC': '基层组',
    'ADVANCED': '进阶组',
    'COMPREHENSIVE': '综合组'
  }
  return map[registration.value.groupType] || registration.value.groupType
})

// 状态标签映射
const statusLabel = computed(() => {
  const map = {
    'DRAFT': '草稿',
    'SUBMITTED': '已提交',
    'APPROVED': '已通过',
    'RETURNED': '已退回'
  }
  return map[registration.value.status] || registration.value.status
})

const statusType = computed(() => {
  const map = {
    'DRAFT': 'info',
    'SUBMITTED': 'warning',
    'APPROVED': 'success',
    'RETURNED': 'danger'
  }
  return map[registration.value.status] || 'info'
})

onMounted(() => {
  fetchDetail()
})
</script>

<style scoped>
.registration-detail {
  padding: 20px;
}

.section {
  margin-bottom: 24px;
  background: white;
  padding: 20px;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

.section h3 {
  margin-bottom: 16px;
  font-size: 18px;
  font-weight: 600;
  color: #333;
}
</style>
```

### React 示例

```jsx
import React, { useState, useEffect } from 'react';
import { useParams } from 'react-router-dom';
import { Card, Descriptions, Tag, Empty } from 'antd';
import axios from 'axios';

const RegistrationDetail = () => {
  const { id } = useParams();
  const [registration, setRegistration] = useState({});
  const [institution, setInstitution] = useState(null);
  const [members, setMembers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchDetail();
  }, [id]);

  const fetchDetail = async () => {
    try {
      const response = await axios.get(`/api/registrations/${id}`, {
        headers: {
          Authorization: `Bearer ${localStorage.getItem('token')}`
        }
      });
      
      const data = response.data.data;
      setRegistration(data.registration || {});
      setInstitution(data.institution || null);  // ⭐ 关键：获取机构信息
      setMembers(data.members || []);
      
    } catch (error) {
      console.error('获取报名详情失败:', error);
    } finally {
      setLoading(false);
    }
  };

  const groupTypeMap = {
    'BASIC': '基层组',
    'ADVANCED': '进阶组',
    'COMPREHENSIVE': '综合组'
  };

  const statusMap = {
    'DRAFT': { text: '草稿', color: 'default' },
    'SUBMITTED': { text: '已提交', color: 'processing' },
    'APPROVED': { text: '已通过', color: 'success' },
    'RETURNED': { text: '已退回', color: 'error' }
  };

  return (
    <div className="registration-detail">
      {/* 机构基本信息 */}
      <Card title="机构基本信息" style={{ marginBottom: 24 }}>
        {institution ? (
          <Descriptions column={2} bordered>
            <Descriptions.Item label="医疗机构名称">
              {institution.name || 'N/A'}
            </Descriptions.Item>
            <Descriptions.Item label="机构编号">
              {institution.code || 'N/A'}
            </Descriptions.Item>
            <Descriptions.Item label="统一社会信用代码">
              {institution.uscc || 'N/A'}
            </Descriptions.Item>
            <Descriptions.Item label="地区">
              {institution.region || 'N/A'}
            </Descriptions.Item>
          </Descriptions>
        ) : (
          <Empty description="机构信息未设置" />
        )}
      </Card>

      {/* 项目基本信息 */}
      <Card title="项目基本信息" style={{ marginBottom: 24 }}>
        <Descriptions column={2} bordered>
          <Descriptions.Item label="项目名称">
            {registration.projectName}
          </Descriptions.Item>
          <Descriptions.Item label="组别">
            {groupTypeMap[registration.groupType] || registration.groupType}
          </Descriptions.Item>
          <Descriptions.Item label="状态">
            <Tag color={statusMap[registration.status]?.color}>
              {statusMap[registration.status]?.text || registration.status}
            </Tag>
          </Descriptions.Item>
        </Descriptions>
      </Card>

      {/* 成员信息等其他部分... */}
    </div>
  );
};

export default RegistrationDetail;
```

## ⚠️ 注意事项

### 1. 空值处理

机构信息可能为 `null`，前端需要做好空值处理：

```javascript
// 推荐写法
const institutionName = institution?.name || 'N/A'

// 或使用条件渲染
{institution ? (
  <div>{institution.name}</div>
) : (
  <div>机构信息未设置</div>
)}
```

### 2. 权限控制

- 参赛者只能查看**自己的报名详情**
- 组委会/评委可以查看**所有报名详情**
- API会自动验证权限

### 3. 响应字段变化

**之前的响应（无机构信息）：**
```json
{
  "registration": {...},
  "members": [...],
  "activityInfo": {...}
}
```

**现在的响应（新增机构信息）：**
```json
{
  "registration": {...},
  "institution": {        // ⭐ 新增字段
    "id": 11,
    "name": "嘉兴市第一医院",
    "code": "INS-0011",
    "uscc": "12330000470533493L",
```
