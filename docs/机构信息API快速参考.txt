================================================================================
                    机构信息API快速参考
================================================================================

更新时间：2026-02-06

================================================================================
  ✅ 确认：参赛者可以看到机构信息
================================================================================

接口：GET /api/registrations/{id}

返回的 institution 字段包含：
  - name：医疗机构名称
  - code：机构编号
  - uscc：统一社会信用代码
  - region：地区

================================================================================
  📦 响应数据示例
================================================================================

{
  "code": 200,
  "message": "success",
  "data": {
    "registration": {
      "id": 116,
      "projectName": "门诊预约体验提升-11",
      "groupType": "COMPREHENSIVE",
      "status": "APPROVED"
    },
    "institution": {                      ⭐ 机构信息
      "id": 11,
      "name": "嘉兴市第一医院",           ← 医疗机构名称
      "code": "INS-0011",                 ← 机构编号
      "uscc": "12330000470533493L",       ← 统一社会信用代码
      "region": "嘉兴"                    ← 地区
    },
    "members": [...],
    "activityInfo": {...}
  }
}

================================================================================
  💻 前端使用方式
================================================================================

1. 调用API获取报名详情
   GET /api/registrations/{id}
   Headers: Authorization: Bearer {token}

2. 从响应中获取机构信息
   const institution = response.data.data.institution

3. 显示机构信息
   医疗机构名称：institution.name
   机构编号：institution.code
   统一社会信用代码：institution.uscc
   地区：institution.region

4. 注意空值处理
   institution 可能为 null，需要做空值判断
