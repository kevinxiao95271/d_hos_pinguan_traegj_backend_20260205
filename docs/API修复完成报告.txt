【核心数据结构】

1. MemberRole（成员角色）
   - PARTICIPANT  参与者/圈员
   - MENTOR       辅导员

2. GroupType（组别）
   - BASIC        基础组
   - ADVANCED     高级组

3. RegistrationStatus（报名状态）
   - DRAFT        草稿（可修改）
   - SUBMITTED    已提交（不可修改）
   - RETURNED     退回（可修改）
   - APPROVED     已通过（不可修改）

4. 活动说明必填字段
   ✅ theme                    主题
   ✅ keywords                 关键词
   ✅ subjectTypeCode          选题类型
   ✅ methodCode               方法
   ✅ experienceImproveCode    改善经验
   ✅ qualityTopicCode         质量主题
   ✅ avgWorkYears             平均工作年限
   ✅ avgAge                   平均年龄
   ✅ crossDepartment          是否跨部门

【测试指南】

测试用例1: 评委端（无任务）

  2. GET /api/reviews/my-tasks

测试用例2: 参赛者完整流程
  1. 登录参赛者账号
  2. POST /api/registrations (创建报名)
  3. PUT /api/registrations/{id}/members (提交成员)
     - name, title, role必填
     - department可选
  4. PUT /api/registrations/{id}/activity (提交活动说明)
     - 所有带@NotBlank的字段必填
     - code字段使用建议值（见文档）
  5. PUT /api/registrations/{id}/summary (提交总结)
  6. POST /api/registrations/{id}/submit (提交审核)
  7. 尝试修改已提交的报名（应返回400）
