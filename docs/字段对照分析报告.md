## 字段设计说明

### 1. 单选字段的设计模式

对于单选字段（如"改善就医环境"、"医疗质量相关主题"），系统采用了**代码+其他说明**的设计模式：

- **主字段**（如 `experienceImproveCode`）：存储选项代码
- **其他字段**（如 `experienceImproveOther`）：当选择"其他"时，存储用户填写的说明

#### 示例：改善就医环境

```java
// 字段定义
private String experienceImproveCode;  // 存储选项代码，如 "outpatient_process"
private String experienceImproveOther; // 当选择"其他"时，存储说明文字
```

**选项代码映射**（需要在字典表 `dictionary_items` 中配置）：
- `appointment_service` → "预约诊疗服务更加便捷"
- `outpatient_process` → "门诊就诊更加优化"
- `inpatient_experience` → "患者住院体验更加舒适"
- `post_hospital_service` → "院后医疗服务更加连续"
- `pre_inpatient_connection` → "院前院内衔接更加高效"
- `comfortable_environment` → "舒心就医环境更加温馨"
- `internet_diagnosis` → "互联网诊疗更加便捷"
- `other` → "其他"（此时需要填写 `experienceImproveOther`）

## 字典表配置要求

### 需要在 `dictionary_items` 表中配置的字典类型

1. **subject_type** - 主题类型
2. **method** - 运用手法（品管工具）
3. **experience_improve** - 改善就医环境（需要配置）
4. **quality_topic** - 医疗质量相关主题（需要配置）

### 字典表结构

```sql
CREATE TABLE dictionary_items (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  type VARCHAR(64) NOT NULL,        -- 字典类型
  code VARCHAR(64) NOT NULL,        -- 选项代码
  label VARCHAR(200) NOT NULL,      -- 选项显示文本
  active BOOLEAN DEFAULT TRUE,      -- 是否启用
  sort_order INT DEFAULT 0,         -- 排序
  UNIQUE KEY uk_type_code (type, code)
);
```
