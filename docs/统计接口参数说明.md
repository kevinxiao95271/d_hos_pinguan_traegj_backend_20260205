# 统计接口参数说明

## 接口信息

### 基本信息
- **接口路径**: `/api/admin/stats/summary`
- **请求方法**: `GET`
- **权限要求**: 需要登录（任何角色）

## 请求参数

### 可选参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `competitionId` | Number | 否 | 赛事ID，不传则返回最新赛事 |

### 使用方式

#### 1. 不带参数（默认返回最新赛事）

```javascript
// 返回ID最大的赛事（最新创建的赛事）
fetch('/api/admin/stats/summary', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```

#### 2. 指定赛事ID

```javascript
// 返回指定赛事的统计数据
fetch('/api/admin/stats/summary?competitionId=21', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```

## 接口行为

### 自动查询最新赛事

接口会自动查询数据库中**ID最大的赛事**（即最新创建的赛事），并返回该赛事的统计数据。

**后端逻辑**:
```java
Competition competition = competitionRepository.findAll().stream()
    .max(Comparator.comparing(Competition::getId))
    .orElseThrow(() -> new IllegalArgumentException("暂无赛事"));
```

### 示例场景

假设数据库中有以下赛事：

| 赛事ID | 赛事名称 | 创建时间 |
|--------|----------|----------|
| 21 | 2026浙江品管大赛 | 2026-01-15 |
| 28 | 2026年省级质量改进赛-1 | 2026-02-01 |
| 29 | 2026年省级质量改进赛-2 | 2026-02-05 |

**接口会返回赛事29的数据**（ID最大）

## 请求示例

### JavaScript/TypeScript

```javascript
async function getStats() {
  const token = localStorage.getItem('token');
  
  const response = await fetch('/api/admin/stats/summary', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    }
  });
  
  const result = await response.json();
  
  if (result.success) {
    console.log('赛事ID:', result.data.competitionId);
    console.log('赛事名称:', result.data.competitionName);
    console.log('报名总数:', result.data.registrationCount);
    console.log('地区分布:', result.data.regionCounts);
  }
}
```

### Vue 3 Composition API

```vue
<script setup>
import { ref, onMounted } from 'vue';
import { useAuthStore } from '@/stores/auth';

const authStore = useAuthStore();
const statsData = ref(null);
const loading = ref(false);

const fetchStats = async () => {
  loading.value = true;
  
  try {
    const response = await fetch('/api/admin/stats/summary', {
      headers: {
        'Authorization': `Bearer ${authStore.token}`
      }
    });
    
    const result = await response.json();
    
    if (result.success) {
      statsData.value = result.data;
    }
  } catch (error) {
    console.error('获取统计数据失败:', error);
  } finally {
    loading.value = false;
  }
};

onMounted(() => {
  fetchStats();
});
</script>
```

## 常见问题

### Q1: 如何查询指定赛事的统计数据？

**A**: ✅ 现在支持通过 `competitionId` 参数指定赛事：

```javascript
// 查询赛事21的统计数据
fetch('/api/admin/stats/summary?competitionId=21', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```

**前端使用建议**:
```javascript
// 根据当前选中的赛事动态查询
const currentCompetitionId = 21; // 从前端状态获取

fetch(`/api/admin/stats/summary?competitionId=${currentCompetitionId}`, {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```

### Q2: 如何知道返回的是哪个赛事的数据？

**A**: 查看响应中的 `competitionId` 和 `competitionName` 字段：

```javascript
const result = await fetch('/api/admin/stats/summary', {
  headers: { 'Authorization': `Bearer ${token}` }
}).then(r => r.json());

console.log(`当前统计的赛事: ${result.data.competitionName} (ID: ${result.data.competitionId})`);
```

### Q3: 为什么我的数据和预期不一致？

**A**: 可能原因：
1. 接口返回的是最新赛事，不是你期望的赛事
2. 检查 `competitionId` 确认是哪个赛事
3. 如果需要查询历史赛事，请联系后端添加参数支持

### Q4: 接口返回401错误怎么办？

**A**: 401表示未授权，请检查：
1. 是否已登录并获取token
2. token是否有效（未过期）
3. 请求头中是否正确设置了 `Authorization: Bearer ${token}`

### Q5: 接口返回的数据为空怎么办？

**A**: 检查：
1. 最新赛事是否有报名数据
2. 查看 `registrationCount` 字段确认报名数量
3. 如果最新赛事没有数据，可能需要查询其他赛事

## 错误处理

### 常见错误码

| 状态码 | 说明 | 处理方式 |
|--------|------|----------|
| 200 | 成功 | 正常处理数据 |
| 401 | 未授权 | 重新登录获取token |
| 403 | 无权限 | 检查用户角色权限 |
| 500 | 服务器错误 | 联系后端排查 |

### 错误处理示例

```javascript
async function getStats() {
  try {
    const response = await fetch('/api/admin/stats/summary', {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    });
    
    if (!response.ok) {
      if (response.status === 401) {
        // 未授权，跳转到登录页
        window.location.href = '/login';
        return;
      }
      throw new Error(`HTTP ${response.status}`);
    }
    
    const result = await response.json();
    
    if (!result.success) {
      throw new Error(result.message || '获取数据失败');
    }
    
    return result.data;
    
  } catch (error) {
    console.error('获取统计数据失败:', error);
    // 显示错误提示
    alert(`获取统计数据失败: ${error.message}`);
    return null;
  }
}
```

## 性能优化建议

### 1. 缓存数据

```javascript
// 缓存5分钟
const CACHE_TIME = 5 * 60 * 1000;
let cachedData = null;
let cacheTime = 0;

async function getStats(forceRefresh = false) {
  const now = Date.now();
  
  if (!forceRefresh && cachedData && (now - cacheTime) < CACHE_TIME) {
    return cachedData;
  }
  
  const data = await fetchStatsFromAPI();
  cachedData = data;
  cacheTime = now;
  
  return data;
}
```

### 2. 防抖处理

```javascript
import { debounce } from 'lodash';

const fetchStats = debounce(async () => {
  // 获取统计数据
}, 1000);
```

### 3. 加载状态

```javascript
const [loading, setLoading] = useState(false);
```
