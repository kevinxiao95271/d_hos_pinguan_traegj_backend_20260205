## 🔍 前端可能的问题原因

### 原因1: 没有传递 competitionId 参数 ⭐⭐⭐⭐⭐

**最可能的原因！**

```javascript
// ❌ 错误：不传参数
fetch('/api/admin/stats/summary')
// 结果：返回赛事29的数据（只有1条报名：杭州1）

// ✅ 正确：传递当前选中的赛事ID
fetch('/api/admin/stats/summary?competitionId=21')
// 结果：返回赛事21的数据（45条报名）
```

**如何验证**:
1. 打开浏览器开发者工具（F12）
2. 切换到 Network 标签
3. 刷新页面
4. 查找 `stats/summary` 请求
5. 检查 Request URL 是否包含 `?competitionId=21`

**如果URL中没有 `?competitionId=21`，那就是这个问题！**

### 原因2: 图表库自动合并小占比项 ⭐⭐⭐⭐

很多图表库（如 ECharts、Chart.js）有自动合并小占比项为"其他"的功能。

#### ECharts 示例

```javascript
// ❌ 可能导致问题的配置
series: [{
  type: 'pie',
  data: data,
  // 某些版本可能有自动合并选项
  minShowLabelAngle: 10  // 小于10度的扇区不显示标签
}]

// ✅ 确保不合并
series: [{
  type: 'pie',
  data: data,
  minShowLabelAngle: 0,  // 显示所有标签
  avoidLabelOverlap: true
}]
```

#### Chart.js 示例

```javascript
// ❌ 可能导致问题的配置
options: {
  plugins: {
    legend: {
      display: true,
      // 某些插件可能会合并小项
    }
  }
}

// ✅ 确保不合并
options: {
  plugins: {
    legend: {
      display: true,
      maxItems: 20  // 显示所有项
    }
  }
}
```

### 原因3: 前端自定义分类逻辑 ⭐⭐⭐

前端代码可能有自定义的分类逻辑，将小占比的地区合并为"其他"。

```javascript
// ❌ 可能导致问题的代码
function processRegionData(regionCounts) {
  const threshold = 0.05; // 5%阈值
  const total = Object.values(regionCounts).reduce((a, b) => a + b, 0);
  
  const result = {};
  let otherCount = 0;
  
  for (const [region, count] of Object.entries(regionCounts)) {
    const percentage = count / total;
    if (percentage < threshold) {
      otherCount += count;  // ← 这里会创建"其他"分类！
    } else {
      result[region] = count;
    }
  }
  
  if (otherCount > 0) {
    result['其他'] = otherCount;
  }
  
  return result;
}
```

**搜索关键词**: `其他`, `other`, `threshold`, `merge`, `combine`

### 原因4: 缓存问题 ⭐⭐

浏览器或前端框架可能缓存了旧数据。

**解决方法**:
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 硬刷新（Ctrl+F5）
3. 在请求URL中添加时间戳：`?competitionId=21&_t=${Date.now()}`

### 原因5: 数据转换错误 ⭐

前端在处理数据时可能有错误的转换逻辑。

```javascript
// ❌ 可能导致问题的代码

  // 某些转换逻辑可能导致数据丢失或合并

```
