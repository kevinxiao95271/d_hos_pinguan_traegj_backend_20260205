## 可能的解决方案

### 方案1: 使用当前系统数据（推荐）
从当前系统的 `review_tasks` 表统计评委任务数量：

```sql
-- 统计当前竞赛的评委任务数量
SELECT 
    u.name as reviewer_name,
    u.title as reviewer_title,
    COUNT(rt.id) as task_count,
    COUNT(CASE WHEN rt.stage = 'BOOK' THEN 1 END) as book_tasks,
    COUNT(CASE WHEN rt.stage = 'INTERVIEW' THEN 1 END) as interview_tasks
FROM review_tasks rt
JOIN user_accounts u ON rt.reviewer_id = u.id
WHERE rt.registration_id IN (
    SELECT id FROM registrations WHERE competition_id = 21
)
GROUP BY u.id, u.name, u.title
ORDER BY task_count DESC;
```
