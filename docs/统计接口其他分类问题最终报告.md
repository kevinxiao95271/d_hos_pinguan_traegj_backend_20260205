```java
Map<String, Integer> regionCounts = new HashMap<>();
for (Registration registration : registrations) {
    String region = null;
    if (registration.getInstitution() != null) {
        region = registration.getInstitution().getRegion();
    }
    if (region == null || region.trim().isEmpty()) {
        region = "未知";  // ← 只有在NULL或空字符串时才标记为"未知"
    }
    regionCounts.put(region, regionCounts.getOrDefault(region, 0) + 1);
}
```

#### 1. 没有传递 `competitionId` 参数 ⭐⭐⭐⭐⭐

**最可能的原因！**


**如何验证**:
- 打开浏览器开发者工具（F12）

- 查找 `stats/summary` 请求
- 检查 Request URL 是否包含 `?competitionId=21`

**如果URL中没有 `?competitionId=21`，那就是这个问题！**

#### 2. 图表库自动合并小占比项 ⭐⭐⭐⭐

很多图表库有自动合并小占比项为"其他"的功能。

**ECharts 示例**:
```javascript
series: [{
  type: 'pie',
  minShowLabelAngle: 10  // ← 小于10度的扇区可能被合并
}]
```

**Chart.js 示例**:
```javascript
options: {
  plugins: {
    legend: {
      // 某些插件可能会合并小项
    }
  }
}
```

#### 3. 前端自定义分类逻辑 ⭐⭐⭐

前端代码可能有自定义的分类逻辑。

```javascript
// ❌ 可能导致问题的代码
function processRegionData(regionCounts) {
  const threshold = 0.05; // 5%阈值
  const result = {};
  let otherCount = 0;
  
  for (const [region, count] of Object.entries(regionCounts)) {
    const percentage = count / total;
    if (percentage < threshold) {
      otherCount += count;  // ← 这里创建了"其他"！
    } else {
      result[region] = count;
    }
  }
  
  if (otherCount > 0) {
    result['其他'] = otherCount;
  }
  
  return result;
}
```

#### 4. 缓存问题 ⭐⭐

浏览器或前端框架可能缓存了旧数据。

**解决方法**:
- 清除浏览器缓存（Ctrl+Shift+Delete）
- 硬刷新（Ctrl+F5）
- 在请求URL中添加时间戳

#### 5. 数据转换错误 ⭐

前端在处理数据时可能有错误的转换逻辑。
