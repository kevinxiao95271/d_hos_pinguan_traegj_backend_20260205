## 🎯 问题根源

### 后端

✅ **后端完全正常**
- 筛选接口存在且工作正常
- 支持按`methodCode`（代码）筛选
- 数据库存储的是`code`（如`qc_topic`），不是`label`（如`品管圈-课题达成`）

### 前端

❌ **前端存在以下问题之一**：

1. **使用了错误的API**
   - 使用了`GET /api/registrations`（不支持筛选）
   - 应该使用`GET /api/admin/registrations/filter`（支持筛选）

2. **传递了错误的参数**
   - 传递了`methodCode="品管圈-课题达成"`（label）
   - 应该传递`methodCode="qc_topic"`（code）

3. **没有维护label→code的映射**
   - 前端显示的是label（用户友好）
   - 但筛选时需要传递code（数据库字段）

---

## ✅ 解决方案

### 方案1：使用正确的API（推荐）

**前端修改**：

```javascript

const response = await axios.get('/api/registrations', {
  params: {
    competitionId: 21,

  }
});

// ✅ 正确的API

  params: {
    competitionId: 21,
    methodCode: 'qc_topic'  // 使用code，不是label
  }

```

### 方案2：维护label→code映射表

**前端实现**：

```javascript
// 1. 从字典接口获取映射
async function loadMethodMapping() {
  const response = await axios.get('/api/dictionaries/method');
  const items = response.data.data;
  
  // 创建label→code映射
  const labelToCode = {};
  items.forEach(item => {
    labelToCode[item.label] = item.code;
  });
  
  return labelToCode;
}

// 2. 使用映射进行筛选
const methodMapping = await loadMethodMapping();

// 用户选择的是label
const selectedLabel = '品管圈-课题达成';

// 转换为code
const methodCode = methodMapping[selectedLabel]; // 'qc_topic'

// 调用筛选API
const response = await axios.get('/api/admin/registrations/filter', {
  params: {
    competitionId: 21,
    methodCode: methodCode  // 使用转换后的code
  }
});
```

### 方案3：后端提供label筛选（不推荐）

如果前端无法修改，可以让后端支持按label筛选：

**后端修改**（不推荐，增加复杂度）：

```java
// 在RegistrationService中添加label→code转换
public List<RegistrationFilterItem> filterRegistrations(..., String methodLabel) {
    String methodCode = null;
    if (methodLabel != null && !methodLabel.trim().isEmpty()) {
        // 从字典表查询code
        DictionaryItem item = dictionaryItemRepository
            .findFirstByTypeAndLabelAndActiveTrue("method", methodLabel)
            .orElse(null);
        if (item != null) {
            methodCode = item.getCode();
        }
    }
    // 使用methodCode进行筛选
    return filterRegistrations(..., methodCode);
}
```

### React 示例

```jsx
import React, { useState, useEffect } from 'react';
import axios from 'axios';

function RegistrationFilter() {
  const [selectedMethodLabel, setSelectedMethodLabel] = useState('');
  const [methodOptions, setMethodOptions] = useState([]);
  const [registrations, setRegistrations] = useState([]);
  const [methodMapping, setMethodMapping] = useState({});
  
  // 加载品管工具字典
  useEffect(() => {
    async function loadMethodOptions() {
      const response = await axios.get('/api/dictionaries/method');
      const options = response.data.data;
      setMethodOptions(options);
      
      // 创建映射
      const mapping = {};
      options.forEach(item => {
        mapping[item.label] = item.code;
      });
      setMethodMapping(mapping);
    }
    
    loadMethodOptions();
  }, []);
  
  // 筛选报名
  async function filterRegistrations(methodLabel) {
    const methodCode = methodMapping[methodLabel];
    
    const response = await axios.get('/api/admin/registrations/filter', {
      params: {
        competitionId: 21,
        methodCode: methodCode
      }
    });
    
    setRegistrations(response.data.data);
  }
  
  // 处理品管工具变化
  function handleMethodChange(e) {
    const label = e.target.value;
    setSelectedMethodLabel(label);
    
    if (label) {
      filterRegistrations(label);
    }
  }
  
  return (
    <div>
      <select value={selectedMethodLabel} onChange={handleMethodChange}>
        <option value="">选择品管工具</option>
        {methodOptions.map(method => (
          <option key={method.code} value={method.label}>
            {method.label}
          </option>
        ))}
      </select>
      
      <table>
        <thead>
          <tr>
            <th>ID</th>
            <th>项目名称</th>
            <th>品管工具</th>
          </tr>
        </thead>
        <tbody>
          {registrations.map(reg => (
            <tr key={reg.registrationId}>
              <td>{reg.registrationId}</td>
              <td>{reg.projectName}</td>
              <td>{reg.methodLabel}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}

export default RegistrationFilter;
```
