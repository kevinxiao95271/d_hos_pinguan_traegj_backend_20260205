# 书审分组下拉框 - 数据说明

## 问题描述

前端反馈：书审阶段项目分组筛选条件的下拉框数据重复了两遍

## 后端数据验证结果

### 1. 数据库检查

✅ **数据库中的group_code没有重复**
- 每个项目(registration)只有一个group_code
- 数据库查询结果正常，无重复数据

### 2. API接口检查

**接口**: `GET /api/admin/reviews/book-scores`

**参数**:
- `competitionId`: 赛事ID (必填)
- `groupType`: 组别类型 (可选)
- `reviewerGroupCode`: 评委分组代码 (可选)
- 其他筛选参数...

**返回数据结构**:
```json
{
  "success": true,
  "data": [
    {
      "taskId": 115,
      "projectName": "护理交接班规范化",
      "groupCode": "A1",
      "groupType": "BASIC",
      "status": "SCORED",
      ...
    },
    {
      "taskId": 117,
      "projectName": "住院用药安全改进",
      "groupCode": "A1",
      "groupType": "BASIC",
      "status": "SCORED",
      ...
    },
    {
      "taskId": 119,
      "projectName": "病区巡查标准化",
      "groupCode": "A2",
      "groupType": "BASIC",
      "status": "PENDING",
      ...
    }
  ]
}
```

### 3. 数据特点

- API返回的是**书审任务列表**，不是分组列表
- 每条记录代表一个评审任务(task)
- 同一个分组(如A1)可能有多个项目，因此会出现多次
- 这是**正常的业务逻辑**，不是数据重复

### 4. 示例数据

当前数据库中的分组分布：
```
A1: 2个项目, 3个任务
A2: 1个项目, 1个任务
A3: 2个项目, 2个任务
```

API返回6条记录，其中A1出现3次（因为有3个任务），这是正常的。

## 前端处理建议

### 方案1: 从列表数据中提取去重 (推荐)

```javascript
// 从API返回的数据中提取唯一的分组代码
const groupCodes = [...new Set(data.map(item => item.groupCode))].filter(Boolean).sort();

// 构建下拉框选项
const groupOptions = groupCodes.map(code => ({
  label: code,
  value: code
}));
```

### 方案2: 使用专门的分组列表接口

如果需要，后端可以提供一个专门的接口来获取分组列表：

```
GET /api/admin/registrations/group-codes?competitionId=21&stage=BOOK
```

返回：
```json
{
  "success": true,
  "data": ["A1", "A2", "A3"]
}
```

**注意**: 目前后端没有这个接口，建议前端使用方案1。

## 结论

✅ **后端数据没有问题**
- 数据库中每个项目只有一个group_code
- API返回的数据结构正确
- 同一个分组出现多次是因为该分组有多个项目/任务

⚠️ **前端需要处理**
- 从任务列表中提取分组代码时需要去重
- 使用 `Set` 或 `Array.filter` 去重
- 建议在获取数据后立即处理，生成下拉框选项

## 代码示例

### JavaScript/TypeScript

```typescript
// 获取书审得分列表
const response = await fetch('/api/admin/reviews/book-scores?competitionId=21');
const result = await response.json();

if (result.success) {
  const tasks = result.data;
  
  // 提取唯一的分组代码
  const uniqueGroupCodes = [...new Set(
    tasks
      .map(task => task.groupCode)
      .filter(code => code != null)
  )].sort();
  
  // 构建下拉框选项
  const groupCodeOptions = [
    { label: '全部', value: '' },
    ...uniqueGroupCodes.map(code => ({
      label: code,
      value: code
    }))
  ];
  
  console.log('分组代码选项:', groupCodeOptions);
  // 输出: [{ label: '全部', value: '' }, { label: 'A1', value: 'A1' }, { label: 'A2', value: 'A2' }, { label: 'A3', value: 'A3' }]
}
```

### Vue 3

```vue
<template>
  <el-select v-model="selectedGroupCode" placeholder="选择分组">
    <el-option label="全部" value="" />
    <el-option
      v-for="code in groupCodeOptions"
      :key="code"
      :label="code"
      :value="code"
    />
  </el-select>
</template>

<script setup>
import { ref, computed } from 'vue';

const bookScores = ref([]);
const selectedGroupCode = ref('');

// 从书审数据中提取唯一的分组代码
const groupCodeOptions = computed(() => {
  const codes = bookScores.value
    .map(item => item.groupCode)
    .filter(code => code != null);
  
  return [...new Set(codes)].sort();
});

// 加载数据
async function loadBookScores() {
  const response = await fetch('/api/admin/reviews/book-scores?competitionId=21');
  const result = await response.json();
  if (result.success) {
    bookScores.value = result.data;
  }
}
</script>
```

### React

```jsx
import { useState, useEffect, useMemo } from 'react';

function BookScoreFilter() {
  const [bookScores, setBookScores] = useState([]);
  const [selectedGroupCode, setSelectedGroupCode] = useState('');
  
  // 从书审数据中提取唯一的分组代码
  const groupCodeOptions = useMemo(() => {
    const codes = bookScores
      .map(item => item.groupCode)
      .filter(code => code != null);
    
    return [...new Set(codes)].sort();
  }, [bookScores]);
  
  useEffect(() => {
    fetch('/api/admin/reviews/book-scores?competitionId=21')
      .then(res => res.json())
      .then(result => {
        if (result.success) {
          setBookScores(result.data);
        }
      });
  }, []);
  
  return (
    <select value={selectedGroupCode} onChange={e => setSelectedGroupCode(e.target.value)}>
      <option value="">全部</option>
      {groupCodeOptions.map(code => (
        <option key={code} value={code}>{code}</option>
      ))}
    </select>
  );
}
```
