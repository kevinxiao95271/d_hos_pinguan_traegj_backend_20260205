## 注意事项

### ⚠️ 当前限制

1. **没有评分历史记录**
   - 第二次打分会完全覆盖第一次的数据
   - 无法查看第一次打分的内容
   - 无法对比两次打分的差异

2. **没有驳回原因记录**
   - 数据库中没有存储驳回原因
   - 评委不知道为什么被驳回
   - 评委不知道应该修改哪些内容

3. **没有驳回次数限制**
   - 可以无限次驳回和重新提交
   - 没有驳回次数统计

### 💡 建议优化（可选）

1. **增加驳回原因字段**
   ```sql
   ALTER TABLE review_tasks 
   ADD COLUMN reject_reason TEXT,
   ADD COLUMN reject_count INT DEFAULT 0;
   ```

2. **增加评分历史表**
   ```sql
   CREATE TABLE review_score_history (
       id BIGSERIAL PRIMARY KEY,
       review_task_id BIGINT NOT NULL,
       version INT NOT NULL,
       total DECIMAL(6,2),
       submitted_at TIMESTAMP
   );
   ```

3. **前端显示驳回原因**
   - 管理员驳回时输入原因
   - 评委查看任务时显示驳回原因
   - 引导评委针对性修改
