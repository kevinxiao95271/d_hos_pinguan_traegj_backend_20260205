# 分组接口机构等级字段使用指南

## 快速参考

所有分组相关接口现在都返回 `institutionLevel` 字段，前端可以直接使用。

## 接口列表

### 1. 书审分组筛选接口

**接口**: `GET /api/admin/registrations/filter`

**参数**:
- `competitionId` (必填): 赛事ID
- `groupType` (可选): 组别类型 (COMPREHENSIVE/BASIC/ADVANCED)
- `groupCode` (可选): 分组代码
- `projectName` (可选): 项目名称（模糊搜索）
- `institutionName` (可选): 机构名称（模糊搜索）
- `methodCode` (可选): 方法代码
- `subjectTypeCode` (可选): 主题类型代码

**返回字段**:
```json
{
  "success": true,
  "data": [
    {
      "registrationId": 106,
      "projectName": "护理交接班规范化-1",
      "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
      "institutionLevel": "三级甲等",  // ← 新增字段
      "groupType": "BASIC",
      "groupCode": "A1",
      "submittedAt": "2026-02-04T15:38:52.604359",
      "subjectTypeCode": "education",
      "methodCode": "qc_topic",
      "subjectTypeLabel": "教育训练",
      "methodLabel": "品管圈-课题达成",
      "applicantName": "参赛者1"
    }
  ]
}
```

### 2. 面谈分组接口

**接口**: `GET /api/admin/registrations/interview-groups`

**参数**:
- `competitionId` (必填): 赛事ID

**返回字段**:
```json
{
  "success": true,
  "data": [
    {
      "groupCode": "A1",
      "items": [
        {
          "registrationId": 106,
          "projectName": "护理交接班规范化-1",
          "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
          "institutionLevel": "三级甲等",  // ← 包含此字段
          "groupType": "BASIC",
          "groupCode": "A1"
        }
      ]
    }
  ]
}
```

### 3. 决赛分组接口

**接口**: `GET /api/admin/registrations/final-groups`

**参数**:
- `competitionId` (必填): 赛事ID

**返回格式**: 与面谈分组接口相同

## 前端代码示例

### Vue 3 示例

```vue
<template>
  <el-table :data="registrations">
    <el-table-column prop="projectName" label="项目名称" />
    <el-table-column prop="institutionName" label="机构名称" />
    <el-table-column prop="institutionLevel" label="机构等级" width="120" />
    <el-table-column prop="groupType" label="组别" />
  </el-table>
</template>

<script setup>
import { ref, onMounted } from 'vue';
import { useAuthStore } from '@/stores/auth';

const authStore = useAuthStore();
const registrations = ref([]);

const fetchRegistrations = async () => {
  const response = await fetch(
    '/api/admin/registrations/filter?competitionId=21',
    {
      headers: {
        'Authorization': `Bearer ${authStore.token}`
      }
    }
  );
  
  const result = await response.json();
  if (result.success) {
    registrations.value = result.data;
  }
};

onMounted(() => {
  fetchRegistrations();
});
</script>
```

### React 示例

```jsx
import { useState, useEffect } from 'react';
import { Table } from 'antd';

function RegistrationList() {
  const [registrations, setRegistrations] = useState([]);
  
  useEffect(() => {
    const fetchData = async () => {
      const token = localStorage.getItem('token');
      const response = await fetch(
        '/api/admin/registrations/filter?competitionId=21',
        {
          headers: {
            'Authorization': `Bearer ${token}`
          }
        }
      );
      
      const result = await response.json();
      if (result.success) {
        setRegistrations(result.data);
      }
    };
    
    fetchData();
  }, []);
  
  const columns = [
    { title: '项目名称', dataIndex: 'projectName', key: 'projectName' },
    { title: '机构名称', dataIndex: 'institutionName', key: 'institutionName' },
    { title: '机构等级', dataIndex: 'institutionLevel', key: 'institutionLevel', width: 120 },
    { title: '组别', dataIndex: 'groupType', key: 'groupType' },
  ];
  
  return <Table dataSource={registrations} columns={columns} />;
}
```

## 字段说明

### institutionLevel
- **类型**: String
- **说明**: 机构等级，如 "三级甲等"、"三级乙等"、"二级甲等" 等
- **是否必填**: 否（但当前所有数据都有此字段）
- **可能的值**: 
  - "三级甲等"
  - "三级乙等"
  - "二级甲等"
  - "二级乙等"
  - 等等

## 注意事项

1. **权限要求**: 所有分组接口都需要登录，请确保在请求头中包含有效的 JWT token
2. **数据完整性**: 当前所有机构都有等级数据，但建议前端做好空值处理
3. **字段名称**: 统一使用 `institutionLevel`，不是 `level` 或 `institutionGrade`

## 常见问题

### Q: 如果机构等级为空怎么办？
A: 虽然当前所有数据都有等级，但建议前端做好空值处理：
```javascript
const level = item.institutionLevel || '未设置';
```

### Q: 机构等级可以用来筛选吗？
A: 当前筛选接口不支持按机构等级筛选，如需此功能请联系后端添加。

### Q: 机构等级会变化吗？
A: 机构等级来自机构表，如果机构信息更新，等级可能会变化。建议每次加载页面时重新获取数据。
