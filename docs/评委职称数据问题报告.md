## ✅ 解决方案

### 方案1: 数据库直接更新（推荐）

```sql
-- 更新李明华的职称
UPDATE user_accounts 
SET title = '主任医师' 
WHERE id = 6;

-- 更新孙丽娟的职称
UPDATE user_accounts 
SET title = '副主任医师' 
WHERE id = 17;

-- 更新陈卫东的职称（如果需要）
UPDATE user_accounts 
SET title = '主任医师' 
WHERE id = 14;
```

如果有很多评委需要更新，可以准备CSV文件：

然后使用脚本批量更新。
