# 评委任务查看功能 - 前端开发指引

**更新日期**: 2026-02-07  
**功能**: 书审/面谈/决赛评委任务分配查看，支持多维度筛选

---

## 一、功能概述

在"书审评委分配"、"面谈评委分配"、"决赛评委分配"页面，添加"查看已分配任务"按钮。点击后弹窗展示所有已分配任务的列表，支持以下筛选：

- **分组筛选**: 竞赛组别（基层组/综合组/高级组）、分组代码（A1/A2/A3/B2）
- **专家筛选**: 评委姓名/单位
- **品管工具筛选**: 品管圈、QFD、根本原因分析等

---

## 二、API接口

### 2.1 接口地址

```
GET /api/reviews/tasks/stage
```

### 2.2 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `competitionId` | Number | ✅ | 赛事ID | 21 |
| `stage` | String | ✅ | 评审阶段 | "BOOK" / "INTERVIEW" / "FINAL" |
| `status` | String | ❌ | 任务状态 | "PENDING" / "SCORED" |
| `groupType` | String | ❌ | 竞赛组别 | "BASIC" / "COMPREHENSIVE" / "ADVANCED" |
| `groupCode` | String | ❌ | 分组代码 | "A1" / "A2" / "A3" / "B2" |
| `reviewerId` | Number | ❌ | 评委ID | 6 |
| `methodCode` | String | ❌ | 品管工具代码 | "qc_topic" / "qfd" |

### 2.3 响应数据

```typescript
interface ApiResponse {
  success: boolean;
  data: ReviewTaskItem[];
  message?: string;
}

interface ReviewTaskItem {
  id: number;
  registrationId: number;
  projectName: string;
  institutionName: string;
  institutionLevel: string;
  groupType: "BASIC" | "COMPREHENSIVE" | "ADVANCED";
  groupCode: string;
  stage: "BOOK" | "INTERVIEW" | "FINAL";
  status: "PENDING" | "SCORED";
  createdAt: string;
  reviewerId: number;
  reviewerName: string;
  reviewerInstitutionName: string;
  methodCode: string;
  methodLabel: string;
}
```

### 2.4 调用示例

```typescript
import axios from 'axios';

// 获取书审阶段所有任务
const response = await axios.get('/api/reviews/tasks/stage', {
  params: {
    competitionId: 21,
    stage: 'BOOK'
  },
  headers: {
    Authorization: `Bearer ${token}`
  }
});

const tasks = response.data.data;
console.log(`共 ${tasks.length} 条任务`);
```

<script>
export default {
  name: 'AssignedTasksDialog',
  data() {
    return {
      dialogVisible: false,
      loading: false,
      tasks: [],
      filters: {
        competitionId: null,
        stage: 'BOOK',
        groupType: null,
        groupCode: null,
        reviewerId: null,
        methodCode: null,
        status: null
      },
      reviewerOptions: []
    };
  },
  computed: {
    pendingCount() {
      return this.tasks.filter(t => t.status === 'PENDING').length;
    },
    scoredCount() {
      return this.tasks.filter(t => t.status === 'SCORED').length;
    },
    completionRate() {
      if (this.tasks.length === 0) return 0;
      return Math.round((this.scoredCount / this.tasks.length) * 100);
    }
  },
  methods: {
    async open(competitionId, stage) {
      this.filters.competitionId = competitionId;
      this.filters.stage = stage;
      this.dialogVisible = true;
      await this.fetchTasks();
    },
    
    async fetchTasks() {
      this.loading = true;
      try {
        const params = {};
        Object.keys(this.filters).forEach(key => {
          if (this.filters[key] != null && this.filters[key] !== '') {
            params[key] = this.filters[key];
          }
        });
        
        const response = await this.$http.get('/api/reviews/tasks/stage', { params });
        this.tasks = response.data.data;
        
        // 提取评委选项（用于筛选）
        this.updateReviewerOptions();
      } catch (error) {
        this.$message.error('获取任务列表失败：' + error.message);
      } finally {
        this.loading = false;
      }
    },
    
    updateReviewerOptions() {
      const reviewerMap = new Map();
      this.tasks.forEach(task => {
        if (task.reviewerId && !reviewerMap.has(task.reviewerId)) {
          reviewerMap.set(task.reviewerId, {
            id: task.reviewerId,
            name: task.reviewerName
          });
        }
      });
      this.reviewerOptions = Array.from(reviewerMap.values());
    },
    
    resetFilters() {
      this.filters.groupType = null;
      this.filters.groupCode = null;
      this.filters.reviewerId = null;
      this.filters.methodCode = null;
      this.filters.status = null;
      this.fetchTasks();
    },
    
    getGroupTypeLabel(type) {
      const labels = {
        'BASIC': '基层组',
        'COMPREHENSIVE': '综合组',
        'ADVANCED': '高级组'
      };
      return labels[type] || type;
    },
    
    getGroupTypeTagType(type) {
      const types = {
        'BASIC': 'success',
        'COMPREHENSIVE': 'warning',
        'ADVANCED': 'danger'
      };
      return types[type] || 'info';
    },
    
    formatDateTime(dateStr) {
      if (!dateStr) return '-';
      return dateStr.replace('T', ' ').substring(0, 19);
    }
  }
};
</script>

## 四、React + TypeScript 版本

```typescript
import React, { useState, useEffect, useMemo } from 'react';
import { Modal, Table, Form, Select, Button, Tag, Descriptions, message } from 'antd';
import type { ColumnsType } from 'antd/es/table';
import axios from 'axios';

interface ReviewTaskItem {
  id: number;
  registrationId: number;
  projectName: string;
  institutionName: string;
  institutionLevel: string;
  groupType: 'BASIC' | 'COMPREHENSIVE' | 'ADVANCED';
  groupCode: string;
  stage: 'BOOK' | 'INTERVIEW' | 'FINAL';
  status: 'PENDING' | 'SCORED';
  createdAt: string;
  reviewerId: number;
  reviewerName: string;
  reviewerInstitutionName: string;
  methodCode: string;
  methodLabel: string;
}

interface AssignedTasksDialogProps {
  visible: boolean;
  competitionId: number;
  stage: 'BOOK' | 'INTERVIEW' | 'FINAL';
  onClose: () => void;
}

export const AssignedTasksDialog: React.FC<AssignedTasksDialogProps> = ({
  visible,
  competitionId,
  stage,
  onClose
}) => {
  const [form] = Form.useForm();
  const [loading, setLoading] = useState(false);
  const [tasks, setTasks] = useState<ReviewTaskItem[]>([]);

  const fetchTasks = async (filters?: any) => {
    setLoading(true);
    try {
      const params = {
        competitionId,
        stage,
        ...filters
      };
      
      // 移除空值
      Object.keys(params).forEach(key => {
        if (params[key] == null || params[key] === '') {
          delete params[key];
        }
      });
      
      const response = await axios.get<{ data: ReviewTaskItem[] }>(
        '/api/reviews/tasks/stage',
        { params }
      );
      
      setTasks(response.data.data);
    } catch (error: any) {
      message.error('获取任务列表失败：' + error.message);
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    if (visible) {
      fetchTasks();
    }
  }, [visible, competitionId, stage]);

  const onSearch = () => {
    const values = form.getFieldsValue();
    fetchTasks(values);
  };

  const onReset = () => {
    form.resetFields();
    fetchTasks();
  };

  const reviewerOptions = useMemo(() => {
    const map = new Map<number, { id: number; name: string }>();
    tasks.forEach(task => {
      if (task.reviewerId && !map.has(task.reviewerId)) {
        map.set(task.reviewerId, {
          id: task.reviewerId,
          name: task.reviewerName
        });
      }
    });
    return Array.from(map.values());
  }, [tasks]);

  const statistics = useMemo(() => {
    const pending = tasks.filter(t => t.status === 'PENDING').length;
    const scored = tasks.filter(t => t.status === 'SCORED').length;
    const rate = tasks.length > 0 ? Math.round((scored / tasks.length) * 100) : 0;
    return { total: tasks.length, pending, scored, rate };
  }, [tasks]);

  const columns: ColumnsType<ReviewTaskItem> = [
    { title: '任务ID', dataIndex: 'id', width: 80 },
    { title: '项目名称', dataIndex: 'projectName', width: 200 },
    { title: '参赛机构', dataIndex: 'institutionName', width: 180 },
    { title: '机构等级', dataIndex: 'institutionLevel', width: 100 },
    {
      title: '竞赛组别',
      dataIndex: 'groupType',
      width: 100,
      render: (type: string) => {
        const labels: Record<string, string> = {
          'BASIC': '基层组',
          'COMPREHENSIVE': '综合组',
          'ADVANCED': '高级组'
        };
        const colors: Record<string, string> = {
          'BASIC': 'success',
          'COMPREHENSIVE': 'warning',
          'ADVANCED': 'error'
        };
        return <Tag color={colors[type]}>{labels[type]}</Tag>;
      }
    },
    { title: '分组', dataIndex: 'groupCode', width: 80 },
    { title: '评委', dataIndex: 'reviewerName', width: 120 },
    { title: '评委单位', dataIndex: 'reviewerInstitutionName', width: 180 },
    { title: '品管工具', dataIndex: 'methodLabel', width: 150 },
    {
      title: '状态',
      dataIndex: 'status',
      width: 100,
      render: (status: string) => (
        <Tag color={status === 'SCORED' ? 'success' : 'warning'}>
          {status === 'SCORED' ? '已评审' : '待评审'}
        </Tag>
      )
    },
    {
      title: '分配时间',
      dataIndex: 'createdAt',
      width: 160,
      render: (date: string) => date?.replace('T', ' ').substring(0, 19) || '-'
    }
  ];

  return (
    <Modal
      title="已分配任务列表"
      open={visible}
      onCancel={onClose}
      width="90%"
      footer={null}
      style={{ top: 20 }}>
      
      <Form form={form} layout="inline" style={{ marginBottom: 16 }}>
        <Form.Item name="groupType" label="竞赛组别">
          <Select style={{ width: 120 }} allowClear>
            <Select.Option value="BASIC">基层组</Select.Option>
            <Select.Option value="COMPREHENSIVE">综合组</Select.Option>
            <Select.Option value="ADVANCED">高级组</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item name="groupCode" label="分组">
          <Select style={{ width: 100 }} allowClear>
            <Select.Option value="A1">A1</Select.Option>
            <Select.Option value="A2">A2</Select.Option>
            <Select.Option value="A3">A3</Select.Option>
            <Select.Option value="B2">B2</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item name="reviewerId" label="评委">
          <Select
            style={{ width: 150 }}
            showSearch
            allowClear
            placeholder="输入姓名搜索"
            filterOption={(input, option) =>
              (option?.children as string).toLowerCase().includes(input.toLowerCase())
            }>
            {reviewerOptions.map(r => (
              <Select.Option key={r.id} value={r.id}>
                {r.name}
              </Select.Option>
            ))}
          </Select>
        </Form.Item>
        
        <Form.Item name="methodCode" label="品管工具">
          <Select style={{ width: 150 }} allowClear>
            <Select.Option value="qc_topic">品管圈-课题达成</Select.Option>
            <Select.Option value="qfd">QFD</Select.Option>
            <Select.Option value="method_5">根本原因分析</Select.Option>
            <Select.Option value="method_7">标杆学习</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item name="status" label="状态">
          <Select style={{ width: 100 }} allowClear>
            <Select.Option value="PENDING">待评审</Select.Option>
            <Select.Option value="SCORED">已评审</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item>
          <Button type="primary" onClick={onSearch}>查询</Button>
          <Button style={{ marginLeft: 8 }} onClick={onReset}>重置</Button>
        </Form.Item>
      </Form>
      
      <Table
        columns={columns}
        dataSource={tasks}
        rowKey="id"
        loading={loading}
        scroll={{ y: 500 }}
        pagination={false}
        bordered
      />
      
      <Descriptions column={4} bordered style={{ marginTop: 20 }}>
        <Descriptions.Item label="总任务数">{statistics.total}</Descriptions.Item>
        <Descriptions.Item label="待评审">{statistics.pending}</Descriptions.Item>
        <Descriptions.Item label="已评审">{statistics.scored}</Descriptions.Item>
        <Descriptions.Item label="完成率">{statistics.rate}%</Descriptions.Item>
      </Descriptions>
    </Modal>
  );
};
```

## 五、注意事项

### 5.1 权限控制

- 所有角色均可调用此API（需JWT Token）
- 前端应根据用户角色控制入口显示（如管理员可见）

### 5.2 性能优化

- 后端已使用`JOIN FETCH`优化查询
- 如数据量大（>100条），建议前端添加虚拟滚动
- **等待分页功能上线后，使用分页接口**

### 5.3 数据刷新

- 分配任务后，应自动刷新任务列表
- 建议每30秒自动刷新一次（轮询）

### 5.4 导出功能（可选）

可添加导出Excel功能，将筛选后的任务列表导出：
