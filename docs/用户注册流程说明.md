# 用户注册流程说明

## 📋 概述

品管大赛评审系统支持两种用户角色的注册：
- **参赛者（CONTESTANT）** - 需要选择所属医疗机构
- **评委（REVIEWER）** - 需要选择所属医疗机构和专业背景

## 🏥 医疗机构数据

### 数据来源
- **数据文件**: `2026.1全省医疗机构目录（按地市）（电子化注册系统导出）.xlsx`
- **总机构数**: 36,076 家医疗机构
- **覆盖范围**: 浙江省全省医疗机构

### 数据字段
- `id` - 机构ID（自动生成）
- `name` - 机构名称
- `code` - 机构代码（系统生成）
- `uscc` - 统一社会信用代码（唯一）
- `region` - 地区（如：杭州市、温州市等）
- `level` - 机构等级（三甲、二甲、三乙、二乙等）
- `createdAt` - 创建时间

## 🔄 注册流程

### 1. 获取地区列表（可选）

**接口**: `GET /api/institutions/regions`

**说明**: 获取所有可选地区列表，用于地区筛选

**响应示例**:
```json
{
  "success": true,
  "data": [
    "台州市",
    "温州市",
    "绍兴市",
    "金华市",
    ...
  ],
  "message": null
}
```

### 2. 搜索机构

**接口**: `GET /api/institutions/search`

**参数**:
- `keyword` (可选) - 搜索关键词（机构名称或地区）
- `page` (默认: 0) - 页码
- `size` (默认: 20) - 每页大小

**说明**: 
- 支持按机构名称或地区模糊搜索
- 返回分页结果
- 如果不提供keyword，则返回所有机构（分页）

**示例请求**:
```
GET /api/institutions/search?keyword=人民医院&page=0&size=20
GET /api/institutions/search?keyword=杭州&page=0&size=20
GET /api/institutions/search?page=0&size=20
```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "content": [
      {
        "id": 123,
        "name": "杭州市第一人民医院",
        "code": "INST_ABC123",
        "uscc": "91330100470001234X",
        "region": "杭州市",
        "level": "三甲",
        "createdAt": "2026-02-25T12:00:00"
      },
      ...
    ],
    "totalElements": 844,
    "totalPages": 43,
    "number": 0,
    "size": 20,
    "first": true,
    "last": false
  },
  "message": null
}
```

### 3. 按地区查询（可选）

**接口**: `GET /api/institutions/by-region/{region}`

**说明**: 获取指定地区的所有机构列表

**示例**:
```
GET /api/institutions/by-region/杭州市
```

### 4. 验证USCC（可选）

**接口**: `GET /api/institutions/by-uscc/{uscc}`

**说明**: 根据统一社会信用代码查询机构

**示例**:
```
GET /api/institutions/by-uscc/91330100470001234X
```

### 5. 注册/登录

**接口**: `POST /api/auth/login`

**说明**: 
- 如果用户不存在，自动创建新用户（注册）
- 如果用户存在，更新用户信息（登录）
- 返回JWT Token用于后续请求认证

**请求体（参赛者注册）**:
```json
{
  "phone": "13800138000",
  "name": "张三",
  "title": "主任医师",
  "role": "CONTESTANT",
  "institutionId": 123
}
```

**请求体（评委注册）**:
```json
{
  "phone": "13900139000",
  "name": "李四",
  "title": "教授",
  "role": "REVIEWER",
  "institutionId": 456,
  "expertBackground": "临床医学",
  "reviewerGroupCode": "BOOK_REVIEW_01",
  "interviewGroupCode": "INTERVIEW_01"
}
```

**字段说明**:
- `phone` (必填) - 手机号（唯一标识）
- `name` (必填) - 姓名
- `title` (可选) - 职称
- `role` (必填) - 角色类型
  - `CONTESTANT` - 参赛者
  - `REVIEWER` - 评委
  - `COMMITTEE` - 组委会成员
  - `COMMITTEE_ADMIN` - 组委会管理员
  - `OPS` - 系统运维
- `institutionId` (可选) - 所属机构ID
- `expertBackground` (评委可选) - 专业背景
- `reviewerGroupCode` (评委可选) - 书审组代码
- `interviewGroupCode` (评委可选) - 面试组代码

**响应示例**:
```json
{
  "success": true,
  "data": {
    "id": 789,
    "phone": "13800138000",
    "name": "张三",
    "title": "主任医师",
    "role": "CONTESTANT",
    "institutionId": 123,
    "institutionName": "杭州市第一人民医院",
    "institutionCode": "INST_ABC123",
    "institutionUscc": "91330100470001234X",
    "expertBackground": null,
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "message": null
}
```

## 📱 前端实现示例

### Vue.js 示例

```vue
<template>
  <div class="registration-form">
    <h2>用户注册</h2>
    
    <!-- 基本信息 -->
    <el-form :model="form" :rules="rules" ref="form">
      <el-form-item label="手机号" prop="phone">
        <el-input v-model="form.phone" placeholder="请输入手机号"></el-input>
      </el-form-item>
      
      <el-form-item label="姓名" prop="name">
        <el-input v-model="form.name" placeholder="请输入姓名"></el-input>
      </el-form-item>
      
      <el-form-item label="职称" prop="title">
        <el-input v-model="form.title" placeholder="如：主任医师"></el-input>
      </el-form-item>
      
      <el-form-item label="角色" prop="role">
        <el-select v-model="form.role" placeholder="请选择角色">
          <el-option label="参赛者" value="CONTESTANT"></el-option>
          <el-option label="评委" value="REVIEWER"></el-option>
        </el-select>
      </el-form-item>
      
      <!-- 机构选择 -->
      <el-form-item label="所属机构" prop="institutionId">
        <el-input
          v-model="searchKeyword"
          placeholder="搜索机构名称或地区"
          @input="searchInstitutions"
          clearable
        >
          <template #append>
            <el-button icon="el-icon-search" @click="searchInstitutions"></el-button>
          </template>
        </el-input>
        
        <el-select
          v-model="form.institutionId"
          filterable
          remote
          :remote-method="searchInstitutions"
          :loading="loading"
          placeholder="请选择机构"
          style="width: 100%; margin-top: 10px;"
        >
          <el-option
            v-for="inst in institutions"
            :key="inst.id"
            :label="`${inst.name} (${inst.region})`"
            :value="inst.id"
          >
            <span>{{ inst.name }}</span>
            <span style="float: right; color: #8492a6; font-size: 13px">
              {{ inst.region }} | {{ inst.level || '未定等' }}
            </span>
          </el-option>
        </el-select>
      </el-form-item>
      
      <!-- 评委专业背景（仅评委显示） -->
      <el-form-item v-if="form.role === 'REVIEWER'" label="专业背景">
        <el-input v-model="form.expertBackground" placeholder="如：临床医学"></el-input>
      </el-form-item>
      
      <el-form-item>
        <el-button type="primary" @click="submitForm" :loading="submitting">
          {{ submitting ? '注册中...' : '注册' }}
        </el-button>
      </el-form-item>
    </el-form>
  </div>
</template>

<script>
export default {
  data() {
    return {
      form: {
        phone: '',
        name: '',
        title: '',
        role: 'CONTESTANT',
        institutionId: null,
        expertBackground: ''
      },
      searchKeyword: '',
      institutions: [],
      loading: false,
      submitting: false,
      rules: {
        phone: [
          { required: true, message: '请输入手机号', trigger: 'blur' },
          { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号', trigger: 'blur' }
        ],
        name: [
          { required: true, message: '请输入姓名', trigger: 'blur' }
        ],
        role: [
          { required: true, message: '请选择角色', trigger: 'change' }
        ],
        institutionId: [
          { required: true, message: '请选择所属机构', trigger: 'change' }
        ]
      }
    };
  },
  methods: {
    async searchInstitutions(keyword) {
      if (!keyword && !this.searchKeyword) {
        keyword = '';
      } else {
        keyword = keyword || this.searchKeyword;
      }
      
      this.loading = true;
      try {
        const response = await this.$http.get('/api/institutions/search', {
          params: {
            keyword: keyword,
            page: 0,
            size: 50
          }
        });
        
        if (response.data.success) {
          this.institutions = response.data.data.content;
        }
      } catch (error) {
        this.$message.error('搜索机构失败');
      } finally {
        this.loading = false;
      }
    },
    
    async submitForm() {
      this.$refs.form.validate(async (valid) => {
        if (!valid) return;
        
        this.submitting = true;
        try {
          const response = await this.$http.post('/api/auth/login', this.form);
          
          if (response.data.success) {
            // 保存Token
            localStorage.setItem('token', response.data.data.token);
            localStorage.setItem('user', JSON.stringify(response.data.data));
            
            this.$message.success('注册成功');
            
            // 跳转到首页或其他页面
            this.$router.push('/');
          } else {
            this.$message.error(response.data.message || '注册失败');
          }
        } catch (error) {
          this.$message.error('注册失败: ' + error.message);
        } finally {
          this.submitting = false;
        }
      });
    }
  },
  mounted() {
    // 初始加载部分机构
    this.searchInstitutions('');
  }
};
</script>
```

### React 示例

```jsx
import React, { useState, useEffect } from 'react';
import axios from 'axios';

function RegistrationForm() {
  const [form, setForm] = useState({
    phone: '',
    name: '',
    title: '',
    role: 'CONTESTANT',
    institutionId: null,
    expertBackground: ''
  });
  
  const [searchKeyword, setSearchKeyword] = useState('');
  const [institutions, setInstitutions] = useState([]);
  const [loading, setLoading] = useState(false);
  const [submitting, setSubmitting] = useState(false);
  
  const searchInstitutions = async (keyword = '') => {
    setLoading(true);
    try {
      const response = await axios.get('/api/institutions/search', {
        params: {
          keyword: keyword || searchKeyword,
          page: 0,
          size: 50
        }
      });
      
      if (response.data.success) {
        setInstitutions(response.data.data.content);
      }
    } catch (error) {
      alert('搜索机构失败');
    } finally {
      setLoading(false);
    }
  };
  
  const handleSubmit = async (e) => {
    e.preventDefault();
    
    if (!form.phone || !form.name || !form.institutionId) {
      alert('请填写必填项');
      return;
    }
    
    setSubmitting(true);
    try {
      const response = await axios.post('/api/auth/login', form);
      
      if (response.data.success) {
        // 保存Token
        localStorage.setItem('token', response.data.data.token);
        localStorage.setItem('user', JSON.stringify(response.data.data));
        
        alert('注册成功');
        window.location.href = '/';
      } else {
        alert(response.data.message || '注册失败');
      }
    } catch (error) {
      alert('注册失败: ' + error.message);
    } finally {
      setSubmitting(false);
    }
  };
  
  useEffect(() => {
    searchInstitutions('');
  }, []);
  
  return (
    <div className="registration-form">
      <h2>用户注册</h2>
      
      <form onSubmit={handleSubmit}>
        <div className="form-group">
          <label>手机号 *</label>
          <input
            type="tel"
            value={form.phone}
            onChange={(e) => setForm({...form, phone: e.target.value})}
            placeholder="请输入手机号"
            required
          />
        </div>
        
        <div className="form-group">
          <label>姓名 *</label>
          <input
            type="text"
            value={form.name}
            onChange={(e) => setForm({...form, name: e.target.value})}
            placeholder="请输入姓名"
            required
          />
        </div>
        
        <div className="form-group">
          <label>职称</label>
          <input
            type="text"
            value={form.title}
            onChange={(e) => setForm({...form, title: e.target.value})}
            placeholder="如：主任医师"
          />
        </div>
        
        <div className="form-group">
          <label>角色 *</label>
          <select
            value={form.role}
            onChange={(e) => setForm({...form, role: e.target.value})}
            required
          >
            <option value="CONTESTANT">参赛者</option>
            <option value="REVIEWER">评委</option>
          </select>
        </div>
        
        <div className="form-group">
          <label>所属机构 *</label>
          <input
            type="text"
            value={searchKeyword}
            onChange={(e) => {
              setSearchKeyword(e.target.value);
              searchInstitutions(e.target.value);
            }}
            placeholder="搜索机构名称或地区"
          />
          
          <select
            value={form.institutionId || ''}
            onChange={(e) => setForm({...form, institutionId: parseInt(e.target.value)})}
            required
          >
            <option value="">请选择机构</option>
            {institutions.map(inst => (
              <option key={inst.id} value={inst.id}>
                {inst.name} ({inst.region}) - {inst.level || '未定等'}
              </option>
            ))}
          </select>
        </div>
        
        {form.role === 'REVIEWER' && (
          <div className="form-group">
            <label>专业背景</label>
            <input
              type="text"
              value={form.expertBackground}
              onChange={(e) => setForm({...form, expertBackground: e.target.value})}
              placeholder="如：临床医学"
            />
          </div>
        )}
        
        <button type="submit" disabled={submitting}>
          {submitting ? '注册中...' : '注册'}
        </button>
      </form>
    </div>
  );
}

export default RegistrationForm;
```

## ⚠️ 注意事项

1. **手机号唯一性**: 同一个手机号只能注册一次，重复提交会更新用户信息
2. **机构必选**: 参赛者和评委必须选择所属机构
3. **Token认证**: 注册成功后返回的Token需要保存，用于后续API调用
4. **搜索优化**: 建议实现防抖功能，避免频繁请求
5. **分页加载**: 机构列表支持分页，建议一次加载20-50条
6. **地区筛选**: 可先让用户选择地区，再在该地区内搜索机构

## 📊 API总结

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/api/institutions/regions` | GET | 获取所有地区列表 | 需要 |
| `/api/institutions/search` | GET | 搜索机构（分页） | 需要 |
| `/api/institutions/by-region/{region}` | GET | 按地区查询机构 | 需要 |
| `/api/institutions/by-uscc/{uscc}` | GET | 根据USCC查询机构 | 需要 |
| `/api/auth/login` | POST | 注册/登录 | 不需要 |
