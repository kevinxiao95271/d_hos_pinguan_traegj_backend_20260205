# 医院等级字典修复报告

## 问题描述

**用户反馈：**
> 注册环节给前端的下拉列表显示的是"二级"、"二甲"、"三甲"这几个，但是注册机构表中又是"三级"，这样都筛选不出来医院了。

**问题根源：**
字典表中**缺少** `type='institution_level'` 的数据，导致前端下拉框无法正确显示医院等级选项，或者显示的选项与数据库实际存储的值不匹配。

## 问题分析

### 1. 数据库实际情况

通过API `/api/institutions/levels` 查询，机构表中实际使用的医院等级值：

| 等级值 | 机构数量 |
|--------|---------|
| 三级 | 121个 |
| 未分级 | 3个 |
| 二级 | 1个 |
| 三甲 | 1个 |

### 2. 字典表缺失

修复前，通过API `/api/dictionaries/institution_level` 查询：
- **返回0条数据** ❌
- 字典表中完全没有 `institution_level` 类型的数据

### 3. 影响

1. **前端下拉框为空**：注册页面无法选择医院等级
2. **筛选功能失效**：管理后台无法按等级筛选机构
3. **数据不一致**：前端可能硬编码了一些等级选项，与数据库实际值不匹配

前端应统一使用字典API获取医院等级选项：

```javascript
// 推荐方式 - 使用字典API
async function loadInstitutionLevels() {
  const response = await fetch('/api/dictionaries/institution_level');
  const data = await response.json();
  
  if (data.success) {
    // data.data 包含所有等级选项
    this.institutionLevelOptions = data.data.map(item => ({
      value: item.code,    // 二级、三甲、三级等
      label: item.label    // 二级、三级甲等、三级等
    }));
  }
}
```
