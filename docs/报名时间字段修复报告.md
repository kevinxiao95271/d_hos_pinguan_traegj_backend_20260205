# 报名时间字段修复报告

## 📋 问题描述

**现象**：书审分组和面谈分组的列表中，报名时间（`submittedAt`）字段不显示

**影响范围**：
- ✅ `/api/admin/registrations/book-review-groups` - 书审分组列表
- ✅ `/api/admin/registrations/interview-groups` - 面谈分组列表
- ✅ `/api/admin/registrations/final-groups` - 终审分组列表

---

## 🔍 根因分析

### 问题1：测试数据缺失 `submitted_at`

**数据库检查结果**：
```
总报名数: 129条
submitted_at为NULL: 128条  ❌
submitted_at有值: 1条      ✅
```

**原因**：
`scripts/generate_test_registrations.py` 生成测试数据时，**只填充了 `created_at`，没有填充 `submitted_at`**：

```python
cursor.execute("""
    INSERT INTO registrations 
    (project_name, group_type, status, competition_id, applicant_id, institution_id, created_at)
    VALUES (%s, %s, %s, %s, %s, %s, %s)
""", (...))
# ❌ 缺少 submitted_at 字段
```

---

### 问题2：API返回字段缺失 `submittedAt`

**DTO检查结果**：
`GroupedRegistrationItem.java` 中**没有定义 `submittedAt` 字段**：

```java
public class GroupedRegistrationItem {
    private Long id;
    private Long registrationId;
    private String projectName;
    private String institutionName;
    private String institutionLevel;
    private GroupType groupType;
    private String groupCode;
    // ❌ 缺少 submittedAt 字段
}
```

**Service层问题**：
`RegistrationService.groupByGroupCode()` 方法中，**构造DTO时没有传入 `submittedAt`**：

```java
.map(reg -> new GroupedRegistrationItem(
    reg.getId(),
    reg.getProjectName(),
    reg.getInstitution().getName(),
    reg.getInstitution().getLevel(),
    reg.getGroupType(),
    reg.getGroupCode()
    // ❌ 缺少 reg.getSubmittedAt()
))
```

---

## 🛠️ 修复方案

### 修复1：补充 API 返回字段

#### 1.1 修改 `GroupedRegistrationItem.java`

**添加 `submittedAt` 字段**：

```java
@Schema(example = "2026-02-26T10:30:00", description = "报名提交时间")
private LocalDateTime submittedAt;
```

**修改构造函数**：

```java
public GroupedRegistrationItem(Long registrationId, String projectName, String institutionName, 
                               String institutionLevel, GroupType groupType, String groupCode, 
                               LocalDateTime submittedAt) {
    this.id = registrationId;
    this.registrationId = registrationId;
    this.projectName = projectName;
    this.institutionName = institutionName;
    this.institutionLevel = institutionLevel;
    this.groupType = groupType;
    this.groupCode = groupCode;
    this.submittedAt = submittedAt;  // ✅ 新增
}
```

#### 1.2 修改 `RegistrationService.java`

**在 `groupByGroupCode()` 方法中传入 `submittedAt`**：

```java
.map(reg -> new GroupedRegistrationItem(
    reg.getId(),
    reg.getProjectName(),
    reg.getInstitution().getName(),
    reg.getInstitution().getLevel(),
    reg.getGroupType(),
    reg.getGroupCode(),
    reg.getSubmittedAt()  // ✅ 新增
))
```

---

### 修复2：补充测试数据的 `submitted_at`

**创建修复脚本** `scripts/fix_submitted_at.py`：

**逻辑**：
1. 查询所有 `status = 'SUBMITTED'` 且 `submitted_at IS NULL` 的报名
2. 为每条记录生成一个合理的提交时间（`created_at` 之后 5分钟~24小时内）
3. 批量更新数据库

**执行结果**：
```
修复前：66条SUBMITTED状态的报名没有submitted_at
修复后：67条SUBMITTED状态的报名全部有submitted_at  ✅
```
