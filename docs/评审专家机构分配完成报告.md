### 验证所有专家都在三甲医院

```sql
-- 查询所有评审专家及其机构等级
SELECT 
    u.name as expert_name,
    u.phone,
    u.title,
    i.name as institution_name,
    i.level as institution_level
FROM user_accounts u
JOIN institutions i ON u.institution_id = i.id
WHERE u.role = 'REVIEWER';

-- 验证三甲占比
SELECT 
    COUNT(*) as total_reviewers,
    SUM(CASE WHEN i.level = '三甲' THEN 1 ELSE 0 END) as sanjia_count,
    ROUND(SUM(CASE WHEN i.level = '三甲' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as sanjia_percentage
FROM user_accounts u
JOIN institutions i ON u.institution_id = i.id
WHERE u.role = 'REVIEWER';

-- 结果应该是：
-- total_reviewers: 30
-- sanjia_count: 30
-- sanjia_percentage: 100.0
```

### 查看专家机构分布

```sql
-- 统计每家医院的专家数

    i.name as hospital_name,
```
