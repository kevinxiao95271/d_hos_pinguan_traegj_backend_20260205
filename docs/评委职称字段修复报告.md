- 书审阶段（BOOK）
- 面谈阶段（INTERVIEW）

## 七、注意事项

### 7.1 数据来源

评委职称（`reviewerTitle`）来自 `user_accounts` 表的 `title` 字段：

```sql
-- 评委注册时填写的职称
SELECT id, name, title 
FROM user_accounts 
WHERE role = 'REVIEWER';
```

### 7.2 空值处理

如果评委账号未填写职称，`reviewerTitle` 将返回 `null`：

```json
{
  "reviewerName": "张三",
  "reviewerTitle": null  // 未填写职称
}
```

**前端建议处理**:

```typescript
// Vue
{{ task.reviewerTitle || '未填写' }}

// React
{task.reviewerTitle || '未填写'}
```
