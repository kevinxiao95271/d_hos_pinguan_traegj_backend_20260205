# 项目摘要字段添加报告

## 问题描述

参赛者和评委查看报名详情时，项目摘要（projectSummary）缺少"运作"和"展示"两个字段。

用户反馈需要显示的7个分项字段：
- ✅ 计划 (plan)
- ✅ 问题 (problem)
- ✅ 行动 (action)
- ✅ 成效 (success)
- ✅ 回顾 (discussion)
- ❌ 运作 (operation) - **缺失**
- ❌ 展示 (presentation) - **缺失**

## 解决方案

### 1. 数据库修改

在 `project_summaries` 表中添加两个新字段：

```sql
-- 添加 operation 字段（运作）
ALTER TABLE project_summaries 
ADD COLUMN operation VARCHAR(1000) NULL COMMENT '运作' AFTER discussion;

-- 添加 presentation 字段（展示）
ALTER TABLE project_summaries 
ADD COLUMN presentation VARCHAR(1000) NULL COMMENT '展示' AFTER operation;
```

**执行脚本**: `add_project_summary_fields.sql`

### 2. 后端代码修改

#### 2.1 实体类 (ProjectSummary.java)

添加两个新字段：

```java
@Column(length = 1000)
private String operation;

@Column(length = 1000)
private String presentation;
```

#### 2.2 DTO (ProjectSummaryRequest.java)

添加两个新字段：

```java
private String operation;
private String presentation;
```

注意：这两个字段设置为可选（非 @NotBlank），因为可能是后期添加的功能。

#### 2.3 Service (RegistrationService.java)

在 `saveSummary` 方法中添加字段赋值：

```java
summary.setOperation(request.getOperation());
summary.setPresentation(request.getPresentation());
```

### 3. 影响的接口

#### 3.1 提交项目摘要
- **接口**: `POST /api/registrations/{id}/summary`
- **变化**: 请求体中可以包含 `operation` 和 `presentation` 字段

#### 3.2 查看报名详情
- **接口**: `GET /api/registrations/{id}`
- **变化**: 返回的 `projectSummary` 对象中包含 `operation` 和 `presentation` 字段

## 数据迁移说明

### 现有数据处理

- 新字段设置为 `NULL` 允许，不影响现有数据
- 已提交的报名，这两个字段将显示为 `null`
- 参赛者可以通过编辑功能补充这两个字段（如果报名状态允许）

### 前端适配

前端需要：

1. **表单提交**：在项目摘要提交表单中添加"运作"和"展示"两个输入框
2. **详情展示**：在报名详情页面显示这两个字段
3. **空值处理**：对于旧数据，这两个字段可能为 `null`，需要友好显示

## 注意事项

1. **向后兼容**：新字段为可选，不影响现有功能
2. **数据完整性**：旧数据的这两个字段为 `null`，前端需要处理
3. **权限控制**：字段的读写权限与其他摘要字段一致
4. **字段长度**：每个字段最大1000字符，与其他摘要字段一致
