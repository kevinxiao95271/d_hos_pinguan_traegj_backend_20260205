## 📋 字段详细说明

### 1. `id` (主键)
- **类型**: `bigint` (8字节整数)
- **约束**: NOT NULL, AUTO_INCREMENT
- **说明**: 机构唯一标识符，自动递增

### 2. `name` (机构名称)
- **类型**: `varchar(200)` (最长200个字符)
- **约束**: NOT NULL
- **说明**: 医疗机构全称
- **示例**: 
  - 浙江大学医学院附属第一医院
  - 浙江大学医学院附属第二医院
  - 浙江省人民医院

### 3. `code` (机构代码)
- **类型**: `varchar(64)` (最长64个字符)
- **约束**: NOT NULL, UNIQUE
- **说明**: 系统内部机构唯一代码
- **格式**: `INS-0001`, `INS-0002`, ...
- **用途**: 机构快速检索和关联

### 4. `uscc` (统一社会信用代码)
- **类型**: `varchar(32)` (最长32个字符)
- **约束**: NOT NULL, UNIQUE
- **说明**: 国家统一社会信用代码（18位）
- **格式**: `1233000047053349XG`
- **用途**: 机构法人识别，对接外部系统

### 5. `region` (地区)
- **类型**: `varchar(64)` (最长64个字符)
- **约束**: NULL (可空)
- **说明**: 机构所在地区
- **示例**: 
  - 杭州
  - 宁波
  - NULL (未填写)

### 6. `created_at` (创建时间)
- **类型**: `datetime`
- **约束**: NOT NULL
- **说明**: 机构记录创建时间
- **格式**: `YYYY-MM-DD HH:mm:ss`
- **示例**: `2026-02-04 23:45:40`

## 🎯 业务规则

### 唯一性约束
1. **机构代码 (`code`)**: 系统内唯一，格式为 `INS-XXXX`
2. **统一社会信用代码 (`uscc`)**: 全国唯一，18位字符

### 数据完整性
- ✅ 机构名称、代码、统一社会信用代码为**必填字段**
- ⚠️ 地区为**可选字段**，建议填写以便统计分析
- ✅ 创建时间由系统自动生成

### 数据安全
- 统一社会信用代码为敏感信息，需谨慎处理
- 建议对外API只暴露机构ID和名称，不暴露USCC

## 🛠️ 实体类定义

### Java Entity (JPA)

```java
@Entity
@Table(name = "institutions")
public class Institution {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(nullable = false, length = 200)
    private String name;
    
    @Column(nullable = false, length = 64, unique = true)
    private String code;
    
    @Column(nullable = false, length = 32, unique = true)
    private String uscc;
    
    @Column(length = 64)
    private String region;
    
    @Column(nullable = false)
    private LocalDateTime createdAt;
}
```

## 🔍 常用查询SQL

### 查询所有机构
```sql
SELECT * FROM institutions ORDER BY id ASC;
```

### 根据地区查询
```sql
SELECT * FROM institutions WHERE region = '杭州';
```

### 查询未填写地区的机构
```sql
SELECT * FROM institutions WHERE region IS NULL;
```

### 统计各地区机构数量
```sql
SELECT region, COUNT(*) as count 
FROM institutions 
GROUP BY region 
ORDER BY count DESC;
```
