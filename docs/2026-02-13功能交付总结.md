### 2. 组件复用

由于数据结构完全相同，可以复用书审得分列表的所有组件：

```vue
<template>
  <el-tabs v-model="activeTab" @tab-click="handleTabChange">
    <el-tab-pane label="书审得分" name="book"></el-tab-pane>
    <el-tab-pane label="面谈得分" name="interview"></el-tab-pane>
  </el-tabs>
  
  <ScoreTable :scores="scores" />
</template>

<script>
export default {
  methods: {
    async handleTabChange(tab) {
      const endpoint = tab.name === 'book' 
        ? '/api/admin/reviews/book-scores'
        : '/api/admin/reviews/interview-scores';
      
      const { data } = await axios.get(endpoint, {
        params: { competitionId: this.competitionId }
      });
      
      this.scores = data;
    }
  }
}
</script>
```

## 技术要点

### 1. 数据结构一致性
- 书审和面谈使用相同的`BookScoreItem`结构
- 前端可以完全复用组件和样式
- 只需改变API endpoint

### 2. 阶段区分
- 书审：`ReviewStage.BOOK`
- 面谈：`ReviewStage.INTERVIEW`
- 数据库通过`stage`字段区分

### 3. 业务差异
- 书审：所有组别（BASIC + ADVANCED）
- 面谈：通常只有进阶组（ADVANCED）
