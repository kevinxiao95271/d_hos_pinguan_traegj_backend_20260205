问题：按品管工具筛选返回空结果

原因：前端传递了label（品管圈-课题达成）而不是code（qc_topic）

================================================================================
  正确的API
================================================================================

GET /api/admin/registrations/filter

参数：
  - competitionId: 21 (必填)
  - methodCode: "qc_topic" (可选，使用code不是label)
  - groupType: "BASIC" (可选)
  - groupCode: "A1" (可选)
  - projectName: "护理" (可选，模糊匹配)
  - institutionName: "浙江" (可选，模糊匹配)
  - subjectTypeCode: "education" (可选)

================================================================================
  前端实现（核心代码）
================================================================================

// 1. 获取字典映射
const response = await axios.get('/api/dictionaries/method');
const methodMapping = {};
response.data.data.forEach(item => {
  methodMapping[item.label] = item.code;
});

// 2. 用户选择label
const selectedLabel = '品管圈-课题达成';

// 3. 转换为code
const methodCode = methodMapping[selectedLabel]; // 'qc_topic'

// 4. 调用筛选API
const result = await axios.get('/api/admin/registrations/filter', {
  params: {
    competitionId: 21,
    methodCode: methodCode  // 使用code
  }
});
