# 机构报名数量限制功能说明

## 功能概述

限制同一机构在同一赛事中的报名项目数量，防止单个机构提交过多项目。

## 业务规则

- **限制对象**：同一机构在同一赛事中
- **限制内容**：报名项目总数不得超过N个
- **默认值**：N = 8
- **可配置**：运维可通过系统设置修改限制值

## 实现方案

### 1. 系统设置

**配置键：** `maxRegistrationsPerInstitution`  
**默认值：** 8  
**说明：** 单个机构在单个赛事中允许的最大报名项目数

### 2. 检查逻辑

在创建报名时（`RegistrationService.create()`），系统会：

1. 查询系统设置获取限制值（默认8）
2. 统计该机构在该赛事中已有的报名数量
3. 如果已达上限，拒绝创建并返回错误信息

### 3. 错误提示

```
该机构报名数量已达上限（8个项目），无法继续报名
```

## API说明

### 1. 查询机构报名配额（前端使用）

**接口：** `GET /api/registrations/institution-quota`

**参数：**
- `competitionId` (必填): 赛事ID
- `institutionId` (必填): 机构ID

**响应示例：**
```json
{
  "success": true,
  "data": {
    "institutionId": 1,
    "institutionName": "浙江大学医学院附属第二医院（浙二医院）",
    "competitionId": 21,
    "competitionName": "2026浙江品管大赛",
    "currentCount": 2,
    "maxCount": 8,
    "remainingCount": 6,
    "canRegister": true
  }
}
```

**字段说明：**
- `currentCount`: 当前已报名数量
- `maxCount`: 最大允许报名数量
- `remainingCount`: 剩余可报名数量
- `canRegister`: 是否还可以报名（true/false）

### 1. RegistrationRepository.java

### 2. RegistrationService.java

在 `create()` 方法中添加检查逻辑：
```java
// 检查机构报名数量限制
int maxRegistrationsPerInstitution = systemSettingRepository
        .findBySettingKey("maxRegistrationsPerInstitution")
        .map(setting -> Integer.parseInt(setting.getSettingValue()))
        .orElse(8);  // 默认值为8

long currentCount = registrationRepository
        .findByCompetitionIdAndInstitutionId(competition.getId(), institution.getId())
        .size();

if (currentCount >= maxRegistrationsPerInstitution) {
    throw new IllegalArgumentException(
            String.format("该机构报名数量已达上限（%d个项目），无法继续报名", 
                         maxRegistrationsPerInstitution));
}
```

## 测试场景

### 场景1：正常报名（未达上限）

- 机构已报名：3个项目
- 限制值：8
- 结果：✅ 允许创建

### 场景2：达到上限

- 机构已报名：8个项目
- 限制值：8
- 结果：❌ 拒绝创建，提示"该机构报名数量已达上限（8个项目），无法继续报名"

### 场景3：修改限制值后

- 原限制值：8
- 修改为：10
- 机构已报名：8个项目
- 结果：✅ 允许继续创建（还可以创建2个）

## 注意事项

1. **统计范围**：统计的是该机构在该赛事中的所有报名（包括草稿、已提交、已退回等所有状态）
2. **实时检查**：每次创建报名时都会重新检查，确保限制有效
3. **默认值**：如果系统设置中没有配置，使用默认值8
4. **权限控制**：只有管理员可以修改系统设置
5. **不影响已有报名**：修改限制值不会影响已创建的报名
