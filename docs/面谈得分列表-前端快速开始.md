# 面谈得分列表 - 前端快速开始

## 一句话总结
面谈得分列表API与书审得分列表完全一致，只需改endpoint即可复用所有组件。

## 快速对接（3步）

### Step 1: API封装（5分钟）
```javascript
// api/review.js
export const getBookScores = (params) => {
  return axios.get('/api/admin/reviews/book-scores', { params });
};

export const getInterviewScores = (params) => {
  return axios.get('/api/admin/reviews/interview-scores', { params });
};
```

### Step 2: 组件复用（10分钟）
```vue
<template>
  <div>
    <el-tabs v-model="activeTab" @tab-click="handleTabChange">
      <el-tab-pane label="书审得分" name="book"></el-tab-pane>
      <el-tab-pane label="面谈得分" name="interview"></el-tab-pane>
    </el-tabs>
    
    <!-- 复用现有的书审得分表格组件 -->
    <BookScoreTable :data="scores" />
  </div>
</template>

<script>
import { getBookScores, getInterviewScores } from '@/api/review';

export default {
  data() {
    return {
      activeTab: 'book',
      scores: []
    };
  },
  methods: {
    async handleTabChange() {
      const api = this.activeTab === 'book' ? getBookScores : getInterviewScores;
      const { data } = await api({ competitionId: 21 });
      this.scores = data;
    }
  },
  mounted() {
    this.handleTabChange();
  }
}
</script>
```

### Step 3: 测试验证（5分钟）
1. 切换到"面谈得分"标签
2. 验证数据显示正常
3. 测试筛选功能

```javascript
getInterviewScores({
  competitionId: 21,
  groupType: 'ADVANCED'
});
```

### 按评委筛选
```javascript
getInterviewScores({
  competitionId: 21,
  reviewerId: 3
});
```

### 按机构筛选
```javascript
getInterviewScores({
  competitionId: 21,
  institutionId: 1

```

## 注意事项

1. **数据量差异**: 面谈得分通常比书审少（面谈主要是进阶组）
2. **默认筛选**: 建议默认筛选进阶组（`groupType=ADVANCED`）
3. **权限控制**: 需要管理员权限和JWT token
4. **组件复用**: 100%复用书审得分的表格、筛选、导出等组件
