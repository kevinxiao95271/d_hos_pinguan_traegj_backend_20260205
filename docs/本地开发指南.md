# 本地开发指南

## 🚀 本地服务启动

### 方式1：使用 Maven（推荐开发时使用）

```powershell
# 在项目根目录执行
mvn spring-boot:run
```

**优点：**
- 支持热重载（修改代码后自动重启）
- 调试方便
- 无需手动打包

**启动时间：** 约 15-20 秒

---

### 方式2：使用 JAR 包（推荐测试使用）

```powershell
# 1. 先打包
mvn clean package -DskipTests

# 2. 运行jar包
java -jar target/pinguan-backend-0.0.1-SNAPSHOT.jar
```

**优点：**
- 启动速度快
- 接近生产环境
- 资源占用少

## 🛑 停止服务

### 停止 Maven 启动的服务

```powershell
# 方法1：在运行Maven的终端按 Ctrl+C

# 方法2：查找并停止进程
Get-Process -Name "java" | Where-Object {$_.CommandLine -like "*spring-boot*"} | Stop-Process -Force
```

### 停止 JAR 启动的服务

```powershell
# 查找并停止Java进程
Get-Process -Name "java" | Where-Object {$_.CommandLine -like "*pinguan-backend*"} | Stop-Process -Force
```

## 🐛 常见问题

### Q1: 端口 6031 被占用

**错误信息：**
```
Port 6031 was already in use
```

**解决方法：**
```powershell
# 查找占用6031端口的进程
netstat -ano | findstr :6031

# 停止进程（替换<PID>为实际进程ID）
taskkill /PID <PID> /F
```

### Q2: 数据库连接失败

**错误信息：**
```
Communications link failure
```

**检查项：**
1. 网络连接是否正常
2. 数据库地址和端口是否正确
3. 用户名密码是否正确
4. 防火墙是否允许连接

### Q3: Maven 下载依赖慢

**解决方法：**

编辑 `~/.m2/settings.xml`，添加国内镜像：

```xml
<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <name>Aliyun Maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```
