# 项目负责人职称统计 - 前端使用指引

## 功能概述

报名统计API新增了项目负责人职称分布统计，可用于展示职称分布饼图。

---

## API接口

### 接口信息

- **路径**: `GET /api/admin/stats/summary`
- **权限**: 需要管理员权限（COMMITTEE角色）
- **参数**: `competitionId` (可选) - 不传则返回最新赛事

### 请求示例

```javascript
// 查询最新赛事统计
fetch('/api/admin/stats/summary', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})

// 查询指定赛事统计
fetch('/api/admin/stats/summary?competitionId=23', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```

## 响应数据

### 新增字段

```json
{
  "code": 200,

  "data": {
    "leaderTitleCounts": {
      "主管护师": 40,
      "药师": 28,

      "主治医师": 15,
      "医师": 13,
      "康复治疗师": 3
    }

```

### 字段说明

- **leaderTitleCounts**: 项目负责人职称分布
  - 类型: `Object` / `Record<string, number>`
  - Key: 职称名称
  - Value: 该职称的项目数量

### 2. 数据获取

```typescript
async function fetchStats(competitionId?: number): Promise<StatsSummaryResponse> {
  const url = competitionId 
    ? `/api/admin/stats/summary?competitionId=${competitionId}`
    : '/api/admin/stats/summary';
    
  const response = await fetch(url, {
    headers: {
      'Authorization': `Bearer ${getToken()}`
    }
  });
  
  const result = await response.json();
  if (result.code === 200) {
    return result.data;
  }
  throw new Error(result.message);
}
```

### 4. Chart.js 饼图示例

```typescript
import { Chart } from 'chart.js/auto';

function renderLeaderTitleChart(leaderTitleCounts: Record<string, number>) {
  const ctx = document.getElementById('leader-title-chart') as HTMLCanvasElement;
  
  const labels = Object.keys(leaderTitleCounts);
  const data = Object.values(leaderTitleCounts);
  
  new Chart(ctx, {
    type: 'pie',
    data: {
      labels: labels,
      datasets: [{
        label: '项目数量',
        data: data,
        backgroundColor: [
          'rgba(255, 99, 132, 0.8)',
          'rgba(54, 162, 235, 0.8)',
          'rgba(255, 206, 86, 0.8)',
          'rgba(75, 192, 192, 0.8)',
          'rgba(153, 102, 255, 0.8)',
          'rgba(255, 159, 64, 0.8)',
          'rgba(199, 199, 199, 0.8)'
        ]
      }]
    },
    options: {
      responsive: true,
      plugins: {
        legend: {
          position: 'right',
        },
        title: {
          display: true,
          text: '项目负责人职称分布'
        },
        tooltip: {
          callbacks: {
            label: function(context) {
              const label = context.label || '';
              const value = context.parsed || 0;
              const total = context.dataset.data.reduce((a, b) => a + b, 0);
              const percentage = ((value / total) * 100).toFixed(1);
              return `${label}: ${value}个项目 (${percentage}%)`;
            }
          }
        }
      }
    }
  });
}
```

### 5. React 组件示例

```tsx
import React, { useEffect, useState } from 'react';
import * as echarts from 'echarts';

interface LeaderTitleChartProps {
  competitionId?: number;
}

export const LeaderTitleChart: React.FC<LeaderTitleChartProps> = ({ competitionId }) => {
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  
  useEffect(() => {
    let chart: echarts.ECharts | null = null;
    
    async function loadData() {
      try {
        setLoading(true);
        const stats = await fetchStats(competitionId);
        
        // 初始化图表
        const chartDom = document.getElementById('leader-title-chart');
        if (chartDom) {
          chart = echarts.init(chartDom);
          
          const data = Object.entries(stats.leaderTitleCounts).map(([name, value]) => ({
            name,
            value
          }));
          
          chart.setOption({
            title: {
              text: '项目负责人职称分布',
              left: 'center'
            },
            tooltip: {
              trigger: 'item',
              formatter: '{b}: {c}个项目 ({d}%)'
            },
            legend: {
              orient: 'vertical',
              left: 'left'
            },
            series: [
              {
                name: '职称分布',
                type: 'pie',
                radius: '50%',
                data: data
              }
            ]
          });
        }
        
        setLoading(false);
      } catch (err) {
        setError(err.message);
        setLoading(false);
      }
    }
    
    loadData();
    
    // 清理
    return () => {
      if (chart) {
        chart.dispose();
      }
    };
  }, [competitionId]);
  
  if (loading) return <div>加载中...</div>;
  if (error) return <div>加载失败: {error}</div>;
  
  return (
    <div id="leader-title-chart" style={{ width: '600px', height: '400px' }} />
  );
};
```

## 数据处理建议

### 1. 数据排序

按项目数量降序排列：

```typescript
function sortLeaderTitles(leaderTitleCounts: Record<string, number>) {
  return Object.entries(leaderTitleCounts)
    .sort(([, a], [, b]) => b - a)
    .reduce((acc, [key, value]) => {
      acc[key] = value;
      return acc;
    }, {} as Record<string, number>);
}
```

### 2. 数据过滤

只显示前N个职称：

```typescript
function getTopNTitles(leaderTitleCounts: Record<string, number>, n: number = 5) {
  const sorted = Object.entries(leaderTitleCounts)
    .sort(([, a], [, b]) => b - a);
  
  const topN = sorted.slice(0, n);
  const others = sorted.slice(n);
  
  if (others.length > 0) {
    const othersCount = others.reduce((sum, [, count]) => sum + count, 0);
    topN.push(['其他', othersCount]);
  }
  
  return Object.fromEntries(topN);
}
```

### 3. 百分比计算

```typescript
function calculatePercentages(leaderTitleCounts: Record<string, number>) {
  const total = Object.values(leaderTitleCounts).reduce((sum, count) => sum + count, 0);
  
  return Object.entries(leaderTitleCounts).map(([title, count]) => ({
    title,
    count,
    percentage: ((count / total) * 100).toFixed(1) + '%'
  }));
}
```

## 注意事项

### 1. 数据可能为空

某些赛事可能没有项目负责人数据：

```typescript
if (stats.leaderTitleCounts && Object.keys(stats.leaderTitleCounts).length > 0) {
  renderLeaderTitleChart(stats.leaderTitleCounts);
} else {
  showEmptyState('暂无职称数据');
}
```

### 2. "未知"职称处理

建议在UI上特殊标注：

```typescript
function formatTitleName(title: string): string {
  return title === '未知' ? '未填写职称' : title;
}
```

// ECharts 响应式

## 常见问题

### Q1: 职称总数为什么小于报名总数？

A: 有些项目可能没有设置负责人，这些项目不会被统计。

### Q2: 如何处理职称名称过长？

A: 可以在图表中使用缩写，在tooltip中显示完整名称：

```typescript
legend: {
  formatter: (name) => {
    return name.length > 6 ? name.substring(0, 6) + '...' : name;
  }
}
```

### Q3: 如何自定义颜色？

A: 在ECharts中使用color配置：

```typescript
option: {
  color: ['#5470c6', '#91cc75', '#fac858', '#ee6666', '#73c0de', '#3ba272', '#fc8452']
}
```
