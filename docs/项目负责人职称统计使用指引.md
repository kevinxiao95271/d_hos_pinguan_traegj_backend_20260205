# 项目负责人职称统计功能使用指引

## 功能概述

报名统计API新增了**项目负责人职称分布**统计维度，用于前端展示饼图。

## API接口

### 获取报名统计（含职称分布）

**接口地址**: `GET /api/admin/stats/summary`

**权限要求**: 组委会管理员（COMMITTEE_ADMIN）

**请求参数**:
- `competitionId` (可选): 赛事ID，不传则使用最新赛事

**响应示例**:

## 新增字段说明

### leaderTitleCounts

**类型**: `Map<String, Integer>`

**说明**: 项目负责人职称分布统计

**数据来源**: 
- 从 `registration_members` 表中筛选 `role='PARTICIPANT'` 的成员
- 每个报名项目只统计一个负责人（第一个PARTICIPANT角色的成员）
- 按职称分组统计数量

**字段值示例**:
```json
{
  "主管护师": 19,
  "主治医师": 10,
  "药师": 9,
  "技师": 4,
  "医师": 3
}
```

## 前端展示建议

### 1. 饼图展示

使用ECharts或其他图表库展示职称分布饼图：

```javascript
// 示例：使用ECharts展示职称分布
const leaderTitleData = Object.entries(data.leaderTitleCounts).map(([name, value]) => ({
  name: name,
  value: value
}));

const option = {
  title: {
    text: '项目负责人职称分布',
    left: 'center'
  },
  tooltip: {
    trigger: 'item',
    formatter: '{b}: {c} ({d}%)'
  },
  legend: {
    orient: 'vertical',
    left: 'left'
  },
  series: [
    {
      name: '职称',
      type: 'pie',
      radius: '50%',
      data: leaderTitleData,
      emphasis: {
        itemStyle: {
          shadowBlur: 10,
          shadowOffsetX: 0,
          shadowColor: 'rgba(0, 0, 0, 0.5)'
        }
      }
    }
  ]
};
```

### 2. 表格展示

也可以用表格形式展示详细数据：

## 测试数据

使用赛事21（2026浙江品管大赛）进行测试：
- 报名总数: 45
- 职称分布: 主管护师19、主治医师10、药师9、技师4、医师3

## 注意事项

1. **空值处理**: 如果某个报名项目没有PARTICIPANT角色的成员，该项目不会被统计
2. **职称为空**: 如果成员的职称字段为空，会被统计为"未知"
3. **多个负责人**: 每个项目只统计第一个PARTICIPANT角色的成员职称
4. **权限控制**: 该接口需要组委会管理员权限，前端需要正确传递JWT token
