# 前端正确调用统计接口指南

## ⚠️ 重要提示

统计接口 `GET /api/admin/stats/summary` **必须传递 `competitionId` 参数**，否则会返回最新赛事（ID最大）的数据，而不是当前选中赛事的数据！

## 错误的调用方式 ❌

```javascript
// ❌ 错误：不传参数，会返回最新赛事（ID 29）
fetch('/api/admin/stats/summary', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})

// 结果：返回赛事29的数据（只有1条报名）
// 这不是用户当前选中的赛事！
```

## 正确的调用方式 ✅

```javascript
// ✅ 正确：传递当前选中的赛事ID
const currentCompetitionId = 21; // 从前端状态获取当前选中的赛事

fetch(`/api/admin/stats/summary?competitionId=${currentCompetitionId}`, {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})

// 结果：返回赛事21的数据（45条报名）
// 这是用户当前选中的赛事！
```

## 完整的前端实现示例

### Vue 3 示例

```vue
<template>
  <div>
    <!-- 赛事选择器 -->
    <el-select v-model="currentCompetitionId" @change="loadStats">
      <el-option 
        v-for="comp in competitions" 
        :key="comp.id" 
        :label="comp.name" 
        :value="comp.id"
      />
    </el-select>
    
    <!-- 统计图表 -->
    <div v-if="statsData">
      <h2>{{ statsData.competitionName }}</h2>
      <div ref="chartRef" style="width: 600px; height: 400px;"></div>
    </div>
  </div>
</template>

<script setup>
import { ref, watch } from 'vue';
import { useAuthStore } from '@/stores/auth';
import * as echarts from 'echarts';

const authStore = useAuthStore();
const currentCompetitionId = ref(21); // 默认选中赛事21
const statsData = ref(null);
const chartRef = ref(null);

// 监听赛事切换
watch(currentCompetitionId, () => {
  loadStats();
});

// 加载统计数据
const loadStats = async () => {
  if (!currentCompetitionId.value) {
    console.error('未选择赛事');
    return;
  }
  
  try {
    // ✅ 关键：必须传递 competitionId 参数
    const url = `/api/admin/stats/summary?competitionId=${currentCompetitionId.value}`;
    
    console.log('请求URL:', url); // 调试用
    
    const response = await fetch(url, {
      headers: {
        'Authorization': `Bearer ${authStore.token}`
      }
    });
    
    const result = await response.json();
    
    if (result.success) {
      statsData.value = result.data;
      
      // 验证返回的赛事ID是否正确
      if (result.data.competitionId !== currentCompetitionId.value) {
        console.error('返回的赛事ID不匹配！', {
          expected: currentCompetitionId.value,
          actual: result.data.competitionId
        });
      }
      
      // 绘制图表
      drawChart(result.data.regionCounts);
    } else {
      console.error('获取统计数据失败:', result.message);
    }
  } catch (error) {
    console.error('请求失败:', error);
  }
};

// 绘制图表
const drawChart = (regionCounts) => {
  const chart = echarts.init(chartRef.value);
  
  const data = Object.entries(regionCounts).map(([name, value]) => ({
    name,
    value
  }));
  
  chart.setOption({
    title: {
      text: '地区分布'
    },
    series: [{
      type: 'pie',
      data: data
    }]
  });
};

// 初始加载
loadStats();
</script>
```

### 通用函数封装

```javascript
/**
 * 获取指定赛事的统计数据
 * @param {number} competitionId - 赛事ID（必填！）
 * @param {string} token - 认证token
 * @returns {Promise<Object>} 统计数据
 */
async function getCompetitionStats(competitionId, token) {
  // 参数验证
  if (!competitionId) {
    throw new Error('competitionId 是必填参数！');
  }
  
  if (!token) {
    throw new Error('token 是必填参数！');
  }
  
  // 构建URL（必须包含 competitionId）
  const url = `/api/admin/stats/summary?competitionId=${competitionId}`;
  
  console.log(`[统计接口] 请求赛事 ${competitionId} 的统计数据`);
  
  const response = await fetch(url, {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  
  const result = await response.json();
  
  if (!result.success) {
    throw new Error(result.message || '获取统计数据失败');
  }
  
  // 验证返回的赛事ID
  if (result.data.competitionId !== competitionId) {
    console.warn('⚠️ 返回的赛事ID与请求不符！', {
      requested: competitionId,
      received: result.data.competitionId
    });
  }
  
  console.log(`[统计接口] 成功获取赛事 ${result.data.competitionId} 的数据`);
  console.log(`  - 赛事名称: ${result.data.competitionName}`);
  console.log(`  - 报名总数: ${result.data.registrationCount}`);
  
  return result.data;
}

// 使用示例
const token = localStorage.getItem('token');
const currentCompetitionId = 21; // 从状态管理获取

try {
  const stats = await getCompetitionStats(currentCompetitionId, token);
  console.log('地区分布:', stats.regionCounts);
} catch (error) {
  console.error('获取统计数据失败:', error);
}
```

## 常见错误

### 错误1: 不传 competitionId

```javascript
// ❌ 错误
fetch('/api/admin/stats/summary')

// 结果：返回赛事29（最新赛事）
// 问题：用户选的是赛事21，但看到的是赛事29的数据
```

### 错误2: 使用错误的变量

```javascript
// ❌ 错误：使用了错误的变量名
const selectedCompetition = 21;
fetch(`/api/admin/stats/summary?competitionId=${competitionId}`) // competitionId 未定义

// ✅ 正确
const selectedCompetition = 21;
fetch(`/api/admin/stats/summary?competitionId=${selectedCompetition}`)
```

### 错误3: 没有监听赛事切换

```javascript
// ❌ 错误：只在组件加载时调用一次
useEffect(() => {
  loadStats();
}, []); // 空依赖数组

// ✅ 正确：监听赛事ID变化
useEffect(() => {
  loadStats();
}, [currentCompetitionId]); // 依赖赛事ID
```

## 浏览器开发者工具检查

### 1. 打开 Network 面板

1. 按 F12 打开开发者工具
2. 切换到 Network 标签
3. 刷新页面或触发统计数据加载

### 2. 查找统计接口请求

找到 `stats/summary` 请求，检查：

```
Request URL: http://localhost:6031/api/admin/stats/summary?competitionId=21
```

**如果URL中没有 `?competitionId=21`，那就是问题所在！**

### 3. 查看响应数据

点击请求，查看 Response 标签：

```json
{
  "success": true,
  "data": {
    "competitionId": 21,  // ← 检查这个值
    "competitionName": "2026浙江品管大赛",
    "registrationCount": 45,
    ...
  }
}
```

**如果 `competitionId` 不是你期望的值，说明请求参数有问题！**

## 总结

✅ **必须传递 `competitionId` 参数**  
✅ **参数值应该是当前选中的赛事ID**  
✅ **监听赛事切换事件，重新加载数据**  
✅ **验证返回的赛事ID是否正确**  

❌ **不要不传参数**  
❌ **不要使用硬编码的赛事ID**  
❌ **不要忘记监听赛事切换**
