### 3. ✅ 修改 RegistrationService 关联查询材料

**文件**: `src/main/java/com/trae/pinguan/service/RegistrationService.java`

**变更内容**: 在 `filterRegistrations` 方法中添加材料文件查询和组装逻辑

```java
public List<RegistrationFilterItem> filterRegistrations(...) {
    // ... 原有的基本信息查询 ...
    
    // 批量查询材料文件
    List<Long> registrationIds = items.stream()
            .map(RegistrationFilterItem::getRegistrationId)
            .collect(Collectors.toList());
    
    if (!registrationIds.isEmpty()) {
        // 查询所有材料文件并按 registration_id 分组
        Map<Long, List<MaterialFile>> materialsMap = materialRepository
                .findByRegistrationIdIn(registrationIds)
                .stream()
                .collect(Collectors.groupingBy((MaterialFile m) -> m.getRegistration().getId()));
        
        // 组装材料文件到每个 item
        for (RegistrationFilterItem item : items) {
            List<MaterialFile> materials = materialsMap.getOrDefault(
                    item.getRegistrationId(), new ArrayList<>()
            );
            
            List<RegistrationFilterItem.MaterialFileSimple> materialSimples = materials.stream()
                    .map(m -> new RegistrationFilterItem.MaterialFileSimple(
                            m.getId(),
                            m.getType(),
                            m.getFileName(),
                            "/api/materials/" + m.getId() + "/download"
                    ))
                    .collect(Collectors.toList());
            
            item.setMaterials(materialSimples);
        }
    }
    
    return items;
}
```

**作用**: 
- 批量查询所有列表项的材料文件
- 按 registration_id 分组
- 组装到每个列表项的 materials 字段中
- 预构建下载 URL

```java
@GetMapping("/{id}/download")
@Operation(summary = "下载材料文件")
public ResponseEntity<InputStreamResource> download(@PathVariable Long id) {
    MaterialFile material = materialService.getById(id);
    
    // 从 MinIO 获取文件流
    String bucketName = minioProperties.getBucket().getRegistrationFiles();
    InputStream inputStream = fileStorageService.getInputStream(
        material.getFileUrl(), bucketName
    );
    
    // URL 编码文件名（支持中文）
    String encodedFilename;
    try {
        encodedFilename = URLEncoder.encode(material.getFileName(), "UTF-8")
            .replace("+", "%20");
    } catch (UnsupportedEncodingException e) {
        throw new IllegalStateException("UTF-8 encoding not supported", e);
    }
    
    return ResponseEntity.ok()
        .contentType(MediaType.APPLICATION_OCTET_STREAM)
        .header(HttpHeaders.CONTENT_DISPOSITION, 
                "attachment; filename*=UTF-8''" + encodedFilename)
        .body(new InputStreamResource(inputStream));
}
```

**同时新增 MaterialService 方法**:
```java
public MaterialFile getById(Long materialId) {
    return materialFileRepository.findById(materialId)
            .orElseThrow(() -> new IllegalArgumentException("材料文件不存在"));
}
```

**作用**: 提供材料文件下载接口，从 MinIO 读取文件流并返回。

                @click="downloadMaterial(material)"
              >
                {{ getMaterialTypeLabel(material.type) }}
                <i class="el-icon-download el-icon--right"></i>
              </el-tag>
            </el-tooltip>
          </div>
          <span v-else style="color: #ccc">暂无文件</span>
        </template>
      </el-table-column>
      
      <el-table-column label="操作" width="200" fixed="right">
        <template slot-scope="scope">
          <el-button size="small" @click="viewDetail(scope.row.registrationId)">
            查看详情
          </el-button>
          <el-button size="small" type="primary" @click="review(scope.row.registrationId)">
            评审
          </el-button>
        </template>
      </el-table-column>
    </el-table>
  </div>
</template>

<script>
export default {
  data() {
    return {
      registrations: []
    }
  },
  
  async mounted() {
    await this.loadRegistrations()
  },
  
  methods: {
    async loadRegistrations() {
      try {
        const response = await this.$axios.get('/api/admin/registrations/filter', {
          params: {
            competitionId: this.$route.query.competitionId,
            status: 'SUBMITTED'
          },
          headers: {
            'Authorization': `Bearer ${this.$store.state.token}`
          }
        })
        
        this.registrations = response.data.data
      } catch (error) {
        this.$message.error('加载列表失败')
      }
    },
    
    async downloadMaterial(material) {
      try {
        // 方式1：直接打开新窗口下载（简单）
        // window.open(material.downloadUrl + '?token=' + this.$store.state.token, '_blank')
        
        // 方式2：使用 axios 下载（更好的控制）
        const response = await this.$axios.get(material.downloadUrl, {
          responseType: 'blob',
          headers: {
            'Authorization': `Bearer ${this.$store.state.token}`
          }
        })
        
        // 创建下载链接
        const url = window.URL.createObjectURL(new Blob([response.data]))
        const link = document.createElement('a')
        link.href = url
        link.setAttribute('download', material.fileName)
        document.body.appendChild(link)
        link.click()
        link.remove()
        window.URL.revokeObjectURL(url)
        
        this.$message.success('下载成功')
      } catch (error) {
        this.$message.error('下载失败')
      }
    },
    
    getMaterialTypeLabel(type) {
      const labels = {
        'registration_form': '报名表',
        'result_report': '成果报告',
        'supporting_materials': '支撑材料'
      }
      return labels[type] || type
    },
    
    getMaterialTagType(type) {
      const types = {
        'registration_form': 'success',
        'result_report': 'warning',
        'supporting_materials': 'info'
      }
      return types[type] || 'info'
    },
    
    viewDetail(registrationId) {
      this.$router.push(`/admin/registration/${registrationId}`)
    },
    
    review(registrationId) {
      this.$router.push(`/review/${registrationId}`)
    }
  }
}
</script>

## 📊 数据库查询分析

### 执行的 SQL 查询

#### 1. 基本信息查询（已有）
```sql
SELECT 
    r.id, r.project_name, i.name, i.level, r.group_type, 
    r.group_code, r.submitted_at, a.subject_type_code, 
    a.method_code, r.applicant_name
FROM registrations r
LEFT JOIN institutions i ON r.institution_id = i.id
LEFT JOIN activity_infos a ON r.id = a.registration_id
WHERE r.competition_id = ? 
  AND r.status = 'SUBMITTED'
  AND r.group_type = 'ADVANCED';
```

#### 2. 批量查询材料文件（新增）
```sql
SELECT m.* 
FROM material_files m
WHERE m.registration_id IN (123, 124, 125, ..., 172);
```

**优势**:
- 使用 `IN` 子句批量查询
- 避免循环查询（N+1 问题）
- 单次查询完成所有材料文件获取

## ⚠️ 注意事项

### 1. 权限控制

**当前实现**: 需要 JWT token

**权限策略**:
- ✅ **CONTESTANT（参赛者）**: 只能下载自己的材料
- ✅ **OPS（运维）**: 可以下载所有材料
- ✅ **COMMITTEE（组委会）**: 可以下载所有材料
- ✅ **REVIEWER（评委）**: 可以下载分配给自己的项目材料

**建议**: 在 `MaterialController.download` 方法中添加权限检查逻辑

```java
@GetMapping("/{id}/download")
public ResponseEntity<InputStreamResource> download(
        @PathVariable Long id,
        HttpServletRequest request) {
    MaterialFile material = materialService.getById(id);
    
    // 权限检查
    String role = (String) request.getAttribute("role");
    Long userId = Long.parseLong((String) request.getAttribute("userId"));
    
    if ("CONTESTANT".equals(role)) {
        // 参赛者只能下载自己的材料
        if (!material.getRegistration().getApplicant().getId().equals(userId)) {
            throw new ResponseStatusException(HttpStatus.FORBIDDEN, "无权下载该材料");
        }
    }
    // OPS 和 COMMITTEE 可以下载所有材料（无需检查）
    
    // ... 原有下载逻辑 ...
}
```
