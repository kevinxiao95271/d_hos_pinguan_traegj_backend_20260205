**实施时间：** 2026-02-28  
**状态：** ✅ 已完成

---

## 📋 背景

评审专家不仅来自医院机构，还包括以下外部机构：
- 卡内基
- 浙江省护理质控中心
- 浙江省质量协会
- 浙江省医疗服务管理评价中心

## ✅ 实施方案

### 方案选择

采用**方案1：将外部机构创建为 Institution 记录**

**理由：**
- ✅ 无需修改代码
- ✅ 数据结构统一
- ✅ 前端无需修改
- ✅ 便于管理和扩展

---

## 🔧 技术实现

### 1. 数据库变更

#### 添加标识字段

```sql
ALTER TABLE institutions 
ADD COLUMN is_ext TINYINT NOT NULL DEFAULT 0 
COMMENT '是否外部机构: 0-医院, 1-外部机构';
```

**字段说明：**
- `is_ext = 0`：普通医院机构（默认）
- `is_ext = 1`：外部机构

**用途：**
- 仅作标记，方便后续识别
- 代码逻辑不依赖此字段
- 可用于统计和数据分析

#### 插入外部机构

| ID | 名称 | Code | USCC | Region | Level | is_ext |
|----|------|------|------|--------|-------|--------|
| 36257 | 卡内基 | EXT_CARNEGIE | EXT000000001 | 外部 | 外部机构 | 1 |
| 36258 | 浙江省护理质控中心 | EXT_NURSING_QC | EXT000000002 | 浙江省 | 外部机构 | 1 |
| 36259 | 浙江省质量协会 | EXT_QUALITY_ASSOC | EXT000000003 | 浙江省 | 外部机构 | 1 |

## 💡 使用说明

### 1. 创建评审专家

管理员在创建评审专家时，可以选择外部机构：

```json
POST /api/admin/users/reviewers

{
  "phone": "13800138000",
  "name": "张三",
  "title": "专家",
  "institutionId": 36257,  // 卡内基的ID
  "reviewerGroupCode": "GROUP_A"
}
```

### 2. 前端展示

前端在机构下拉框中，会自动显示这4个外部机构，与医院机构一视同仁。

### 3. 查询外部机构专家

```sql
-- 查询来自外部机构的评审专家
SELECT 
    u.id,
    u.name,
    u.phone,
    i.name AS institution_name,
    i.is_ext
FROM user_accounts u
JOIN institutions i ON u.institution_id = i.id
WHERE u.role = 'REVIEWER' 
  AND i.is_ext = 1;
```

### 4. 统计

```sql
-- 按机构类型统计评审专家
SELECT 
    CASE WHEN i.is_ext = 0 THEN '医院' ELSE '外部机构' END AS type,
    COUNT(*) AS reviewer_count
FROM user_accounts u
JOIN institutions i ON u.institution_id = i.id
WHERE u.role = 'REVIEWER'
GROUP BY i.is_ext;
```

## 📝 注意事项

1. **不影响现有功能**
   - 现有代码无需修改
   - 前端无需修改
   - API接口保持不变

2. **is_ext 字段用途**
   - 仅作标记，方便识别
   - 代码逻辑不强制依赖
   - 可用于数据分析和统计

3. **扩展性**
   - 如需添加新的外部机构，继续插入记录即可
   - 保持 is_ext=1 标识
   - code 和 uscc 使用 EXT_ 前缀避免冲突

4. **Code 和 USCC 规则**
   - 外部机构使用 EXT_ 前缀
   - 确保唯一性，避免与医院冲突
