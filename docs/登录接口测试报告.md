## Swagger使用指引

### 访问地址
```
http://localhost:6031/swagger-ui/index.html
```

### 登录步骤

1. **找到登录接口**
   - 展开"认证"分组
   - 找到 `POST /api/auth/login`

2. **点击 Try it out**

3. **填写请求体**
   ```json
   {
     "phone": "13800000041",
     "name": "CommitteeAdmin A",
     "role": "COMMITTEE_ADMIN"
   }
   ```

4. **点击 Execute**

5. **复制Token**
   - 从响应中复制 `data.token` 的值

6. **设置Authorization**
   - 点击页面顶部的 "Authorize" 按钮
   - 输入: `Bearer <你的token>`
   - 点击 "Authorize" 和 "Close"

7. **测试其他接口**
   - 现在可以测试任何需要认证的接口

## 注意事项

1. **Token有效期**: 24小时
2. **重启服务器**: 如果再次出现超时，重启服务器即可解决
3. **数据库连接**: 确保PostgreSQL服务正常运行
4. **并发测试**: 建议进行压力测试验证并发性能
