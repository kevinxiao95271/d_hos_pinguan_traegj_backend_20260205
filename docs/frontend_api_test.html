📊 统计接口测试工具

用于验证后端API是否返回"其他"分类

1️⃣ 登录获取Token

2️⃣ 测试统计接口

📝 使用说明

  1. 点击"登录"按钮获取Token（会自动保存到localStorage）
  2. 选择要测试的赛事ID
  3. 点击"测试接口"查看结果
  4. 检查返回的地区分布中是否有"其他"分类

✅ 期望结果

  • 赛事21: 返回11个浙江省地级市，没有"其他"分类
  • 赛事29: 返回1个地区（杭州），没有"其他"分类
  • 不传参数: 返回最新赛事（ID最大）的数据

⚠️ 注意事项

  • 如果API返回的数据中没有"其他"，但图表中有，那是前端处理的问题
  • 如果选择"不传参数"，会返回赛事29而不是赛事21
  • 前端应该根据当前选中的赛事传递competitionId参数
