【常见错误及解决】

❌ 错误1: 字段名写错
{
  "items": [...]  // ❌ 应该是 members
}

✅ 正确:
{
  "members": [...]  // ✅ 正确
}

---

❌ 错误2: Code值格式不对
{
  "subjectTypeCode": "PATIENT_CARE"  // ❌ 不是这种格式
}

✅ 正确:
{
  "subjectTypeCode": "subject_type_1"  // ✅ 使用下划线格式
}

---

❌ 错误3: 必填字段缺失
{
  "name": "",  // ❌ 空字符串
  "title": null  // ❌ null
}

✅ 正确:
{
  "name": "张三",  // ✅ 非空字符串
  "title": "主管护师"  // ✅ 非空字符串
}
