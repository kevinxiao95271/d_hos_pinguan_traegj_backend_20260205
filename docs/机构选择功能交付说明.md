## 🎯 用户注册流程设计

### 推荐流程：地区优先

```
步骤1: 用户打开注册页面
       ↓
       显示最近使用的机构（如有）
       显示热门地区标签
       
步骤2: 用户选择地区
       ↓
       调用: POST /api/institutions/search
       { "region": "杭州市", "page": 0, "size": 20 }
       返回: 该地区前20家机构
       
步骤3: 用户输入搜索关键词（可选）
       ↓
       调用: POST /api/institutions/search
       { "keyword": "人民", "region": "杭州市", "page": 0, "size": 20 }
       返回: 精确匹配结果
       
步骤4: 用户滚动加载更多（可选）
       ↓
       调用: POST /api/institutions/search
       { "keyword": "人民", "region": "杭州市", "page": 1, "size": 20 }
       
步骤5: 用户选择机构
       ↓
       保存 institutionId
       
步骤6: 填写其他信息并提交
       ↓
       调用: POST /api/auth/login
       {
         "phone": "13800138000",
         "name": "张三",
         "title": "主任医师",
         "role": "CONTESTANT",
         "institutionId": 123
       }
       
步骤7: 注册成功
       ↓
       保存Token，进入原有报名流程
```

## 📱 前端集成建议

### 关键点

1. **防抖搜索**: 用户输入时延迟500ms再请求
2. **最少字符**: 至少2个字符才触发搜索
3. **虚拟滚动**: 列表超过100条时使用虚拟滚动
4. **懒加载**: 滚动到底部时自动加载下一页
5. **缓存**: 缓存已加载的数据30分钟
6. **最近使用**: 保存最近选择的5个机构
