## 一、用户需求场景

1. **书审阶段**：多个评委的评分记录
2. **面谈阶段**：多个评委的评分记录
3. 每条记录需要显示：

   - 评委单位

   - 亮点评语
   - 改进建议
   - 评审时间

## 三、数据表结构分析

### 核心表结构

#### 1. review_tasks（评审任务表）
```sql
CREATE TABLE review_tasks (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    stage VARCHAR(32) NOT NULL,           -- BOOK/INTERVIEW/FINAL
    registration_id BIGINT NOT NULL,      -- 关联报名
    reviewer_id BIGINT NOT NULL,          -- 关联评委
    status VARCHAR(32) NOT NULL,          -- PENDING/SCORED
    created_at DATETIME NOT NULL
);
```

#### 2. review_scores（评审评分表）
```sql
CREATE TABLE review_scores (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    review_task_id BIGINT UNIQUE NOT NULL,  -- 一对一关联review_tasks
    plan INT NOT NULL,                      -- 计划维度得分
    problem INT NOT NULL,                   -- 问题维度得分
    action INT NOT NULL,                    -- 行动维度得分
    success INT NOT NULL,                   -- 成效维度得分
    review INT NOT NULL,                    -- 回顾维度得分
    operation INT NOT NULL,                 -- 运作维度得分
    presentation INT NOT NULL,              -- 展示维度得分
    total INT NOT NULL,                     -- 总分
    highlight VARCHAR(500) NOT NULL,        -- 亮点
    weakness VARCHAR(500) NOT NULL,         -- 改进建议
    submitted_at DATETIME NOT NULL          -- 提交时间
);
```

#### 3. user_accounts（用户表，包含评委信息）
```sql
CREATE TABLE user_accounts (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    phone VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    title VARCHAR(100),                     -- 职称
    role VARCHAR(32) NOT NULL,              -- REVIEWER等
    institution_id BIGINT,                  -- 关联机构
    ...
);
```

#### 4. institutions（机构表）
```sql
CREATE TABLE institutions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(64) UNIQUE NOT NULL,
    level VARCHAR(32),                      -- 医院等级
    ...
);
```

### 数据关系
```
review_tasks (评审任务)
    ├─ registration_id → registrations (报名项目)
    ├─ reviewer_id → user_accounts (评委)
    │       └─ institution_id → institutions (评委单位)
    └─ review_task_id ← review_scores (评审评分，一对一)
```

#### 步骤2: Service层实现

**ReviewService.java - 新增方法**
```java
@Transactional(readOnly = true)
public List<ReviewerScoreDetail> getReviewerScoresByRegistration(
        Long registrationId, 
        ReviewStage stage) {
    
    List<ReviewerScoreDetail> results = new ArrayList<>();
    
    // 构建查询条件
    List<ReviewTask> tasks;
    if (stage == null) {
        tasks = reviewTaskRepository.findByRegistrationId(registrationId);
    } else {
        tasks = reviewTaskRepository.findByRegistrationIdAndStage(
            registrationId, stage);
    }
    
    // 遍历评审任务
    for (ReviewTask task : tasks) {
        // 只处理已评分的任务
        if (task.getStatus() != ReviewStatus.SCORED) {
            continue;
        }
        
        // 获取评分记录
        ReviewScore score = reviewScoreRepository
            .findByReviewTaskId(task.getId())
            .orElse(null);
        if (score == null) {
            continue;
        }
        
        // 获取评委信息
        UserAccount reviewer = task.getReviewer();
        Institution institution = reviewer.getInstitution();
        
        // 构建返回对象
        results.add(ReviewerScoreDetail.builder()
            .stage(task.getStage())
            .reviewerId(reviewer.getId())
            .reviewerName(reviewer.getName())
            .reviewerTitle(reviewer.getTitle())
            .reviewerInstitutionId(institution == null ? null : institution.getId())
            .reviewerInstitutionName(institution == null ? null : institution.getName())
            .reviewerInstitutionLevel(institution == null ? null : institution.getLevel())
            .scores(ScoreBreakdown.builder()
                .plan(score.getPlan())
                .problem(score.getProblem())
                .action(score.getAction())
                .success(score.getSuccess())
                .review(score.getReview())
                .operation(score.getOperation())
                .presentation(score.getPresentation())
                .total(score.getTotal())
                .build())
            .highlight(score.getHighlight())
            .weakness(score.getWeakness())
            .submittedAt(score.getSubmittedAt())
            .build());
    }
    
    // 按阶段、评委ID排序
    results.sort(Comparator
        .comparing(ReviewerScoreDetail::getStage)
        .thenComparing(ReviewerScoreDetail::getReviewerId));
    
    return results;
}
```

```java
@GetMapping("/{id}/reviewer-scores")
@Operation(summary = "报名的多评委评分详情")
public ApiResponse<List<ReviewerScoreDetail>> reviewerScores(
        @PathVariable Long id,
        @RequestParam(required = false) ReviewStage stage,
        HttpServletRequest request) {
    
    // 获取当前用户
    Long currentUserId = (Long) request.getAttribute("userId");
    String role = (String) request.getAttribute("role");
    
    // 权限检查
    if ("CONTESTANT".equals(role)) {

        if (!currentUserId.equals(registration.getApplicant().getId())) {
            throw new ResponseStatusException(HttpStatus.FORBIDDEN, "无权限");
        }
    }
    // COMMITTEE和OPS可以查看所有
    
    return ApiResponse.ok(reviewService.getReviewerScoresByRegistration(id, stage));
}
```

## 八、数据验证SQL

### 验证SQL 1: 检查项目106的评审记录
```sql
SELECT 
    rt.stage AS 阶段,
    u.name AS 评委姓名,
    u.title AS 评委职称,
    i.name AS 评委单位,
    i.level AS 医院等级,
    rs.plan AS 计划,
    rs.problem AS 问题,
    rs.action AS 行动,
    rs.success AS 成效,
    rs.review AS 回顾,
    rs.operation AS 运作,
    rs.presentation AS 展示,
    rs.total AS 总分,
    LEFT(rs.highlight, 20) AS 亮点摘要,
    LEFT(rs.weakness, 20) AS 改进建议摘要,
    rs.submitted_at AS 评审时间
FROM review_tasks rt
LEFT JOIN review_scores rs ON rs.review_task_id = rt.id
LEFT JOIN user_accounts u ON u.id = rt.reviewer_id
LEFT JOIN institutions i ON i.id = u.institution_id
WHERE rt.registration_id = 106
  AND rt.status = 'SCORED'
ORDER BY rt.stage, u.name;
```

### 验证SQL 2: 统计各项目的评委数
```sql
SELECT 
    r.id AS 报名ID,
    r.project_name AS 项目名称,
    rt.stage AS 阶段,
    COUNT(*) AS 评委数,
    SUM(CASE WHEN rt.status = 'SCORED' THEN 1 ELSE 0 END) AS 已评数
FROM registrations r
LEFT JOIN review_tasks rt ON rt.registration_id = r.id
WHERE r.competition_id = 1
GROUP BY r.id, r.project_name, rt.stage
ORDER BY r.id, rt.stage;
```
