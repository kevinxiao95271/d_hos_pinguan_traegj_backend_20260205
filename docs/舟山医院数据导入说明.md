## 🔍 查询示例

### 查看舟山医院所有项目

```sql
SELECT 
    r.id,
    r.project_name,
    r.group_type,
    r.group_code,
    u.name AS applicant_name,
    u.phone
FROM registrations r
INNER JOIN user_accounts u ON r.applicant_id = u.id
WHERE r.institution_id = 17
  AND u.phone LIKE '19925%'
ORDER BY r.id;
```

### 查看某个项目的完整信息

```sql
SELECT 
    r.*,
    a.theme AS activity_theme,
    a.method_code,
    p.problem,
    p.success
FROM registrations r
LEFT JOIN activity_infos a ON a.registration_id = r.id
LEFT JOIN project_summaries p ON p.registration_id = r.id
INNER JOIN user_accounts u ON r.applicant_id = u.id
WHERE u.phone = '19925000001';
```

## ⚠️ 注意事项

1. **执行顺序**: SQL脚本必须按顺序执行，因为有外键依赖
2. **数据备份**: 建议执行前先备份数据库
3. **重复执行**: 如果重复执行脚本，会因为手机号UNIQUE约束而失败
4. **数据清理**: 如需重新导入，先删除相关数据：

```sql
-- 删除舟山医院新导入的数据
DELETE FROM registration_members WHERE registration_id IN 
  (SELECT r.id FROM registrations r INNER JOIN user_accounts u ON r.applicant_id = u.id WHERE u.phone LIKE '19925%');
DELETE FROM project_summaries WHERE registration_id IN 
  (SELECT r.id FROM registrations r INNER JOIN user_accounts u ON r.applicant_id = u.id WHERE u.phone LIKE '19925%');
DELETE FROM activity_infos WHERE registration_id IN 
  (SELECT r.id FROM registrations r INNER JOIN user_accounts u ON r.applicant_id = u.id WHERE u.phone LIKE '19925%');
DELETE FROM registrations WHERE applicant_id IN 
  (SELECT id FROM user_accounts WHERE phone LIKE '19925%');
DELETE FROM user_accounts WHERE phone LIKE '19925%';
```
