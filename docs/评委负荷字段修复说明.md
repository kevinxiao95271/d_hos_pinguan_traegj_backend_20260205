# 评委负荷字段修复说明

## 问题描述

前端调用评委列表API时，所有评委的负荷显示为0，因为后端API没有返回 `currentLoad` 字段。

## 问题根源

`ReviewerListItem` DTO 中缺少 `currentLoad` 字段，导致前端无法获取评委的实际负荷数据。

## 修复方案

### 1. 在DTO中添加字段

**文件：** `src/main/java/com/trae/pinguan/web/dto/ReviewerListItem.java`

```java
@Data
@AllArgsConstructor
public class ReviewerListItem {
    private Long id;
    private String phone;
    private String name;
    private String title;
    private Long institutionId;
    private String institutionName;
    private String reviewerGroupCode;
    private String interviewGroupCode;
    private String expertBackground;
    private Integer currentLoad;  // ✅ 新增：当前负荷（已分配任务数）
}
```

### 2. 在Service中计算负荷

**文件：** `src/main/java/com/trae/pinguan/service/ReviewerService.java`

```java
@Transactional(readOnly = true)
public List<ReviewerListItem> list(...) {
    List<UserAccount> reviewers = userAccountRepository.findByRoleWithInstitution(RoleType.REVIEWER);
    
    // ✅ 计算每个评委的负荷（已分配任务数）
    Map<Long, Integer> loadMap = new HashMap<>();
    for (UserAccount reviewer : reviewers) {
        int load = reviewTaskRepository.findByReviewerId(reviewer.getId()).size();
        loadMap.put(reviewer.getId(), load);
    }
    
    return reviewers.stream()
        .filter(...)
        .map(user -> new ReviewerListItem(
            user.getId(),
            user.getPhone(),
            user.getName(),
            user.getTitle(),
            user.getInstitution() == null ? null : user.getInstitution().getId(),
            user.getInstitution() == null ? null : user.getInstitution().getName(),
            user.getReviewerGroupCode(),
            user.getInterviewGroupCode(),
            user.getExpertBackground(),
            loadMap.getOrDefault(user.getId(), 0)  // ✅ 返回负荷
        ))
        .collect(Collectors.toList());
}
```

## 前端使用

```javascript
// 获取评委列表
const response = await fetch('/api/admin/reviewers?competitionId=21', {
  headers: { 'Authorization': `Bearer ${token}` }
});

const result = await response.json();
const reviewers = result.data;

// 显示负荷
reviewers.forEach(reviewer => {
  console.log(`${reviewer.name}: ${reviewer.currentLoad} 个任务`);
});

// 按负荷排序
const sortedByLoad = reviewers.sort((a, b) => b.currentLoad - a.currentLoad);
```

## 注意事项

1. **负荷计算**：`currentLoad` 是评委已分配的所有任务数（包括所有阶段和状态）
2. **性能优化**：使用Map一次性计算所有评委的负荷，避免N+1查询
3. **默认值**：如果评委没有任务，返回0
4. **实时性**：每次调用API都会重新计算最新的负荷
