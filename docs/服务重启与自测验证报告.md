## ⚠️ 故障排查

### 问题1: 服务无法启动

**症状**: `mvn spring-boot:run` 卡住或报错

**排查步骤**:
1. 检查数据库连接配置
2. 查看完整错误日志
3. 确认环境变量配置
4. 检查依赖是否完整

**解决方案**:
```bash
# 重新安装依赖
mvn clean install -DskipTests

# 查看详细日志
mvn spring-boot:run -X
```

### 问题2: 编译错误

**症状**: `BUILD FAILURE` 或类型不匹配

**已修复**: 
- ✅ `RegistrationController.listByApplicant()` 返回类型

**如果仍有问题**:
1. 清理编译缓存: `mvn clean`
2. 刷新IDE: Reload Project
3. 检查Java版本: `java -version` (需要Java 8+)

### 问题3: 测试脚本失败

**症状**: Python脚本报错

**排查步骤**:
1. 确认Python已安装requests库: `pip install requests`

3. 检查防火墙设置
