# 评审专家列表 - 机构等级字段添加

## 变更时间
2026-02-13 16:03

## 变更内容

在评审专家列表接口中添加 `institutionLevel` 字段，显示评审专家所属机构的等级。

## 影响接口

### GET /api/admin/reviewers

**变更前**：
```json
{
  "id": 14,
  "phone": "13800000001",
  "name": "陈卫东",
  "title": "主任医师",
  "institutionId": 1,
  "institutionName": "浙江大学医学院附属第二医院",
  "expertBackground": "MEDICAL",
  "currentLoad": 0
}
```

**变更后**：
```json
{
  "id": 14,
  "phone": "13800000001",
  "name": "陈卫东",
  "title": "主任医师",
  "institutionId": 1,
  "institutionName": "浙江大学医学院附属第二医院",
  "institutionLevel": "三级甲等",  ← 新增字段
  "expertBackground": "MEDICAL",
  "currentLoad": 0
}
```

### GET /api/admin/reviewers/list

同上（兼容路径）

## 字段说明

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| institutionLevel | String | 机构等级 | "三级甲等", "三级乙等", "二级甲等" 等 |

**可能的值**：
- 三级甲等
- 三级乙等
- 三级丙等
- 二级甲等
- 二级乙等
- 二级丙等
- 一级甲等
- 一级乙等
- 一级丙等
- null（未设置）

### React组件示例

```jsx
import React, { useEffect, useState } from 'react';
import axios from 'axios';

function ReviewerList() {
  const [reviewers, setReviewers] = useState([]);

  useEffect(() => {
    axios.get('/api/admin/reviewers')
      .then(response => setReviewers(response.data.data));
  }, []);

  return (
    <table>
      <thead>
        <tr>
          <th>姓名</th>
          <th>职称</th>
          <th>机构</th>
          <th>机构等级</th>
          <th>专业背景</th>
          <th>当前负荷</th>
        </tr>
      </thead>
      <tbody>
        {reviewers.map(reviewer => (
          <tr key={reviewer.id}>
            <td>{reviewer.name}</td>
            <td>{reviewer.title}</td>
            <td>{reviewer.institutionName}</td>
            <td>{reviewer.institutionLevel}</td>
            <td>{reviewer.expertBackground}</td>
            <td>{reviewer.currentLoad}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```
