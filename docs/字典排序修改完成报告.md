## 📊 排序逻辑说明

### SQL 排序表达式

```sql
ORDER BY CASE WHEN d.code = 'other' THEN 1 ELSE 0 END, d.id
```

**逻辑**：
1. `CASE WHEN d.code = 'other' THEN 1 ELSE 0 END`
   - `code='other'` 的项：排序值 = 1
   - 其他项：排序值 = 0
   - 升序排列：0 在前，1 在后
2. `, d.id`：相同排序值内按 ID 升序

**结果**：
- 非 'other' 的项按 ID 升序排在前面
- 'other' 项排在最后
