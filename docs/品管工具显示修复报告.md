## 📋 问题描述

### 用户反馈

**前端现象**:
- 表格列绑定：`<el-table-column prop="methodLabel" .../>`
- 数据来源：`GET /admin/registrations/filter` API
- 显示问题：品管工具显示 `method_11`、`method_1` 等代码，而不是 `品质标杆管理`、`PDCA` 等中文标签

### 根因分析

**API**: `GET /api/admin/registrations/filter`

**问题代码** (RegistrationService.java 第365-373行):

```java
// 字典标签查询已移除，直接使用code作为label ❌
for (RegistrationFilterItem item : items) {
    if (item.getMethodCode() != null) {
        item.setMethodLabel(item.getMethodCode());  // ❌ 直接用code作为label
    }
    if (item.getSubjectTypeCode() != null) {
        item.setSubjectTypeLabel(item.getSubjectTypeCode());  // ❌ 直接用code作为label
    }
}
```

**根本原因**:
- 代码注释说"字典标签查询已移除"
- 直接将 `code` 赋值给 `label` 字段
- 没有从字典表查询真正的中文标签

#### 3. 添加getLabel辅助方法

**新增方法**:
```java
/**
 * 根据code获取label，如果找不到则返回code本身
 */
private String getLabel(String code) {
    if (code == null || code.trim().isEmpty()) {
        return "未知";
    }
    return dictionaryItemRepository.findByCode(code)
            .map(item -> item.getLabel())
            .orElse(code);
}
```

**说明**:
- 参考 `StatsService.java` 中的相同方法
- 查询字典表获取label
- 如果找不到，返回code本身（兜底）

## 🚀 性能考虑

### 当前实现

**查询方式**: 每个记录查询一次字典表
```java
for (RegistrationFilterItem item : items) {
    if (item.getMethodCode() != null) {
        item.setMethodLabel(getLabel(item.getMethodCode()));  // 每次查询
    }
    if (item.getSubjectTypeCode() != null) {
        item.setSubjectTypeLabel(getLabel(item.getSubjectTypeCode()));  // 每次查询
    }
}
```

**性能分析**:
- 127条记录 × 2次查询 = 254次数据库查询
- 由于字典表数据量小（约110条），且有索引，查询速度快
- 实际测试耗时：< 1秒

### 优化建议（可选）

如未来数据量增大，可考虑批量查询优化：

```java
// 1. 收集所有code
Set<String> allCodes = new HashSet<>();
items.forEach(item -> {
    if (item.getMethodCode() != null) allCodes.add(item.getMethodCode());
    if (item.getSubjectTypeCode() != null) allCodes.add(item.getSubjectTypeCode());
});

// 2. 批量查询
List<DictionaryItem> dictItems = dictionaryItemRepository.findByCodeIn(allCodes);
Map<String, String> codeToLabel = dictItems.stream()
    .collect(Collectors.toMap(DictionaryItem::getCode, DictionaryItem::getLabel));

// 3. 填充label
items.forEach(item -> {
    if (item.getMethodCode() != null) {
        item.setMethodLabel(codeToLabel.getOrDefault(item.getMethodCode(), item.getMethodCode()));
    }
    if (item.getSubjectTypeCode() != null) {
        item.setSubjectTypeLabel(codeToLabel.getOrDefault(item.getSubjectTypeCode(), item.getSubjectTypeCode()));
    }
});
```
