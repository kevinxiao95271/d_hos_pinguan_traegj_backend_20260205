## 问题根因分析

### Bug 1：JPQL查询条件的空字符串判断问题

**位置：** `ConstInitInstitutionRepository.searchInstitutions()`

**原代码：**
```java
@Query("SELECT c FROM ConstInitInstitution c WHERE " +
       "(:keyword IS NULL OR c.name LIKE %:keyword% ...) AND " +
       "(:region IS NULL OR c.region = :region) AND " +
       "(:level IS NULL OR c.level = :level)")
```

**问题：**
1. `:keyword IS NULL` 只能判断NULL，不能判断空字符串`""`
2. 前端传空字符串`""`时，条件被判断为false，导致查询失败
3. LIKE语法错误：`%:keyword%` 应该用 `CONCAT`

**修复后：**
```java
@Query("SELECT c FROM ConstInitInstitution c WHERE " +
       "(:keyword IS NULL OR :keyword = '' OR c.name LIKE CONCAT('%', :keyword, '%') ...) AND " +
       "(:region IS NULL OR :region = '' OR c.region = :region) AND " +
       "(:level IS NULL OR :level = '' OR c.level = :level)")
```

**关键改动：**
- ✅ 添加 `:keyword = ''` 空字符串判断
- ✅ 使用 `CONCAT('%', :keyword, '%')` 正确的LIKE语法
- ✅ 对所有参数都添加空字符串判断

---

### Bug 2：Specification查询缺少默认条件

**位置：** `ConstInitInstitutionService.searchWithExpandedRegions()`

**原代码：**
```java
return cb.and(predicates.toArray(new Predicate[0]));
```

**问题：**
- 当所有条件都为空时，`predicates` 数组为空
- `cb.and()` 空数组返回 false，导致无结果

**修复后：**
```java
// 如果没有任何条件，返回所有结果
if (predicates.isEmpty()) {
    return cb.conjunction();
}
return cb.and(predicates.toArray(new Predicate[0]));
```

---

### Bug 3：等级为null没有统一处理

**位置：** `InstitutionController.searchV2()`

**修复：** 在DTO转换时统一处理
```java
// 等级处理：null或空字符串统一显示为"无等级"
String level = inst.getLevel();
if (level == null || level.trim().isEmpty() || "未定等".equals(level)) {
    level = "无等级";
}
```
