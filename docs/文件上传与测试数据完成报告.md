## 5. API使用说明

### 5.1 文件上传API

**端点**: `POST /api/registrations/{id}/materials`

**请求参数**:
- `type`: 材料类型（String）
- `file`: 上传的文件（MultipartFile）

**文件限制**:
- ✅ 最大大小: **30MB**
- ✅ 支持格式: pdf, doc, docx, xls, xlsx, ppt, pptx, **zip, rar**, jpg, jpeg, png, gif

**请求示例** (curl):
```bash
curl -X POST "http://localhost:6031/api/registrations/123/materials" \
  -H "Authorization: Bearer {token}" \
  -F "type=PROJECT_SUMMARY" \
  -F "file=@/path/to/document.rar"
```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "id": 456,
    "type": "PROJECT_SUMMARY",
    "fileName": "document.rar",
    "fileUrl": "/data/uploads/123/uuid-document.rar",
    "uploadedAt": "2026-02-26T10:00:00"
  }
}
```

### 5.2 统计API

**端点**: `GET /api/admin/stats/summary`

**认证**: Bearer Token (管理员)

**查询参数**:
- `competitionId` (可选): 赛事ID，不传则获取最新赛事统计

**请求示例**:

## 9. 前端集成示例

### 9.1 文件上传

```vue
<template>
  <el-upload
    :action="`/api/registrations/${registrationId}/materials`"
    :headers="{ Authorization: `Bearer ${token}` }"
    :data="{ type: 'PROJECT_SUMMARY' }"
    :before-upload="beforeUpload"
    accept=".pdf,.doc,.docx,.xls,.xlsx,.ppt,.pptx,.zip,.rar,.jpg,.jpeg,.png,.gif"
  >
    <el-button type="primary">上传佐证材料</el-button>
    <template #tip>
      <div class="el-upload__tip">
        支持 pdf, doc, docx, xls, xlsx, ppt, pptx, zip, rar, jpg, jpeg, png, gif
        <br/>
        文件大小不超过 30MB
      </div>
    </template>
  </el-upload>
</template>

<script setup>
const beforeUpload = (file) => {
  const maxSize = 30 * 1024 * 1024; // 30MB
  if (file.size > maxSize) {
    ElMessage.error('文件大小不能超过30MB');
    return false;
  }
  
  const allowedTypes = [
    'pdf', 'doc', 'docx', 'xls', 'xlsx', 
    'ppt', 'pptx', 'zip', 'rar',
    'jpg', 'jpeg', 'png', 'gif'
  ];
  
  const ext = file.name.split('.').pop().toLowerCase();
  if (!allowedTypes.includes(ext)) {
    ElMessage.error('不支持的文件类型');
    return false;
  }
  
  return true;
};
</script>
```

```vue
import { ref, onMounted } from 'vue';
import axios from 'axios';

const stats = ref(null);

onMounted(async () => {
  const { data } = await axios.get('/api/admin/stats/summary', {
    headers: { Authorization: `Bearer ${token}` }
  });
  
  if (data.success) {
    stats.value = data.data;
    
    // 加载字典表，将code转换为label
    await enrichWithLabels(stats.value);
  }
});

// 将code转换为中文label
const enrichWithLabels = async (stats) => {
  // 获取所有字典数据
  const dictionaries = await axios.get('/api/dictionaries').then(r => r.data);
  
  // 创建code到label的映射
  const codeToLabel = {};
  dictionaries.forEach(item => {
    codeToLabel[item.code] = item.label;
  });
  
  // 转换methodCounts
  const methodCountsWithLabels = {};
  for (const [code, count] of Object.entries(stats.methodCounts)) {
    const label = codeToLabel[code] || code;
    methodCountsWithLabels[label] = count;
  }
  stats.methodCountsDisplay = methodCountsWithLabels;
  
  // 同样处理subjectTypeCounts
  const subjectCountsWithLabels = {};
  for (const [code, count] of Object.entries(stats.subjectTypeCounts)) {
    const label = codeToLabel[code] || code;
    subjectCountsWithLabels[label] = count;
  }
  stats.subjectTypeCountsDisplay = subjectCountsWithLabels;
};
</script>
```
