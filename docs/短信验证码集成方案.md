# 短信验证码集成方案

## 📋 概述

为了防止恶意注册和验证手机号真实性，系统新增了**短信验证码**功能。

### 两种注册方式

| 方式 | 安全性 | 适用场景 | 状态 |
|------|--------|---------|------|
| **短信验证码注册** | ⭐⭐⭐⭐⭐ | 生产环境、公开注册 | ✅ 推荐 |
| 直接密码注册 | ⭐⭐⭐ | 测试环境、内部系统 | ⚠️ 不推荐 |

---

## 🚀 使用方式

### 模式A: 模拟模式（默认）

**适合**: 开发、测试环境

**特点**:
- ✅ 无需真实短信服务
- ✅ 验证码打印到日志
- ✅ 功能完全可用
- ✅ 零成本

**配置**: 
```yaml
# application.yml
sms:
  enabled: false
  mock: true
```

**流程**:
```
1. 前端调用 POST /api/auth/send-sms
2. 后端生成验证码（如：123456）
3. 验证码打印到后端日志
4. 开发者从日志中复制验证码
5. 前端输入验证码完成注册
```

---

### 模式B: 真实短信（生产）

**适合**: 生产环境

**特点**:
- ✅ 真实发送短信
- ✅ 用户自动收到
- ⚠️ 需要短信服务商
- ⚠️ 按量收费

**配置**:
```yaml
# application.yml
sms:
  enabled: true
  mock: false
  # 短信服务商配置
  provider: aliyun  # 或 tencent
  accessKeyId: your-access-key-id
  accessKeySecret: your-access-key-secret
  signName: 品管大赛
  templateCode: SMS_123456789
```

## 📡 API接口

### 1. 发送验证码

```http
POST /api/auth/send-sms
Content-Type: application/json

{
  "phone": "13800138000",
  "type": "REGISTER"
}
```

**验证码类型**:
- `REGISTER` - 注册
- `LOGIN` - 登录
- `RESET_PASSWORD` - 重置密码
- `CHANGE_PHONE` - 更换手机号

**响应**:
```json
{
  "success": true,
  "data": "验证码已发送"
}
```

**限制**:
- ✅ 同一手机号60秒内只能发送一次
- ✅ 验证码有效期5分钟
- ✅ 验证码格式：6位数字

---

### 2. 验证验证码（可选）

```http
POST /api/auth/verify-sms
Content-Type: application/json

{
  "phone": "13800138000",
  "code": "123456"
}
```

**响应**:
```json
{
  "success": true,
  "data": "验证成功"
}
```

---

### 3. 短信验证码注册 ⭐

```http
POST /api/auth/register-with-sms
Content-Type: application/json

{
  "phone": "13800138000",
  "smsCode": "123456",
  "password": "password123",
  "confirmPassword": "password123",
  "name": "张三",
  "title": "主任医师",
  "role": "CONTESTANT",
  "institutionId": 123,
  "expertBackground": "心内科"
}
```

**流程**:
1. 验证短信验证码
2. 验证手机号未注册
3. 验证密码一致性
4. 创建用户账号
5. 返回Token

**响应**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "phone": "13800138000",
    "name": "张三",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

## 💻 前端集成

### Vue.js 完整示例

```vue
<template>
  <div class="register-page">
    <!-- 步骤1: 选择机构 -->
    <el-card v-if="step === 1" class="step-card">
      <h2>选择所属机构</h2>
      <institution-selector @select="onInstitutionSelect" />
    </el-card>
    
    <!-- 步骤2: 验证手机号 -->
    <el-card v-if="step === 2" class="step-card">
      <h2>验证手机号</h2>
      <el-form :model="phoneForm" :rules="phoneRules" ref="phoneFormRef">
        <el-form-item label="手机号" prop="phone">
          <el-input 
            v-model="phoneForm.phone" 
            placeholder="请输入手机号"
            maxlength="11">
          </el-input>
        </el-form-item>
        
        <el-form-item label="验证码" prop="code">
          <el-input 
            v-model="phoneForm.code" 
            placeholder="请输入6位验证码"
            maxlength="6"
            style="width: 200px">
            <template #append>
              <el-button 
                @click="sendSms" 
                :disabled="countdown > 0"
                :loading="sending">
                {{ countdown > 0 ? `${countdown}秒后重试` : '获取验证码' }}
              </el-button>
            </template>
          </el-input>
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="verifyPhone">
            下一步
          </el-button>
          <el-button @click="step = 1">返回</el-button>
        </el-form-item>
      </el-form>
    </el-card>
    
    <!-- 步骤3: 设置密码和其他信息 -->
    <el-card v-if="step === 3" class="step-card">
      <h2>完善信息</h2>
      <el-form :model="registerForm" :rules="registerRules" ref="registerFormRef">
        <el-form-item label="密码" prop="password">
          <el-input 
            type="password" 
            v-model="registerForm.password" 
            placeholder="6-20位密码"
            show-password>
          </el-input>
        </el-form-item>
        
        <el-form-item label="确认密码" prop="confirmPassword">
          <el-input 
            type="password" 
            v-model="registerForm.confirmPassword" 
            placeholder="再次输入密码"
            show-password>
          </el-input>
        </el-form-item>
        
        <el-form-item label="姓名" prop="name">
          <el-input v-model="registerForm.name" placeholder="请输入真实姓名" />
        </el-form-item>
        
        <el-form-item label="职称" prop="title">
          <el-input v-model="registerForm.title" placeholder="如：主任医师" />
        </el-form-item>
        
        <el-form-item label="角色" prop="role">
          <el-select v-model="registerForm.role" placeholder="请选择角色">
            <el-option label="参赛者" value="CONTESTANT" />
            <el-option label="评委" value="REVIEWER" />
          </el-select>
        </el-form-item>
        
        <el-form-item label="所属机构">
          <el-input :value="selectedInstitution.name" disabled />
        </el-form-item>
        
        <el-form-item 
          v-if="registerForm.role === 'REVIEWER'" 
          label="专家背景">
          <el-input 
            v-model="registerForm.expertBackground" 
            placeholder="如：心内科" />
        </el-form-item>
        
        <el-form-item>
          <el-button 
            type="primary" 
            @click="submitRegister" 
            :loading="loading">
            完成注册
          </el-button>
          <el-button @click="step = 2">返回</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script>
import InstitutionSelector from './InstitutionSelector.vue';

export default {
  components: { InstitutionSelector },
  
  data() {
    return {
      step: 1,
      selectedInstitution: null,
      countdown: 0,
      sending: false,
      loading: false,
      
      // 手机验证表单
      phoneForm: {
        phone: '',
        code: ''
      },
      phoneRules: {
        phone: [
          { required: true, message: '请输入手机号', trigger: 'blur' },
          { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
        ],
        code: [
          { required: true, message: '请输入验证码', trigger: 'blur' },
          { pattern: /^\d{6}$/, message: '验证码为6位数字', trigger: 'blur' }
        ]
      },
      
      // 注册表单
      registerForm: {
        password: '',
        confirmPassword: '',
        name: '',
        title: '',
        role: 'CONTESTANT',
        expertBackground: ''
      },
      registerRules: {
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' },
          { min: 6, max: 20, message: '密码长度6-20位', trigger: 'blur' }
        ],
        confirmPassword: [
          { required: true, message: '请再次输入密码', trigger: 'blur' },
          { 
            validator: (rule, value, callback) => {
              if (value !== this.registerForm.password) {
                callback(new Error('两次密码不一致'));
              } else {
                callback();
              }
            }, 
            trigger: 'blur' 
          }
        ],
        name: [
          { required: true, message: '请输入姓名', trigger: 'blur' }
        ],
        role: [
          { required: true, message: '请选择角色', trigger: 'change' }
        ]
      }
    };
  },
  
  methods: {
    // 机构选择
    onInstitutionSelect(institution) {
      this.selectedInstitution = institution;
      this.step = 2;
    },
    
    // 发送短信验证码
    async sendSms() {
      // 验证手机号
      try {
        await this.$refs.phoneFormRef.validateField('phone');
      } catch {
        return;
      }
      
      this.sending = true;
      
      try {
        const response = await this.$http.post('/api/auth/send-sms', {
          phone: this.phoneForm.phone,
          type: 'REGISTER'
        });
        
        if (response.data.success) {
          this.$message.success('验证码已发送');
          
          // 开始倒计时
          this.countdown = 60;
          const timer = setInterval(() => {
            this.countdown--;
            if (this.countdown <= 0) {
              clearInterval(timer);
            }
          }, 1000);
        } else {
          this.$message.error(response.data.message);
        }
      } catch (error) {
        this.$message.error('发送失败：' + (error.response?.data?.message || error.message));
      } finally {
        this.sending = false;
      }
    },
    
    // 验证手机号
    async verifyPhone() {
      const valid = await this.$refs.phoneFormRef.validate();
      if (!valid) return;
      
      // 可选：先调用验证接口检查验证码
      // 或者直接进入下一步，在最终注册时验证
      this.step = 3;
    },
    
    // 提交注册
    async submitRegister() {
      const valid = await this.$refs.registerFormRef.validate();
      if (!valid) return;
      
      this.loading = true;
      
      try {
        const response = await this.$http.post('/api/auth/register-with-sms', {
          phone: this.phoneForm.phone,
          smsCode: this.phoneForm.code,
          password: this.registerForm.password,
          confirmPassword: this.registerForm.confirmPassword,
          name: this.registerForm.name,
          title: this.registerForm.title,
          role: this.registerForm.role,
          institutionId: this.selectedInstitution.id,
          expertBackground: this.registerForm.expertBackground
        });
        
        if (response.data.success) {
          // 保存Token
          const token = response.data.data.token;
          localStorage.setItem('token', token);
          localStorage.setItem('user', JSON.stringify(response.data.data));
          
          this.$message.success('注册成功！');
          
          // 跳转到主页
          this.$router.push('/dashboard');
        } else {
          this.$message.error(response.data.message);
        }
      } catch (error) {
        this.$message.error('注册失败：' + (error.response?.data?.message || error.message));
      } finally {
        this.loading = false;
      }
    }
  }
};
</script>

<style scoped>
.register-page {
  max-width: 600px;
  margin: 50px auto;
}

.step-card {
  margin-bottom: 20px;
}
</style>
```

### 方案1: 阿里云短信（推荐）

#### 1. 添加依赖


#### 2. 配置

```yaml

  enabled: true
  mock: false
  provider: aliyun
  aliyun:
    accessKeyId: ${ALIYUN_SMS_ACCESS_KEY_ID}
    accessKeySecret: ${ALIYUN_SMS_ACCESS_KEY_SECRET}
    signName: 品管大赛
    templateCode: SMS_123456789  # 你的模板CODE
```

#### 3. 实现代码

```java
// SmsService.java
private boolean sendSmsViaSmsProvider(String phone, String code, SmsCodeType type) {
    try {
        // 初始化配置
        Config config = new Config()
            .setAccessKeyId(aliyunAccessKeyId)
            .setAccessKeySecret(aliyunAccessKeySecret);
        config.endpoint = "dysmsapi.aliyuncs.com";
        
        Client client = new Client(config);
        
        // 构建请求
        SendSmsRequest request = new SendSmsRequest()
            .setPhoneNumbers(phone)
            .setSignName(aliyunSignName)
            .setTemplateCode(aliyunTemplateCode)
            .setTemplateParam("{\"code\":\"" + code + "\"}");
        
        // 发送
        SendSmsResponse response = client.sendSms(request);
        
        return "OK".equals(response.getBody().getCode());
    } catch (Exception e) {
        log.error("阿里云短信发送失败: {}", e.getMessage(), e);
        return false;
    }
}
```

#### 4. 申请流程

1. **注册阿里云账号**: https://www.aliyun.com
2. **开通短信服务**: 
   - 访问：https://dysms.console.aliyun.com
   - 点击"开通服务"
3. **创建签名**:
   - 名称：品管大赛
   - 类型：网站/App
   - 需要提供证明材料
4. **创建模板**:
   - 内容：`您的验证码是${code}，5分钟内有效`
   - 等待审核（1-2个工作日）
5. **获取AccessKey**:
   - 访问：https://ram.console.aliyun.com
   - 创建用户并授权短信权限
   - 记录AccessKeyId和Secret

#### 5. 费用

- **国内短信**: 约0.045元/条
- **营销短信**: 约0.055元/条
- **充值**: 最低100元

```java
private boolean sendSmsViaSmsProvider(String phone, String code, SmsCodeType type) {
    try {
        Credential cred = new Credential(tencentSecretId, tencentSecretKey);
        
        SmsClient client = new SmsClient(cred, "ap-guangzhou");
        
        SendSmsRequest request = new SendSmsRequest();
        request.setPhoneNumberSet(new String[]{"+86" + phone});
        request.setSmsSdkAppId(tencentAppId);
        request.setSignName(tencentSignName);

        request.setTemplateParamSet(new String[]{code, "5"});
```

## 🔒 安全建议

### 1. 防刷机制

✅ **已实现**:
- 60秒内同一手机号只能发送一次
- 验证码5分钟有效期
- 验证码使用后立即失效

⚠️ **建议增加**:
- 同一IP每小时最多发送10次
- 同一手机号每天最多发送5次
- 图形验证码（防止机器人）

### 2. 验证码安全

✅ **已实现**:
- 6位随机数字
- 一次性使用
- 有效期限制

⚠️ **建议增加**:
- 验证失败3次后锁定5分钟
- 记录发送和验证日志
- 监控异常发送模式

### 3. 数据安全

✅ **建议**:
- AccessKey使用环境变量
- 不在代码中硬编码密钥
- 定期轮换AccessKey
- 限制AccessKey权限

## ❓ 常见问题

### Q1: 模拟模式下如何获取验证码？

**A**: 查看后端日志，搜索"模拟短信"关键词：
```
[INFO] 【模拟短信】发送验证码到 13800138000: 123456
```

### Q2: 验证码有效期多久？

**A**: 5分钟。过期后需要重新获取。

### Q3: 多久可以重新发送？

**A**: 60秒。防止频繁发送浪费短信费用。

### Q4: 验证码可以重复使用吗？

**A**: 不可以。验证成功后立即失效，需要重新获取。

### Q5: 生产环境必须使用真实短信吗？

**A**: 
- **公开注册**: 必须使用，保证安全性
- **内部系统**: 可选，可以使用管理员审核代替

### Q6: 短信服务商如何选择？

**A**: 
- **阿里云**: 稳定性高，价格适中，推荐
- **腾讯云**: 功能丰富，价格略低
- **其他**: 华为云、网易云信等
