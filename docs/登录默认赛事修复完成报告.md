#### 1.2 CompetitionService 新增方法

**文件：** `src/main/java/com/trae/pinguan/service/CompetitionService.java`

```java
/**
 * 获取最新赛事（ID最大的赛事）
 */
public Optional<Competition> getLatest() {
    return competitionRepository.findAll().stream()
            .max(Comparator.comparing(Competition::getId));
}
```

#### 1.3 AuthController 登录逻辑

**文件：** `src/main/java/com/trae/pinguan/web/AuthController.java`

```java
private LoginResponse buildLoginResponse(UserAccount user) {
    // 获取最新赛事作为默认选中
    Optional<Competition> latestCompetition = competitionService.getLatest();
    
    return new LoginResponse(
        // 原有字段...
        jwtService.generateToken(user),
        latestCompetition.map(Competition::getId).orElse(null),
        latestCompetition.map(Competition::getName).orElse(null)
    );
}
```

#### 1.4 新增公开API

**文件：** `src/main/java/com/trae/pinguan/web/CompetitionController.java`

```java
@GetMapping("/latest")
@Operation(summary = "获取最新赛事", description = "返回ID最大的赛事，用作默认选中")
public ApiResponse<Competition> latest() {
    return competitionService.getLatest()
            .map(ApiResponse::ok)
            .orElse(ApiResponse.fail("暂无赛事"));
}
```

#### 1.5 白名单配置

**文件：** `src/main/java/com/trae/pinguan/config/JwtAuthorizationFilter.java`

```java
// 赛事查询公开接口（获取赛事列表和最新赛事）
if ("GET".equalsIgnoreCase(method) && 
    (path.equals("/api/competitions") || path.equals("/api/competitions/latest"))) {
    filterChain.doFilter(request, response);
    return;
}
```

## 💻 前端使用指引

### 1. 登录时获取默认赛事

```javascript
// 登录请求
const response = await fetch('http://81.71.44.180:6031/api/auth/login-with-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    phone: '13800000127',
    password: 'committee2026'
  })
});

const { data } = await response.json();

// 保存到状态管理
localStorage.setItem('token', data.token);
localStorage.setItem('competitionId', data.currentCompetitionId);      // ✨ 保存默认赛事ID
localStorage.setItem('competitionName', data.currentCompetitionName);  // ✨ 保存默认赛事名称
localStorage.setItem('userInfo', JSON.stringify(data));
```

### 2. 使用默认赛事ID

```javascript
// 获取当前赛事ID（无需再弹出选择框）

// 使用赛事ID进行后续操作
const registrations = await fetch(`/api/registrations?competitionId=${competitionId}`, {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});
```

### 3. 切换赛事（可选）

